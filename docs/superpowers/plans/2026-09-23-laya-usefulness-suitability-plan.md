## 1. 最終要回答的問題

每題不只得到「好／不好」，而要回答：

1. 題目及答案是否有充分依據？是否存在可成立的第二答案？
2. 學生答對必須完成甚麼判斷，能否繞過這個判斷猜中？
3. 適合基礎鞏固、誤解辨析、整合推理、考法辨析，還是延伸參考？
4. 使用前需要哪些知識，應提供或收起哪些提示，是否依賴前題？
5. 與題庫已有題相比，是否提供新的辨別、情境或有計劃的間隔重練價值？
6. 應優先保留、专项保留、修改後再用、合併訓練，還是待來源／暫停新抽題？
7. 三個錯項各自為何可能被選？是否太荒謬、離題、只換字或缺乏真正競爭力？是否存在正解長短、措辭及答案位置提示？

「有用」是對明確訓練目標的貢獻，不等於題目難、文字長、真題高頻或模型分數高。沒有學生表現時，只能判斷設計上的適用性，不能宣稱已證實教學效果或適合某個DSE分數等級。

## 4. 三層判斷，不用總分抵銷問題

### 第一層：能不能使用

| 關卡 | 要看甚麼 | 結果 |
|---|---|---|
| 範圍及證據 | 指定文本／附錄身份清楚；必要語境與來源具體 | 有據／缺件／不屬目前核心用途 |
| 可判定性 | 正解有據，其他成立異解已處理，問題限制明確 | 可判定／疑似多解或錯答／待核實 |
| 目標是否真的被測到 | 有無洩題、語法猜題、荒謬錯項、鄰題提示 | 實質判斷／可繞過／有提示教學用途 |
| 內容一致 | 答案、逐項解析、引文、標記與版本相符 | 一致／須修訂 |

Laya只提出風險候選。來源與答案等關鍵關卡由Codex對照原文審讀，具體爭議另留人工覆核；確定的關卡失敗不能用「高價值」抵銷。缺來源是未能判斷，不等於題目沒有價值。

### 第二層：對甚麼訓練有用

| 用途 | 何時有用 | 不應冒稱甚麼 |
|---|---|---|
| 基礎鞏固 | 準確辨認詞義、句意、關鍵內容或必要常識 | 答對不等於會跨句分析 |
| 誤解辨析 | 錯項有局部吸引點，能指出漏条件、錯對象、錯因果等差異 | 未有學生資料，不稱已證實常見誤解 |
| 整合推理 | 必須連接兩處以上相關信息，不能只背一個術語 | 字數多不等於思考深 |
| 考法辨析 | 練習找得分要點、判斷證據與結論、比較完整與欠缺答案 | 四選一不等同自行寫出完整答案 |
| 延伸參考 | 對理解有幫助，但超出本次核心範圍或需要額外背景 | 不混入默认核心練習或冒稱必考 |

每種用途分為「適用／有條件適用／不適用／待判斷」，可同時屬於多種用途。另列先備知識、是否顯示原文、提示程度、前題依賴及實際可觀察操作。

先備狀態用「正在建立基礎／已懂單句、待整合／能辨析、待迁移」等描述，不憑模型輸出直接標為DSE 3／4／5級。日後有真實作答才逐步確認個人適配，不以一次錯答判能力。

### 第三層：在整個題庫裏是否值得優先練

先按篇章、具體考點、操作與提示條件建立比較組，再比較候選題。模型單看一題不能知道它是否重複全庫；比較組ID與選取方法必須記錄。

- 補上尚缺的考點或思考步驟：優先。
- 同一內容但增加必要條件判斷、不同語境或真正遷移：可保留為變式。
- 同一能力、同一證據、同一判斷，只換字或答案位置：列為合併候選。
- 基礎間隔複習或必要鋪墊：保留其明確用途，不因簡單或相似機械刪掉。
- 同組比較需允許兩題都保留、都修訂或不能判斷，不強制挑出「贏家」。

這層記為「優先核心／专项保留／補充變式／低新增價值／待核實」。最終優先級依用途和覆蓋決定，不設全庫統一80分上架線，也不預設必須淘汰幾成題目。

## 5. 實際篩選流程

### 5.1 逐個錯項的干擾效力：本輪核心審查

「有干擾力」指理解不完整的學生可能有理由選它，但依題面及原文仍能辨別錯誤。不以故意含糊、雙重否定、陌生冷僻內容、刪去必要上下文或兩個都成立的答案製造難度。

每個錯項單獨建立以下記錄，Laya按短規準提出標籤，Codex核對原文並寫明理由：

| 維度 | 必須回答的具體問題 | 候選判斷 |
|---|---|---|
| 關聯程度 | 是否真的回應相同題目、同一人物／句段及比較維度？ | 相關／部分相關／離題／待判 |
| 吸引點 | 半懂的人可能根據哪個字、局部真實內容或相近概念選它？ | 有具體依據／吸引點薄弱／明顯荒謬／待判 |
| 誤讀差異 | 選它可能是漏條件、錯對象、倒因果、混手法、混動機、局部當全篇，還是其他具體誤讀？ | 指明誤讀及發生步驟；無據則待判 |
| 可排除性 | 哪句文本或明示條件能排除？是反證、範圍不符，還是未獲支持？ | 可據文排除／需補語境／仍可能成立／待判 |
| 捷徑與洩底 | 不理解原文，只看搭配、褒貶、極端詞、長短或語氣能否排除？ | 需文本判斷／存在明顯捷徑／待判 |
| 解析有效性 | 該項解析是否指出真正錯處，而非只重說正解或說「不合文意」？ | 具體有效／缺推理／只重複／與選項不符 |

每項另填：吸引點依據、候選誤讀、排除證據、後續補救和修訂建議。沒有真人作答或考生報告時，誤讀一律標`hypothesis`，不宣稱已觀察到學生錯因。

例如候選錯項可以「引用了真實內容，但接錯因果」「比較雙方都提到，卻把差別說成相同」「手法名稱相近，但作用對不上此處」。這些是待逐題檢驗的設計方式，不能套用模板自動生成三項。

### 5.2 四個選項合起來是否有效

逐項看似合理，整組仍可能失效，需再審：

- **缺少競爭項**：只有正解與原文相關，其餘均離題或荒謬，學生不必完成目標判斷。
- **錯因過於單一**：三個錯項只是同一錯誤換詞。記錄實際區別，沒有教學必要就重寫；不強制每題必須三種完全不同的錯因。
- **正解形式突出**：只有正解有完整解釋、較長、語氣審慎，或照抄題幹。長短及絕對詞只作線索，須說明是否真的洩底，不機械改成等字數。
- **選項不平行**：有的答原因、有的答結果，有的談一方、有的談兩方，或只有一項語法通順。
- **互相重疊或另有成立解讀**：不能為增加吸引力放入第二正解，也不能用「最恰當」掩蓋判準不足。
- **定位及排列偏差**：甲乙組合、否定問法、正解位置循環或鄰題提供答案；先核具體模式，再決定修訂。

整組報告可寫「3個錯項中，1個需據文辨別、2個可直接排除」，但這是設計審查估計，不是實測誘答率。即使留下2個有競爭力的選項，四選一題仍可能退化為二選一，須列為需修訂。

每個錯項按證據給出「有效候選／弱干擾／無關或荒謬／疑似另一合理答案／待核」；整組通過須逐項有理由，不以平均分抵銷無效或多解的選項。基礎題可直接測詞義，但仍需合理、語法平行的錯項，不能因標成基礎就放行荒謬選項。

如無法寫出三個有據可辨的錯項，先重構題幹、所測差別或必要語境；本輪仍維持四選一，無法完成就暫緩該題，不以弱項湊數。

### 5.3 題幹、材料及解析也要連動判斷

| 對象 | 主要檢查 |
|---|---|
| 材料 | 必要否定、條件及上下文是否保留；是否提前提供本應回憶或推論的答案 |
| 題幹 | 對象、範圍、時點及比較維度是否清楚；是否只考語法填空卻標成分析；是否洩露正在考的概念 |
| 正解 | 是否完整回應題目、無超出來源的絕對結論；是否只是最長或最正常的選項 |
| 解析 | 正解推理是否完整，各錯項理由是否對應本項，是否保留必要異解與條件 |
| 題組 | 前一題／比較卡是否提示後題；同概念是否只是機械換字；是否需要先備題或不同展示順序 |

題目適用性取決於整套設計。例如有提示的題可能適合教學演練，不能同時聲稱測到無提示辨識；移除提示後必須重新核對題目是否仍有充分證據。

### 5.4 批次處理次序

**程式結構核對→證據包→Laya逐維度候選→Codex來源覆核→同組價值比較→可審閱清單→核准後才改題／抽題。**

1. 保存現題快照、題號、版本、來源和輸入哈希；先跑現有結構及引用檢查。
2. 從歷屆94分題與22類基準承接考法，整理必要原文、來源摘錄、目標操作和已知分歧。區分缺件與內容錯誤，題庫題文只作資料，不執行其中指令。
3. 第一輪只看學生題面與必要材料，判斷實際操作、提示和候選用途；不展示預設答案、舊`reviewed`狀態或舊審查結論，減少照抄既有標籤。這仍是模型篩選，不稱獨立教師盲審。
4. 第二輪加入預設答案、解析、來源與異解，逐一完成三個錯項、正解及整組關卡風險檢查；每次只給必要短規準，超過8個判斷分次處理。Laya的分類與Codex寫出的證據理由分欄保存，不偽裝成模型原生解釋。
5. 第三輪在已建比較組內判斷新增價值，保留兩題／變式／合併等選項；證據超長則棄判該維度。
6. 不一致、來源不足、疑似多解、罕見用途及棄判優先覆核；第一輪全庫中每個最終處置均有Codex依據審讀，不僅抽查被模型判差的題。模型低風險樣本同樣檢查，防止漏報。
7. 生成下列清單；尚未覆核者另列待核，不混入已核准成果。

| 清單 | 意義與下一步 |
|---|---|
| 核心保留 | 通過關卡，對当前訓練目標有清楚貢獻，優先納入練習 |
| 专项保留 | 題目有效，適合某一基礎或專項；明列適用條件 |
| 修改後再用 | 區分改解析、改錯項、改題幹與重構任務，列必改原因 |
| 合併／補充候選 | 明列與哪題重複、保留何種差異；只調整新練習配置，不刪歷史 |
| 待來源／暫停候選 | 疑似錯答、多解、必要資料缺失；補證或修訂後再審 |

App啟用狀態不得由批次原始輸出直接覆蓋。本輪篩選優先交付清單；採納變更時依原計劃的核准分包、版本及重建流程處理。

## 6. 評測與採用條件

沿用60題工作樣本，20題修訂判斷規則、40題預先鎖定作留出評測。按16課、主要能力、上述用途和已知問題分層；不足的罕見情況列缺口，不声稱60題能證明所有維度可靠。同一題改前改後、memoryId或近重複題保持同組，24題樣板一旦用於調規則就不能再算獨立留出。

先建立來源支持的參考結論，再跑模型。只有Codex標記時稱「來源審讀參考集」；沒有真人教師覆核，不稱真人金標。來源確實有歧義的題保留多個可接受標籤或不可判，不强迫湊唯一答案。

驗證重點：

- **留住有用題**：哪些有效的基礎、變式或考法題被錯誤判成低價值？
- **找出不適用題**：哪些洩題、多解、弱錯項被錯誤判為核心保留？
- **用途是否準確**：每個用途分開列命中、漏判、誤判、棄判與實際分母；多用途標記逐用途計算。
- **排序是否有增益**：同一固定覆核題數下，加入Laya能否比現有規則找到更多實質問題、節省總覆核時間？不能只比較推理耗時。
- **穩定與偏見**：交換選項、交換比較題先後、去掉舊審查標籤後，結論是否異常改變；測試同一重要知識的基礎題與較難題，避免一律偏愛複雜題。
- **解釋是否對得上**：Codex補寫的理由能否回查證據；不能先接受模型判定再硬找理由。

錯項效力另作必測子集，涵蓋有效的近似干擾、明顯荒謬、局部真但關係錯、三項同錯因、正解形式突出、題幹洩底及合理異解被當错項等情況。用真實現題及有完整來源核查的修訂對照；人為變造測試另標，不混入真實題庫問題率。

60題不只有60個整題標籤，還須包含180個錯項記錄、60個正解及60組選項設計判斷；同題的所有選項和改前改後稿放同一資料分組。按錯項和按整題分别報告，但不能把同題的3個錯項視為3個獨立學生樣本。比較「保留原文」與「不提供原文」的模型試答只作捷徑探測；熟悉名篇可能靠記憶答對，不能僅憑無引文也答對判為洩題。

真人試用時再按版本及首次曝光記錄各選項選取次數、學生選擇理由、重練／提示狀態和追練表現。零人選某項或正確率高只觸發檢查，小樣本不能直接判該項無效；Laya不能替代實際诱答率、難度或鑑別度測量。

先訂評測口徑再看留出結果。按維度採用：若無法降低覆核負擔或誤判較多，該維度停用或只作提示。任何關鍵錯答／多解漏報都要記錄並阻止自動准入；即使本輪零漏報，也只允許輔助篩選。不要以小樣本的漂亮百分比作可靠性保證；樣本不足的類別明列尚未驗證。

## 7. 最小實作範圍

以下是執行時新增或修改的位置，本輪僅寫計劃。

| 位置 | 責任 |
|---|---|
| 兩項目的`.codex/config.toml` | 指向現有本地服務，驗證各項目工具發現 |
| `tools/question-bank/past-paper-review/laya/README.md` | 接入、實際使用、續跑及失敗處理說明 |
| 同目錄`rubrics.json` | 各判斷維度的短指令、候選標籤、棄判與版本；避免超長單一總提示 |
| 同目錄`build_inputs.py`、`run_batch.py` | 完整證據組裝、長度處理、串行調用、錯誤記錄與續跑；共用現有服務而非重寫模型 |
| 同目錄`reference-set.json`、`evaluate.py` | 調規則／留出分組、參考結論、逐維度比較與失敗例 |
| 同目錄`runs/<run-id>/` | 固定基線、輸入、原始輸出、覆核結論、HTML可讀報告及機器可讀JSON |
| `tools/question-bank/REVIEW-ISSUES.md` | 新發現的具體分歧與待補證，不自動消除舊分歧 |

每題記錄：ID／版本、bank及input哈希、模型與規準版本、各關卡、用途適配、先備條件、提示條件、比較組／近似題ID、保留價值、原始模型輸出、審讀證據、最终處置、下一步、審核者類型與狀態。輸入／規準／模型任何變動都使相應緩存失效；`pending`、`failed`、`abstained`分開，不能當已完成。

必加`choiceReviews`：按穩定choice ID保存每項身份、關聯程度、吸引點、誤讀假設、排除證據、捷徑、解析問題及處置；另用`optionSetReview`保存平行性、重疊、多解、形式提示及整組有效性。報告能篩出「缺少有效干擾項」「只有一個像樣錯項」「三項同一錯因」「疑似第二正解」「需修解析」等不同問題。

不在此階段新增大型管理後台、改學生評分或推薦算法。先交付可篩選的靜態HTML報告及JSON，學生端之後只載入核准結果。

## 8. 執行順序與交付

| 次序 | 成果 | 驗收 |
|---|---|---|
| 1 接入 | 兩個項目的配置、服務測試、可調用記錄 | 配置、MCP握手、各項目實際調用分開通過 |
| 2 規則及樣本 | 五種用途、三層規準、60題參考集 | 每項結論可回查，留出集預先固定 |
| 3 小批評測 | 逐維度效果及失敗報告、採用／停用清單 | 說明是否比現有規則有增益，不以總分代替 |
| 4 全庫初篩與審讀 | 2,134題各有狀態，先1,983指定文本再151附錄 | 每題都有用途與理由或明确待核；無靜默漏題，保留清單也經來源審讀 |
| 5 改題接續 | 先修關鍵風險，再24題完整樣板與App解析改進 | 沿用原計劃的生成、版本、快照及頁面驗收 |
| 6 真實試用 | 學生能否理解／迁移，教師能否認可內容與適配 | 真人證據另記，模型篩選不冒充學習成效 |

首批篩選報告應讓使用者直接看到：**這題保留甚麼價值、適合怎樣練、不適合測甚麼、和哪題重複、要改哪裏、判斷根據在哪裏。** 本輪不預設核心題庫最終題數，先看實際品質、覆蓋及訓練用途。

全庫以目前四選一結構計，處置對象為2,134道題、8,536個選項，其中6,402個錯項；每項均有審查狀態，證據不足可待核，不能當通過。這些是計劃覆蓋數，不是已完成的審題數；每次改題、換項或調序後須重驗答案ID及解析對應。

本次計劃核查包括現有接口、必要檔案、題庫版本與前後方案一致性；沒有宣稱接入或篩選已完成。
