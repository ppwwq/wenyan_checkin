## 目标与用户要求

第一次选好学习篇章及各篇题目类型，之后首页直接开始或继续训练；想增加篇章或类型时再主动修改。每日题量放入设置；题面只标错题；明确同一天答错后是否再次出现、何时出现，以及如何计数。

用户随后明确两项修正：“只标错题就好”“选新篇章的时候可选类型”。因此取消题面的未练／已练标记；题目类型随每篇保存，在新增篇章的当次操作里选择，不使用一套全局类型强行覆盖全部篇章。

2026-09-24 用户明确“不要10分钟间隔”：取消当日回练的时间门槛，答错后即可进入待回练清单，本组结束或暂停回到首页后可直接回练，不要求等候。

本次新要求优先于旧计划中“不加入每日目标”的阶段性约定。每日目标是个人安排，达标后仍允许主动加练。保留现有作答、题目快照、收藏、草稿、账号及备份，不修改题库内容。

## 一、长期学习设置

首次使用显示一次“设置我的训练”：

- 学习篇章：多选，可以后增加或暂停；暂停只影响后续出题，历史记录保留。
- 题目类型：选中／新增篇章时，直接展开这篇的“字词、句意、主旨、手法”多选，显示各类可用题数；确认后与该篇一起保存。例如《论语》只练字词、句意，《岳阳楼记》只练主旨、手法。每篇可随时增减类型；无题类型显示原因，至少选一个有题类型才能加入。手法附录独立开关。题目类型与作答方式分开，选择题／文字自查仍受题目实际支持约束，不凭空新增题型。
- 每日目标：默认建议 20 题，10／20／30 快选及 1–100 整数自定义。界面说明“一天同一知识点只计一次，错题回练另计”。
- 后续统一在“我的 → 学习设置”修改；首页只显示简短范围摘要及“调整”入口。顶端字号按钮保留为字号快捷操作，不把全部设置塞入小弹窗。

长期计划与临时专项筛选分开保存。长期范围按“篇章 → 已选类型集合”记录，增加一篇不会修改其他篇的类型。错题、收藏、对照或某个薄弱点的一次练习不覆盖长期设置。长期计划进入账号事件、同步及导出备份。

旧账号先完成同步，再优先采用已有的新版长期计划；若没有，首次升级只展示一次预填确认，可沿用旧本机范围。旧 `count` 原本是单组题数，不能声称它已经是用户确认的每日目标；旧范围也可能被专项入口改变，须允许在这一次确认中调整。显式保存空范围时显示“选择学习内容”，不能默默恢复全选。

按2026-09-24用户确认，保存范围、题类、每日题量与独立手法附录后，立即重排未完成每日训练／回练的未答题；已提交答案和原题快照保留，仍符合新范围的当前题与草稿接续。今日目标立即更新，已练数量不重置；目标低于或等于已练数时不再继续旧待答题。自选专项保持独立范围。旧事件仍按当时冻结规则读取，新的明确保存设置覆盖当天目标。

## 二、每天打开后的流程

首页主区域展示：当前范围、今日完成／目标、今日可回练数量；累计已练放在旁边，明确单位，避免与今日数字混淆。

1. 有未完成的日常组：主按钮为“继续训练”，恢复原题组和位置。
2. 无未完成组且未达目标：主按钮为“开始今日训练”，按设置直接生成剩余题量，无须再选篇章。
3. 达标：显示“今日目标已完成”，另给“错题回练”和“自选加练”。不要再次默认生成一份完整日目标。
4. 原有未完成专项练习单独保留入口，不混作今日新任务。
5. 上一日未做完的题组仍可接续；新增提交归实际香港日期，不补写成昨日完成。接续后的当日已练计入今天目标，之后只补今日剩余数量。

普通每日组按“昨日及更早到期 → 未练 → 已练但今天未练”选题，同一优先级内照顾篇章覆盖。上述状态用于内部选题，不显示为题面标签。今日已经正式提交的同一知识点不再次进入普通每日组；当天失误进入独立回练流程。同知识点的不同变式也不能用来重复凑目标；跨篇题必须满足所有关联篇章均已选中，且各关联篇章均选中该题所属类型，不绕过逐篇选择。

每日目标按当天正式提交的不同 `memoryId` 计数，答错和“暂时不会”也计为做过；主动加练的不同知识点可计入当天总量。收藏、阅读解析、翻卡不算作答。文字题提交可计已练，但未完成自查时独立标“待自查”，不能当正确。统计不因后来修改范围而回退，重复点击或两端同步同一事件不重复累计。

候选不足时显示实际可练数及原因，允许调整范围；不混入未选篇章或无限重复填满目标。首次即答对的旧知识点目前没有自动间隔日期，本轮不暗中重算全部旧曲线；它们仍可作为“已练但今天未练”的补充题。

## 三、题面只标错题

| 题目状态 | 建议呈现 |
| --- | --- |
| 从未做过、做过且不再待巩固 | 不加练习历史标签 |
| 这道题有尚待巩固的错误记录 | 题目顶部显示一个“错题”标签 |
| 当天错后回练改对 | 保留“错题”，提交后的反馈说明“今日已订正，明日再复习”，不添加多枚题面标签 |
| 次日或之后首次有效复习答对，且无更新的失误 | 取消“错题”标签；完整错误历史仍在记录页 |
| 此题没错过，只是同知识点的另一题错过 | 不把此题伪标为错题；知识点仍按既有规则安排巩固 |

错题标记由这道题的实际作答、有效自查及评分类更正派生；不因查看解析、收藏或生成题组而产生。当天先对后错也进入待巩固。正确率仍按原首次规则记录，最新失误及待巩固单独计算，不互相覆盖。题目更新不抹掉未结清的错误记录；有效评分更正为正确时应同步撤销相应的错误状态。

题面不显示“未练过”“已练过”“练过几次”等标签。提交后的对错反馈、文字题必需的自查步骤、回练页对计数规则的说明仍正常保留；这是完成作答的反馈，不是新增练习历史标签。历史日期和旧答案只在作答记录中查看，不提前展示答案。

篇章范围页和记录页仍可呈现累计已练与待巩固数量，明确题数和知识点数，不在每道题上贴标签；避免给跨篇题简单求和后虚增全库累计。保留旧版本完整记录，不因题库更新把累计进度清零。

## 四、同一天答错后的建议规则

按用户最新要求，当日回练不设时间间隔。以下次数及入口安排已按用户继续执行的指示实现。

- 默认开启“当日错题回练”，在学习设置可关闭。当天失误后立即进入待回练清单，不设分钟数或冷却时间；关闭后仍保留错题及次日复习。
- 不在原固定题组里临时插题，也不打断正在作答的题。首页及本组完成后显示回练入口，点击即可开始；暂停回首页也可进入，不用等当前组全部完成或等待计时。
- 每个知识点每天最多自动加入一次回练，即正常作答后至多再自动安排一次。手动加练不受此上限，但不重复发自动回练任务。
- 回练已答对，当天普通训练和自动回练都不再推这道题；回练仍错，也不无限循环，保留明日复习，用户可主动继续练。
- 回练单独计数，不充当第二个已练知识点，也不刷高每日首次正确率或拉长长期间隔。例：今日 20／20，另完成 3 道错题回练。
- 所有新规则启用后的当天失误，至少保留次日提醒；同日改对不能撤销。若手动加练出现“先对后错”，仍显示最新失误并安排回练／次日提醒，而当天首次表现保持正确。这是对当前“只看每日首次排程”的明确补充，须版本化测试，不能把二者混在一个 `correct` 状态里。
- 刷新、退出、暂停不重置已完成的回练次数；香港日期跨日后由次日复习承接。设置关闭、篇章暂停或题目下架后，不再自动安排该题回练；历史保留。现有十分钟提醒不得作为新回练入口的资格限制。

推荐将“长期首次表现”“当日最近一次有效结果”“当日自动回练是否已做”分别计算。旧事件及原有统计保留，新短期规则通过版本标记从启用后作答生效，不对全部历史作答追溯制造新任务。长期间隔增长仍按到期的每日首次有效表现处理；额外失误只能收紧提醒，不增长间隔。

优先沿用现有 `settings`、`session`、`attempt` 事件。长期计划作为一个完整的设置字段更新，避免设备间把篇章和能力分别合并成无意的组合；临时筛选不写入该字段。日常组／回练组附日期、用途及目标快照，恢复时不重新随机生成。新增字段须做前后端输入校验及旧备份兼容，不为界面标记另造一套历史数据库。

已确认同一组中 `session.answers` 及提交编号按题号唯一，因此回练应创建独立回练组，不能把原题重复塞进同一组而沿用旧提交编号。每次进入回练前再核对当前记录和次数，过滤已完成项，不检查等待时长；未答时保留原顺序与草稿，不覆盖已提交内容。

同步完成后重新派生设置和进度；禁止旧设备默认值覆盖已同步的显式设置。在线启动先合并可用记录，离线可继续本机已有计划。两设备同时离线组题可能重叠，恢复同步后按知识点／日期去重统计，保留真实两次作答；不承诺离线全局互斥，实施时明确处理冲突而非悄悄丢记录。

## 六、验收标准

1. 首次选两篇并为两篇选不同类型，重开、次日、重新登录及同账号同步到另一浏览器后，不要求再选；可直接练。新增第三篇时可直接选其类型，前两篇设置不变。专项入口不改变长期范围；跨篇题不能绕过任一篇的类型限制。
2. 每日 20 题，做 8 题暂停后恢复相同第 9 题及草稿；新组只补剩余目标。多次点击、刷新、跨入口和同知识点变式不重复累计。
3. 加入一篇、暂停一篇或变更题类只影响下一组；旧组可继续、旧记录可查。目标变更的生效日期清楚，不能静默删除已生成的任务。
4. 只有有实际待巩固错误记录的题显示“错题”，未做及普通已做题无新增标签；同日改对、次日答对、先对后错、评分更正、同知识点变式、待自查及新版本题都有覆盖，旧答案不会提前泄露。
5. 验证答错后立即进入待回练清单，本组结束或暂停回首页即可开始，不因不足十分钟禁用入口；同日答对后不再自动出现，二次错误也不循环；两种情况均有次日提醒。
6. “先对后错”“先错后对”“文字自查延迟”“评分快照被更正”“跨香港午夜”“关闭回练后重新开启”均有明确预期；首次统计、最近结果和提醒不互相覆盖。
7. 刷新、离线、恢复备份和两设备重复同步不重置目标或回练上限，不新增等待时间，不重复计数，不丢失旧草稿与历史。
8. 候选少于目标、全部已练、范围为空、所有题暂下架及附录单独启用均有真实提示，不越界补题。
9. 扩展现有 `tests/queue.test.mjs`、`tests/review.test.mjs`、`tests/practice.test.mjs`、`tests/storage.test.mjs` 及同步测试；需要时新增 `tests/training.test.mjs`。运行现有 `npm test`、`npm run build`；用隔离的本地测试账号验证完整浏览器流程并目视手机／iPad尺寸。旧浏览器脚本存在已过期选择器，须先对齐本次界面，不能直接沿用旧通过报告。
10. 自动测试、浏览器目视、真实设备试用及正式部署分开记录。已按2026-09-24用户授权完成正式发布。
