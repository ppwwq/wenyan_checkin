# 中文甲：同学使用的 iPad 网页与冲刺题库计划

日期：2026-09-19。状态：仅完成资料抽查与计划；本轮未修改应用、生成正式题库、创建账号或部署网站。

## 1. 产品目标与首版范围

面向同学各自使用，首发平台为 iPad Safari 网页。一套共享题库，每位同学各自拥有学习进度、错题、每日首次作答和收藏。建议采用邀请制账号，并提供账号恢复。

延续已认可的学习书房界面：左侧 DSE 中文倒数、香港日期、鼓励语、较大粗体原句和答案、默认选择题、设置可开启打字题、每组自定义 1–100 题、暂停继续、首次提交锁定、先思考再看解析、历史记录和每日复习日历。

用户已确认加入四项功能：篇章薄弱地图、易混词义对照、收藏与题目报错、考前快速回顾。这四项纳入正式交付范围，在同学使用版验收前完成；开发顺序依题库和个人记录的数据依赖安排。

用户指定考试日期为 2027-04-08，此计划沿用该日期，不将其表述为本轮核实的官方考期。

完成标准：同学在 iPad 打开正式网址并登录后，能选择多个篇章与题数，完成一次混合练习，暂停或刷新不丢进度，复习只按每题每天首次作答更新，且每道题能回查复习书中的依据。四项新增功能能够串起“发现薄弱点 → 对照理解 → 收藏／反馈 → 考前回顾”，所有入口沿用个人独立记录和每日首次作答规则。

## 3. 题目如何解决

### 3.1 优先结构化整理

以本次 PDF 同目录的最终 JSON 为底稿，保存文件版本与摘要，再抽取知识点并对照最终 PDF。目录中指向更早单篇卡片的 source 路径作为溯源材料，不直接覆盖同目录的校订内容。

结构化源文件不可用或发现漏项时，再从 PDF 补提取；复杂版面先核对渲染图，必要时用 MinerU 辅助。提取与核对结果另存，原资料保持完整。

流程：资料区块 → 可定位知识点 → 题目草稿 → 内容检查与修改 → 审核通过的题目包 → 网页使用。

第一版使用预先编写、核查和发布的题库。AI 可以协助拆知识点、拟题和拟干扰项；发布前逐题审核，学生答题时直接读取固定题目包。

### 3.2 适合转换的题型

| 来源内容 | 选择题形式 | 核查重点 |
| --- | --- | --- |
| 原句与词解 | 指定语境下的字词意义 | 原句位置、通假、古今义和多义词不能错配 |
| 语译与必要辨析 | 选最准确语译、找错误理解 | 不遗漏条件、因果、主语或否定关系 |
| 段旨、结构、主旨情感 | 段落作用、作者态度、线索 | 解析引用对应段落，避免只记标签 |
| 修辞与写作手法 | 手法与证据配对、具体作用辨析 | 同句可兼有多种手法，限定问题角度后再设唯一答案 |
| 跨篇比较 | 两篇在指定角度上的异同 | 两侧均有文本依据，且属于当前所选篇章 |

“篇章多选”用于选复习范围；题目维持现有单选作答。打字题继续作为设置中的可选项。

### 3.3 计划示例，不是已发布题库

原句：**空山新雨後，天氣晚來秋。**

题目：“空山”的“空”在这里最准确的意思是什么？

A. 山里完全没有人居住
B. 山中清幽空旷
C. 诗人心中空虚失落
D. 山上已经没有草木

答案 B。依据为资料中的词解“清幽空曠”，以及“不否定下文有人居住”的辨析。解析同时说明 A 把清幽误解为无人，C 把环境描写误当心理，D 无文本依据。

定位：《山居秋暝》原文第 1 组，PDF 实际第 189 页／印刷第 185 页。A–D 为本计划演示拟写，不能标注为资料原有或官方真题。

### 3.4 题目必须具备的数据和审核门槛

每题保存：稳定题号、题目版本、篇章、知识点、原句与目标词位置、题干、选项及各自说明、唯一正确答案、解析、难度、内容标签、资料版本、PDF 实际页与印刷页、来源区块路径、审核状态。

- 引用的原句、词解及正确答案逐题对照来源。
- 单选题恰有一个正确答案；干扰项同类、具有具体误读原因，避免同义答案并列、语法不通或长度直接泄题。
- 同一原句兼具多种修辞时，改问具体证据或作用，不把其他成立的手法判错。
- 有实质分歧的说法并列保留在审核记录中，暂不作为唯一判分题；可以保留为阅读补充。
- 书中“历年考查提示”用于定位，不自动视为完整真题或官方评分。真实题号、题干与配分需要回查对应来源后才能使用相应标识。
- 题库状态分草稿、待核、已审核、暂下架。学生端只抽已审核且仍有效的题。
- 题目修订保留旧版本和已作答快照；纠错后不静默改写旧答案。影响评分的修订需标记受影响记录并单独修复。
- 答题前显示原句和必要语境；词解、解析及含答案的资料定位在提交后开放。

首个试点建议选《岳阳楼记》《论仁、论孝、论君子》《山居秋暝》，目标约 90–120 道已审核题，覆盖散文、语录及诗歌。此数字为开发目标，实际发布以审核通过的题目为准。随后按覆盖清单扩至 16 篇及手法专项，不先承诺固定总题量。

## 4. 多篇混合与最后冲刺

入口放在篇章页，并在首页增加“冲刺混练”。流程为：

选择篇章 → 自定义本组题数 → 选择范围与抽题方式 → 看本组预估分布 → 开始练习 → 按篇章查看本次薄弱点。

### 范围选择

- 多选篇章卡片，支持全选 16 篇、只选文言文、只选诗词、清空。
- 显示已选篇数、可用题数、到期题数，未具备已审核题目的篇章明确显示待开放。
- 每组题数沿用 1–100，提供 10／20／30 的快捷入口。
- 提供“全部题目”“只练错题”范围选项。手法附录作为明确开启的专项，不自动混入未选择的范围。
- 跨篇比较题只在涉及的所有篇章均被选中时出现。

### 默认抽题：均衡混练

篇章之间轮换分配，每篇内部先安排到期题，再安排较薄弱、未练过及其他可用题。

例如选《岳阳楼记》《出师表》《师说》做 20 题，题目足够时可分配为 7／7／6。哪篇得到余数按前次分配轮换；题量不足时将余额分给其他已选篇章。

可选“薄弱优先”：仍限定在选定篇章内，更多题量分给首次作答表现较弱的篇章。首发先确保均衡混练可靠，再加入该选项。

- 单组不重复同题凑数量；多个变式若测同一知识点，首版同组最多一题。
- 题数少于所选篇数时，提示本组不能覆盖全部篇章，允许继续，并在后续组优先补足未覆盖的篇章。
- 选定范围内没有到期题时，按当前范围补充；“只练错题”时不自动塞入新题。
- 未选篇章的复习日期保持原样，待选回或从日常复习入口继续。
- 本组开始后固定题目清单，题库更新、改偏好或转屏均不重排正在做的题。
- 结束页显示各篇题数、首次表现和待巩固知识点；当天重练成绩单独标注，避免混成长期掌握率。

## 5. 记忆规则保留

日常、单篇和多篇冲刺共用一份学习记录：按“用户＋稳定题目／记忆单元＋香港日期”只取当天第一次已提交的作答。

- 第一次正确也保存首次观察，避免后来答错被误认为第一次。
- 当天重复练习记录答案与练习次数，但不再次改变间隔、次日安排或累计错误次数。
- 当天巩固答对可以完成当天提醒，后续间隔保持不变。
- 次日首次作答才有资格再次更新记忆状态。
- 多个入口、刷新、重复点击、网络重试均不能产生重复首次记录。
- 文字题在提交时保留首次位置，完整自查后确定结果；跨天自查仍归原提交日期。
- 未来若增加同知识点的换题变式，共用记忆单元，避免仅换措辞就多计算一次。
- 账号切换后读取各自队列、草稿与首次记录，互不混用。

现有间隔规则作为基线迁移；不宣称为墨墨的专有算法，也不把同日反复练习的正确率展示为新的记忆能力。

## 6. iPad 页面与数据保存

### 页面布局

首页延续当前日期、左侧倒数、鼓励语和复习安排。篇章页支持多选，练习页保持大字和低干扰操作。

iPad 横屏在空间足够时左侧原文、右侧答题；竖屏和分屏窄窗口改为上下排列。较长原文可收起，展开状态在选择答案后保留。触控按钮留足间距，无悬停依赖，不播放点击后的整页淡入；可选打字题需验收软键盘下的提交与继续操作。

### 正式网页方案

建议将当前预览的页面、样式和行为迁为可维护的标准网页项目：组件化前端、题库内容包、本地数据库、云端账号与个人数据接口。保留现有 Flutter 工程，另设 `web-study/`，避免覆盖 Flutter 自身的 `web/` 目录。

共享题库只读发布；每位同学的答案、复习记录和收藏按账号隔离。账号方式暂按邀请制注册＋独立登录＋恢复入口规划，具体认证服务和托管账户在实施时依据实际人数与预算选定，本轮不创建服务或采购。

PWA 能力用于缓存与可选主屏幕入口，直接用 Safari 打开网址即能使用。首次联网下载了相关题库后，断网仍可完成已缓存题目；本地先保存，回到前台且网络恢复后补传，并显示“已保存到此 iPad／已备份”的状态。首次访问、登录及下载新内容仍需要网络。

浏览器本地存储可能被清理，因此个人历史增加云端备份与导出／恢复。只做 iPad 首发仍需要账号数据保护，但不以多设备同时使用为首版重点。参考：[MDN 离线能力](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Offline_and_background_operation)、[存储生命周期](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria)、[主屏幕安装](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)。

## 7. 已确认加入的四项功能

以下四项均由用户明确选择，属于正式交付范围。对应 UI 沿用当前配色、大字和粗体，适配 iPad 横屏、竖屏及分屏。

### 7.1 篇章薄弱地图

入口设在学习记录页，并在首页提供“看看哪里还不稳”。按篇章展示字词、句意、主旨、手法四个维度，可多选篇章筛选。

- 展示已练知识点／可用知识点、待巩固数量和到期数量，配文字标签，颜色作为辅助。
- 每个记忆单元取最近一次有效的“每日首次作答”作为当前表现依据，显示最近作答日期。当天再练不会把弱项刷成已掌握。
- 从未作答的项目标记“未评估”，不算错题。资料尚未覆盖的维度标记“题目待补充”，不算学生薄弱。
- 选择题的首次正确情况与文字题的自查状态分开显示；同时展示样本量，不将一次答对表述为已经掌握整篇。
- 待巩固采用最近一次每日首次答错／不会，或文字自查仍欠缺的既有记录；到期状态由现有复习安排决定，不另建一套评分或记忆算法。
- 点击具体格子可查看对应知识点并进入练习，自动带入所选篇章与能力范围，题数仍可自定义。

依赖：已审核题目的篇章和能力标签、稳定记忆单元、个人每日首次记录。

### 7.2 易混词义对照

入口设在篇章页；提交答案后，如果目标字词有已审核的对照内容，解析旁显示“看看这个字的其他用法”。

- 每张对照卡列出目标字词、篇章、完整必要原句、此处意思和辨别线索，高亮目标字词。
- 支持同字在不同篇章或同篇不同语境中的意义比较；不能只凭相同字形把通假、多音、不同词性或整词解释合并。
- 内容来自已核对的词解与辨析，保留各自定位。尚有分歧的解释不自动作为唯一判分依据。
- 从多篇冲刺进入时默认只比较所选篇章；其他篇章的扩展对照需明确选择后查看，不悄悄改变原练习范围。
- 对照阅读不记为答题，也不改变曲线；可点“练习这些用法”进入现有选择题流程，并遵守每日首次规则。
- 横屏可并排比较，窄窗口改为上下卡片，避免长原句被挤压。

依赖：带原句锚点的词义记录、审核后的易混关系、所选篇章范围。先为三篇试点建立对照组，再随十六篇题库扩展。

### 7.3 收藏与题目报错

收藏和报错是两个明确分开的操作，收藏不代表作答错误，报错也不直接改写答案或记忆记录。

收藏：

- 作答页与解析页均可收藏／取消收藏，操作保留当前选择、输入草稿、滚动和原文展开状态。
- 在个人收藏页按篇章、能力筛选，可对选中的收藏题进行混练或快速回顾。
- 收藏跨登录恢复，按账号隔离；离线操作先保存在 iPad，联网后补传。
- 收藏关联稳定题目号；修订后展示已更新状态，下架题保留收藏说明但不进入新的判分练习。

报错：

- 支持“题干或原文错字”“答案可能有误／存在多解”“解析问题”“来源页码问题”，可补充文字说明。
- 自动附带题号、题目版本、篇章和来源定位；若已提交答案，可附这一次提交的答案，供维护者复现。
- 断网显示“待发送”，联网后补送；提交完成显示“已收到”。用户可查看自己提交的反馈及“处理中／已修正／说明已回复”等实际处理状态。
- 维护者获得简洁的报错处理入口，按来源复核后修订或暂下架。学生的一次报错不会自动改变全体同学的判分结果。
- 题目修订保留旧版与历史答案。确认评分有误时，明确处理受影响的记录，并告知更正情况。

依赖：稳定题目版本、个人收藏记录、报错记录及维护者处理权限；网络补送须防止重复。

### 7.4 考前快速回顾

首页提供固定入口，日常也可使用。可多选篇章，并选择“薄弱重点”“我的收藏”或两者合并。

- 优先列出所选范围内到期或最近首次答错的知识点，再补充收藏，按记忆单元去重。
- 每张卡只呈现关键原句、准确词义／核心理解、一个常见误区，并可展开必要讲解和来源。
- 切换卡片、展开答案、点击“看过了”仅记为浏览，不计答对、不提升掌握状态、不改变记忆间隔。
- 如需检查自己是否记住，点击“转为练习”，继续使用现有题数与每日首次作答规则；浏览记录和作答记录分别保存。
- 没有个人薄弱记录时，明确显示“暂无个人薄弱记录”，可改看已选篇章的审核重点；不伪造薄弱诊断。
- 手法和比较内容只采用已有审核知识点，不在临考时临时生成未经核对的新解释。
- 可暂停后继续，题目和知识点更新时保留位置或明确提示内容已更新。

依赖：薄弱地图的筛选逻辑、收藏记录、审核后的知识点摘要、篇章范围与题目版本。

### 7.5 功能之间的衔接与候选范围

主流程：篇章薄弱地图找出问题 → 易混词义对照帮助理解 → 收藏重点或报告疑点 → 考前快速回顾集中重温。任一处选择正式作答，都进入同一套练习与每日首次记录。

“一键回看资料”继续作为题目溯源的基础能力。此前提出的“保存冲刺组合／分享组合”和“猜对／不确定”未被本次选择，保留为候选，不列为本轮必做。

首版不加入强制每日目标、排名、公开成绩或每题 AI 长对话，以保留当前简洁练习流程。

### 必须验证的行为

1. 原功能：默认选择题、可选打字题、1–100 自定义题数、首次锁定、解析后继续、草稿、记录、倒数、字号及无点击闪烁。
2. 范围：未选篇章不会混入；跨篇题必须满足全部篇章范围；只练错题不补新题。
3. 数量：不重复凑数；题量不足有说明；题数少于篇数时明确覆盖范围并轮换。
4. 曲线：首次对后又错、首次错后反复练、香港跨日、跨入口、自查跨日、重复请求，均符合一次首次记录。
5. 多用户：账号 A 的答案、收藏、草稿、到期列表和本地缓存不泄入账号 B；账号恢复仍能找回自己的进度。
6. 内容：来源区块和 PDF 位置一致，题目版本固定，未审或下架题不进入新队列，现有作答快照保留。
7. iPad 实测：长原句、长选项、横竖切换、分屏、软键盘、暂停与断网恢复均可完成完整练习。
8. 薄弱地图：从未练过和题库未覆盖分别显示；当天重复作答不刷高表现；文字自查与选择题正确性分开；地图入口保持篇章和能力范围。
9. 易混对照：每种意义保留原句和来源；不同词性、通假和多音不错误合并；阅读不改曲线；从冲刺进入时不自动跨出已选范围。
10. 收藏报错：收藏不影响当前答案或记忆记录；账号恢复可取回；离线补传和重复点击不产生重复反馈；未核实的报错不直接改动判分；修订保留历史快照。
11. 快速回顾：薄弱与收藏去重；无记录有真实空状态；浏览、展开、“看过了”均不生成作答或曲线更新；转练习后沿用每日首次规则。
