## 1. 要達成的結果

每題都能回答：考甚麼、適合甚麼訓練、答案憑甚麼成立、三個錯項為何可能被選、各自如何被原文排除、與其他題有何不同用途。

維持指定篇章四選一。改善的核心是讓選項真正考查理解；保留有用途的基礎題，不一律加難。難度來自詞義、條件、因果、動機、手法作用和跨句關係的辨別，不靠荒謬選項、冷僻常識、繞口句或刻意多解。

本輪範圍：材料、題幹、正解、每個錯項、整组选項、解析、重複題取捨及必要 App 顯示。沿用使用者指定文本；四選一練習不冒稱正式試卷或完整書面作答訓練。方法卡與歷屆完整映射承接舊計劃，但不阻塞已確認問題的修訂。

## 3. 每題具體怎樣改

| 部分 | 檢查及改法 | 必留證據 |
|---|---|---|
| 訓練用途 | 指定基礎鞏固、誤解辨析、跨句整合、手法／比較等用途；写一句「答對必須分清甚麼」及必要操作 | 目標、先備知識、提示條件及適用限制；不虛構DSE等級 |
| 材料 | 題幹所問原句必須出現在必要語境或有清楚篇章定位；刪無關冗文，保留否定、轉折、條件 | 精確原句、來源版本、實際PDF頁／印刷頁及blockPath |
| 題幹 | 指明人物、句段、時間與比較維度；不先公布答案，不用「最恰當」掩蓋兩個成立答案 | 一個主要目標，明確判斷標準 |
| 正解 | 先寫原文如何支持結論，再寫選項；範圍不能超過來源 | 原句→白話意思→答案的簡短論證 |
| 三個錯項 | 每項有與文本相關的吸引點、具體誤讀、排除依據、補救方向；不靠極端詞湊錯 | 逐項記錄，無學生資料時標為命題假設 |
| 整組選項 | 同一問題、同一比較維度，語法和信息量相稱；排除同義重複、兩項同時成立、正解固定最長或唯一正常 | 為四項各找最強文本辯護，記下排除或保留理由 |
| 解析 | 先說具體意思，再指出原句及推理；所選錯項解釋清楚「哪部分看似合理、錯在哪一步」 | 主解析和逐項理由分開，不以重述選項充數 |
| 題組及重複題 | 檢查鄰題洩題、換字重複、答案位置模式；保留有間隔複習或對照用途的變式 | 同類題關係、獨特訓練價值、保留／合併理由 |

三個錯項不必機械地分屬三種錯誤，但不能只是同一錯法的換字填充。湊不出三個有作用的錯項時，重構題幹／比較維度；仍不成立則暫停進入新題組，保留原題歷史。

## 4. 優先次序與具體問題

1. **先處理會誤教的題目**：答案錯誤、材料錯配、多解、關鍵語境缺失、來源不足。不能用文筆改善抵銷這些問題。
2. **再處理無需理解就能猜中的題目**：荒謬錯項、離題、正解獨有長度／措辭提示、其他題洩題。
3. **補足學習回饋**：模板解析、三錯項共用理由、只下結論不解釋證據。
4. **調整全庫用途與重複度**：有用基礎題保留；無新增辨別價值的變式合併抽題或暫停新抽題，不刪舊記錄。

已知例子及本輪改法：

- `full-c-16-07-00-08`（青玉案）：錯項「只有直接描寫才可能塑造人物」「環境與人物形象在文學中不能相互關聯」可憑常識排除。重寫為同一原文中可混淆的描寫對象、人物形象或表達作用，讓學生依句子關係區分。具體新選項要核原文後定稿，不預先編造人物動機。
- `full-c-01-23-02-02`、`full-c-01-22-02-02`：所問「問孝於我」「見志不從」與顯示的「義以為質」材料未對齊。先修材料與目標字定位，再審答案和錯項；不只潤飾選項。
- `full-d-16-01`：展望作結是否限於正面、積極仍待補證；目前不直接宣判錯題。可改測有來源的具體例子或保持待來源，不能把爭議當成唯一判分依據。

## 5. 分階段執行

### A. 固定清單與審查底稿

保存當前題庫及來源雜湊，建立全2,134題清單和首批64題manifest。把60題作者審讀證據納入新底稿，但不複製Laya標籤作結論；舊24題對照來源保持。每題保留原版本、優先級、具體問題、處置及審查狀態。基線變了先比對差異，不覆蓋他人新改稿。

完成標準：每個ID有去向；原題與來源可還原；64題去重無誤，4題新增審讀清楚標示。

### B. 完成首批64題改前／改後包

按上述優先順序處理。30題錯項候選是主線，材料錯配先修；7題解析候選、5題材料候選及保留候選也逐項核對。新增4題完整審讀。來源有分歧的先留具體問題，其餘題照常完成，不等候全庫資料齊備。

每題交付：原題／新題、用途、改動理由、原文定位、四項理由、三錯項診斷記錄及五關審查。基礎題若已有合理錯項，只改解析或保留，不能為了湊改題數而重寫。先完成來源充分的稿，再做反駁式自檢。

完成標準：64題都有明確處置，並非要求64題全部重寫或全部上架。只有五關通過的稿可進入App試做；其餘列待修／待來源。這取代舊計劃單獨24題樣板階段。

### C. 接入題庫與必要的解析介面

依賴：B中對應題的內容關卡通過。走現有生成／核准分包流程，新增修訂層，不能只改生成後的bank.json。純解析、題面內容、啟用狀態分別記錄；一題同一批只遞增一次版本。

答題後按此順序呈現：**這題記住甚麼 → 正解及原文依據 → 你選的這項差在哪 → 其他選項（可展開）**。答對時顯示正解依據；沒有選項作答時不推測誤讀；提交前不顯示答案或作者標記。舊題欄位不足時保留可讀回退。

同一學習目標沿用ID／memoryId；若改成另一能力目標，另建ID並關聯舊題，不把舊記憶進度轉綁。選項重排後逐一核答案ID、解釋、高亮及索引。保留暫停題組快照、歷史題文和成績，不回算舊分數。暫停高風險題只影響新抽題。

完成標準：內容可重建、既有練習和歷史資料不回歸、窄屏和大字能讀；本地完成與正式部署分開。

### D. 逐批處理全庫餘下2,070題

首批64題處置後，餘下2,070題按篇章、考查目標與題族分組，每批約40–60題，寧可縮小批量也不以規則標記代替逐義審讀。先指定篇章，附錄另包；同源／同目標題一起比較，但每題每個選項仍各留結論。

每批輸出保留、修改、合併訓練、暫停新抽題、待來源清單，以及已處理／待處理／未解問題數。保留題也須有用途和來源理由。全庫最終覆蓋2,134題、8,536選項，其中6,402個錯項有逐項處置；目標改寫造成題數變動另記新舊ID，不靠刪題使清單看似完成。

既有歷屆94分題／22類考查僅作來源有據的操作對照，首批先做相關映射；不強迫每道字詞題對應一道真題。完整映射和6–10張方法卡是後續內容層，不延誤已知錯項修復。不作未核實的2027題型或出題概率聲稱。

### E. 有真實試做後再調整

收集題目版本、作答模式、首次接觸／重做、有無提示、各選項次數及學生理由。檢查錯項是否真的吸引目標誤讀、解析是否能幫助學生在另一題說明依據。沒有資料標為未實測，不以AI自評充當學生反應。

基礎題高正確率可以合理，無人選的錯項只觸發覆核，不能機械刪除。對不同版本、提示模式及小樣本分開解讀，不設定一個正確率門檻裁決全庫。教師覆核與學生試做是獨立狀態，不阻止先交付有據的修訂稿。

## 6. 五項准入要求

| 關卡 | 合格要求 |
|---|---|
| G1 來源 | 必要原文、版本和定位齊全；關鍵主張有依據，異解保留 |
| G2 唯一答案 | 四項逐一找文本辯護後，仍只有一項符合題幹標準 |
| G3 干擾項 | 三錯項各有具體吸引點、誤讀及排除理由；沒有荒謬湊數 |
| G4 真正測到目標 | 不能僅靠長短、極端詞、常識或鄰題提示繞過主要判斷 |
| G5 一致性 | 題面、正解ID、逐項解析、引文高亮、來源與版本相符 |

每關寫結論及證據，不能用平均分抵銷不合格。只有作者檢查時記 `author-self-check`；遮住答案再做也不稱真正盲審。狀態用待修、可試做、待來源；已有reviewed不能自動代表本輪通過。預期層次不等於實測難度。
