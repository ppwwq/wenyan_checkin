# 月下獨酌

[本篇核心](../chapters/essay-12.md) · [知識庫首頁](../README.md) · [跨篇比較](../topics/comparisons.md) · [異解與待核](../audit/REVIEW.md)

## 先回答這個問題

**詩中既說『三人』，為何仍是『獨酌』？**

月與影是詩人想像的伙伴；由無相親到邀月成三人，再承認月影不能真知己，寫出自我排解與孤獨交織的情緒。

## 全篇思路

1. 花間獨酌、無相親 → 邀月對影成三人
2. 月不解飲、影徒隨身 → 暫伴行樂
3. 歌舞同歡與醉後分散 → 永結無情遊、相期雲漢

## 最容易混淆

- 三人是詩人、月、影，不是三位實際友人。
- 歡樂是暫時寄託，不能據此抹去孤獨。
- 『無情遊』不是冷酷無情，須保留超越俗情及月影特性的解讀。

## 原文與語譯

### 原文第1組｜原文與語譯

<a id="k-2e7b064cbc6176f6"></a>
**原文：** 花間一壺酒，獨酌無相親。舉杯邀明月，對影成三人。月既不解飲，影徒隨我身。

<a id="k-c79e6b1c181cd4bb"></a>
**語譯：** 春夜花叢中放着一壺美酒，我自斟自飲，身邊沒有可以親近的友伴。我舉起酒杯邀請明月，對着自己的影子，湊成三人。可是月亮並不懂得飲酒的樂趣，影子也只是空隨我的身體。


### 原文第2組｜原文與語譯

<a id="k-1b54b3faf6cf59ae"></a>
**原文：** 暫伴月將影，行樂須及春。我歌月徘徊，我舞影零亂。醒時同交歡，醉後各分散。

<a id="k-d7b60faf2e402a8e"></a>
**語譯：** 姑且暫時以月亮和影子為伴，趁着春夜良辰美景，及時行樂。我高歌，月亮彷彿為我徘徊、傾聽；我起舞，影子也跟着舞動，搖曳散亂。清醒時我們共同歡樂，醉倒後便各自離散。


### 原文第3組｜原文與語譯

<a id="k-1aed7ddf3f73c91b"></a>
**原文：** 永結無情遊，相期邈雲漢。

<a id="k-4cf8d4270b2efe65"></a>
**語譯：** 願永遠與月亮、影子結伴，作忘卻世情的逍遙遊，相約在遙遠銀河再會。

## 主旨與思想

### 一句話題旨

<a id="k-f362170f7d9bbd38"></a>
**題旨：** 月下獨酌


### 李白｜唐代｜五言古詩

<a id="k-3829e0bf8776948e"></a>
**內容：** 現實中沒有知己，詩人想像月影相伴，在孤獨與自我排遣之間起伏。


### 理解關鍵

<a id="k-477daa3ea9e1ca6f"></a>
**內容：** 我、月、影是想像中的三人。「暫」與「永」分別指眼前相伴和未來願望。


### 句段核心：原文第1組｜原文與語譯

<a id="k-8b58f93dd3c54050"></a>
**重點：** 由獨飲到想像三人，再發現月影不能相知。


### 語譯

<a id="k-01e0f65878dd11b1"></a>
**內容：** 「三人」是我、月、影，沒有真正來了兩位朋友。邀月的熱鬧與不解飲的失落，正構成情感起伏。

<a id="k-1512e31075fd4eea"></a>
**內容：** 「暫」限定眼前相伴的時間；我歌我舞顯出主動排遣。月影的回應是想像，不能據此說現實孤獨已完全解除。

<a id="k-bacc894d467557d0"></a>
**內容：** 「無情」可以指忘卻世情，也可從月影沒有感情理解。它不等於冷酷無情；「相期」仍是願望。


### 句段核心：原文第2組｜原文與語譯

<a id="k-816b46e5fb18a764"></a>
**重點：** 姑且行樂，暫得歡愉，醉後卻要分散。


### 句段核心：原文第3組｜原文與語譯

<a id="k-e9f9522a19230db4"></a>
**重點：** 以永結和再會的願望，將想像推向遙遠天際。


### 主旨、人格與人生態度

<a id="k-fc8b7b24a756645f"></a>
**內容：** 詩人借春夜花月間獨飲，邀月影共飲、歌舞、相約同遊，抒發懷才不遇、抑鬱孤獨、知音難覓的心情，又企求解脫，不願被愁思束縛。現實孤獨、局部歡樂、自我排遣的努力與排遣是否成功，屬不同層次。

<a id="k-7bc5cd7e2090400c"></a>
**內容：** <b>及時行樂</b>：「行樂須及春」，明知月影不能真正相知，仍暫以之為伴、且歌且舞，不辜負美好時光。<b>豁達超脫</b>：相約月影在遙遠銀河遊歷，超越人世得失，自我紓解。<b>高潔自持、鄙棄世俗</b>：月影是美好事物和感情寄託，與之親密歡洽，反襯人間知音難覓，也可表現對現實社會的憤懣、厭惡及遺世獨立的品格。

<a id="k-e8bbc0db22159a78"></a>
**內容：** 「詩仙」的作品依據有兩層：邀明月、對影成三人，把無伴冷清想成奇妙熱鬧，浪漫而富想像；永結無情遊、相期雲漢，表現道家順其自然、適性、忘情超脫的精神。不能只列稱號而沒有本詩例證。


### 理解補充

<a id="k-f883b13a47780b9e"></a>
**內容：** 全詩是否已排遣憂愁，可以有不同解讀。可由月影終不能相知、醉後分散，說憂仍存在；也可由及春行樂、永結無情遊，說詩人主動自解。兩種立場都要貫通全詩，不能只摘一句便斷定。


### 本句的理解要點

<a id="k-0eb9e282fb092b33"></a>
**內容：** 「三人」是我、月、影，沒有真正來了兩位朋友。邀月的熱鬧與不解飲的失落，正構成情感起伏。
「暫」限定眼前相伴的時間；我歌我舞顯出主動排遣。月影的回應是想像，不能據此說現實孤獨已完全解除。
「無情」可以指忘卻世情，也可從月影沒有感情理解。它不等於冷酷無情；「相期」仍是願望。


### 古詩、律詩、絕句與排律

<a id="k-40da2a6def439e96"></a>
**內容：** 古詩在句數、平仄和對仗方面較自由；律詩通常八句，絕句四句，排律在律詩格律基礎上延長至十句或以上。不能單憑每句五字或七字判定體裁，還要核對句數與格律。


### 被動句

<a id="k-fc83a80239eb0faa"></a>
**內容：** 被動句中主語是動作的承受者。文言可用「見」「於」「為……所……」等標誌，也可不帶標誌而由語意判斷。不能看見「於」或「為」就直接判作被動，須查明動作由誰發出、誰承受。


### 押韻與韻腳

<a id="k-20f1a16691c49129"></a>
**內容：** 韻腳是詩句末尾用來押韻的字。律詩一般偶數句押韻，首句可入韻，也可不入韻；不能把每句最後一字都當作韻腳。判斷古詩用韻要留意古音及韻部，不能只按現代普通話讀音。

## 結構與脈絡

### 內容線索

<a id="k-b6da4e1c17706f07"></a>
**內容：** 無伴→邀月影→發現不能相知→暫且行樂→醉散→相約再遊


### 1—2：花間獨酌

<a id="k-35f1bbd53d508c6a"></a>
**行動、場景、情緒與作用：** 繁花盛開，詩人獨自斟飲，無人相伴，孤獨寂寞。


### 3—4：邀月對影

<a id="k-caa6e29ba3720252"></a>
**行動、場景、情緒與作用：** 想像邀月影對飲，成三人，冷清轉熱鬧，似找到伴侶而獲慰藉；熱鬧出於想像，更顯現實無友。


### 5—6：月影不解

<a id="k-8582ecbadbd9e234"></a>
**行動、場景、情緒與作用：** 月不懂飲酒，影只隨身而動，兩者不識人心、不解人意，詩人回落到失落、孤單與無奈。


### 7—8：暫伴及春

<a id="k-d9dd32f678a6fbe5"></a>
**行動、場景、情緒與作用：** 不願辜負春夜良辰，姑且以月影為伴，及時行樂，自我開解；既可見曠達，亦可見聊勝於無、更添苦悶。


### 9—10：歌舞共歡

<a id="k-2c3e1c8414c73ae9"></a>
**行動、場景、情緒與作用：** 月彷彿傾聽、影彷彿伴舞，場面熱鬧，情緒上揚、自得其樂；此為局部狀態，現實知己並未出現。


### 11—12：醒歡醉散

<a id="k-30a27d956f2a8ceb"></a>
**行動、場景、情緒與作用：** 清醒時同歡，醉倒後不省人事、與月影離別；歡樂不能長久，轉為失落惆悵。亦可依2023接受角度解作不執着聚散。


### 13—14：相期雲漢

<a id="k-8d1254829d8c18bc"></a>
**行動、場景、情緒與作用：** 想像與月影永遠忘情同遊，相约銀河，失落化期盼，自我開解、曠達超脫；另一角度則認為只是對現實無法排憂的無奈逃避。


### 章末串連｜重建全文

<a id="k-f451457dc5b19953"></a>
**內容：** 全詩反覆在獨與伴之間移動，想像既帶來安慰，也反照真實孤獨。


### 由一到三

<a id="k-65014d4b816e5441"></a>
**怎樣連起來：** 「無相親」在先，舉杯邀月、對影在後；缺少知己才需要想像友伴。


### 歡聚有裂縫

<a id="k-bedbdb62184c9c44"></a>
**怎樣連起來：** 月不解飲、影徒隨身，揭示伴侶不能回應；暫伴行樂遂帶自解意味。


### 由散到遠約

<a id="k-915b551fbd5f7c0f"></a>
**怎樣連起來：** 歌舞暫聚，醉後仍散；相期雲漢把相伴延至超越現實的想像，留曠達與孤寂兩層餘味。


### 關鍵轉折

<a id="k-b0cd8771f0f48ffd"></a>
**怎樣連起來：** 「不解」「徒」指出想像伴侶的限制，「暫」承認歡聚短促，「永結」「相期」才把希望推往超越現實的境地。


### 兩層結尾

<a id="k-4107746e5dca0f88"></a>
**怎樣連起來：** 若着眼相期雲漢，可見自我超越；若着眼現實仍無相親，可見孤獨未解。兩層理解各有全詩依據。


### 律詩四聯

<a id="k-c6be6290a616ef8d"></a>
**內容：** 律詩通常有八句，每兩句為一聯：第1–2句是首聯，第3–4句是頷聯，第5–6句是頸聯，第7–8句是尾聯。頷聯和頸聯通常要求對仗。判斷聯次須從全詩第一句數起，不能把題目節錄的次序當成全詩句次。


<a id="technique"></a>
## 手法與賞析

### 字詞、語法與煉字

<a id="k-1320bf384adc8e58"></a>
**內容：** 「無情」亦可反襯「我」有情：月影不識人意，我仍願邀其再遊，顯出深情與對陪伴的渴望。「徒」突顯無法改變事實的無奈；「暫」的悲哀讀法與享受當下讀法須依全篇立場論證，不混成唯一詞義。


### 想像、構思精奇

<a id="k-57295f420f8c3904"></a>
**具體例子與效果：** 邀月對影成三人；月聽歌、影伴舞；醒同歡、醉分散；最後相期雲漢。從眼前邀伴推展到未來相約，意境愈轉愈奇，仍圍繞「獨」。


### 擬人

<a id="k-b587e6e19c29764e"></a>
**具體例子與效果：** 月影可受邀、傾聽、共舞、交歡、分散、相期；「月既不解飲，影徒隨我身」亦從人的知覺與回應能力描述月影。把物賦予人的動作、思想感情，使冷清場面在想像中轉熱鬧、生動。另形容為知己共聚、「把酒談天」；談天是對想像場面的展開，原詩未明記交談內容。


### 樂景反襯哀情／以景襯情

<a id="k-2403f87171e6e733"></a>
**具體例子與效果：** 花間月下、良辰美景、美酒當前，本宜歡暢，卻無友分享；景愈美好，孤寂苦悶愈鮮明。


### 以熱鬧反襯孤獨／以物襯情

<a id="k-cc6497719b93e9ce"></a>
**具體例子與效果：** 想像三人既歌且舞，熱鬧與現實獨酌形成反差；沒有真正知己，愈熱鬧愈顯孤獨。


### 借景、借事、借物抒情

<a id="k-211d7c4cd2ce21ce"></a>
**具體例子與效果：** 花月之景襯孤寂；獨酌、邀伴、歌舞之事抒知己難求與自解；月影之物暫伴、醉後仍散，寄無奈。角度可交疊，不必互斥。


### 抑揚交錯、一波三折

<a id="k-80914b4d1ac91b7c"></a>
**具體例子與效果：** 無伴→似有伴→月影不解→暫伴行樂→醉散→永結相期，悲喜交錯，心境往返「獨／不獨」，結構自然兼有跳躍感，引人入勝。


### 呼應一

<a id="k-38c9ddc80a01d77c"></a>
**具體例子與效果：** 「花間一壺酒」與「行樂須及春」相應，春花盛放、及時行樂。


### 呼應二

<a id="k-deb565a7af9246ef"></a>
**具體例子與效果：** 「行樂須及春」與「我歌月徘徊，我舞影零亂」相應，以歌舞具體說明行樂。


### 呼應三

<a id="k-adecc23a2f1fa1b5"></a>
**具體例子與效果：** 「月既不解飲，影徒隨我身」與「永結無情遊」相應，連接月影不解人意與無情交遊。


### 對偶

<a id="k-111fe0c8feff93a4"></a>
**具體例子與效果：** 「我歌／我舞、月／影、徘徊／零亂」；「醒時／醉後、同／各、交歡／分散」，結構整齊，節奏相稱。


### 對比

<a id="k-7e367915cd9dbbe3"></a>
**具體例子與效果：** 醒與醉、喜與悲、聚與散相對，使歡後孤獨鮮明；2023另一角度可分析不執着離合的自解。


### 託物寄志、象徵

<a id="k-8af6d2acd233aa5c"></a>
**具體例子與效果：** 月影象徵美好，寄寓思想感情，與之為友象徵鄙棄凡俗、孤清高潔。


### 誇張筆法

<a id="k-37819a500e16fe66"></a>
**具體例子與效果：** 把月影寫成同宴友伴，想像超越現實，重點是想像超越現實，不能把「三人」當真實人数。


### 雙聲

<a id="k-a6565739006bc911"></a>
**具體例子與效果：** 「零亂」兩字聲母相同，為音韻觀察，與對偶的句法對稱分開。


### 語言質樸而精鍊

<a id="k-679a260b341f689c"></a>
**具體例子與效果：** 淺白如話，少艱深字，沒有典故堆砌、辭藻雕飾，情感率真自然；首四句一氣呵成，「月、影、我」反覆而不呆板，像自然說話。「一壺、既、徒、暫、無情」皆可細析，平易不代表沒有煉字。


### 手法與例證

<a id="k-f957b67d61502565"></a>
**內容：** 詩題是「獨酌」，詩中卻想像出月、影兩位伴侶。人數由一變三，現實的孤獨仍未消失；正因真實無人可伴，這場想像的歡聚才格外動人。


### 對比與襯托

<a id="k-2d87939bcd126238"></a>
**內容：** 對比把兩方並置，突出差異，兩方都參與表意；襯托有主次，以陪襯的一方突出主要對象。分析須指出哪兩方、在哪一方面形成關係，以及這個關係如何支持文意。


### 借代

<a id="k-94e9f49a8b88063f"></a>
**內容：** 借代利用事物之間的關聯，以特徵、部分、材料或相關事物代替本體。比喻依靠相似，借代依靠關聯。答題要說明代指對象及兩者關係。

## 比較與應用

### 跨篇比較

<a id="k-993802844ba2740d"></a>
**內容：** 《月下獨酌》與《登樓》都用美好花景襯托心事：李白苦於無相親，杜甫傷於萬方多難。結尾則不同：李白把相伴寄於雲漢的想像，杜甫以梁甫吟自況，仍想濟世卻未能施展。

<a id="k-a885f120df39846f"></a>
**內容：** <b>與《念奴嬌・赤壁懷古》</b>：可比较失意处境、月等自然意象、飲酒及精神自解；須分李白邀月影的想像交遊與蘇軾懷古、自傷、酹江月的過程。<b>與《聲聲慢・秋情》</b>：可比較尋求慰藉的方式與結果；李白主動想像同伴、心情反覆，李清照尋覓寄託而不得，酒、雁等又增愁。詳細各篇證據另見相應篇章及考卷卡，不以「都借酒消愁」抹平差異。
