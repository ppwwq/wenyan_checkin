# 魚我所欲也

[本篇核心](../chapters/essay-02.md) · [知識庫首頁](../README.md) · [跨篇比較](../topics/comparisons.md) · [異解與待核](../audit/REVIEW.md)

## 先回答這個問題

**為甚麼明知義重要，仍會失去本心？**

文章先用魚與熊掌的取捨說明價值有高下，再指出生命與義不能兼得時應取義；由拒絕侮辱之食轉到接受萬鍾，揭示物欲會令人放棄原來的道德判斷。

## 全篇思路

1. 魚與熊掌 → 生與義：建立取捨原則
2. 欲生惡死仍有界限 → 行人乞人拒食：證明本心可見於常人
3. 過去拒絕、現在接受 → 利益蒙蔽 → 不失本心

## 最容易混淆

- 捨生取義有『二者不可得兼』的前提，不是輕視生命。
- 關鍵是受取是否合義，不是食物少便高尚、俸祿多便有罪。
- 『妻妾之奉』『鄉為身死而不受』保留異讀；不要用一種解釋排斥另一種。

## 原文與語譯

### 第1段｜原文與語譯 1

<a id="k-a5934b0412d67232"></a>
**原文：** 孟子曰：「魚，我所欲也，熊掌，亦我所欲也；二者不可得兼，舍魚而取熊掌者也。生亦我所欲也，義亦我所欲也；二者不可得兼，舍生而取義者也。生亦我所欲，所欲有甚於生者，故不為苟得也；死亦我所惡，所惡有甚於死者，故患有所不辟也。

<a id="k-07e79e1aa9b5fbbd"></a>
**語譯：** 孟子說：「魚，是我想要的，熊掌，也是我想要的；如果這兩者不能同時得到，我就捨棄魚而選擇熊掌。生命是我想要的，大義也是我想要的；如果兩者不能同時得到，我就捨棄生命而選擇大義。生命是我想要的，然而我還有比生命更想要的東西，所以我不會苟且偷生；死亡是我所厭惡的，然而我還有比死亡更厭惡的事情，所以有的禍患我不躲避。


### 第1段｜原文與語譯 2

<a id="k-37eb8f9a8d07e595"></a>
**原文：** 如使人之所欲莫甚於生，則凡可以得生者，何不用也？使人之所惡莫甚於死者，則凡可以辟患者，何不為也？由是則生而有不用也，由是則可以辟患而有不為也，是故所欲有甚於生者，所惡有甚於死者。非獨賢者有是心也，人皆有之，賢者能勿喪耳。

<a id="k-1c0b1b60755778af"></a>
**語譯：** 如果人們沒有比生命更想要的東西，那麼凡是可求得生存的手段，有甚麼不可用呢？如果人們沒有比死亡更厭惡的事情，那麼凡是可以躲避禍害的事情，有甚麼不可做呢？依循這些方法就可以生存，卻有人不使用，依循這些方法就可以躲避禍患，卻有人不願意這樣做，因此人們有比生命更想要的東西，人們有比死亡更厭惡的事情。不僅僅賢人有這種本性，人人都有這種本性，只不過賢人能夠保持不喪失罷了。


### 第2段｜原文與語譯 1

<a id="k-04cd8a6b390fef7b"></a>
**原文：** 一簞食，一豆羹，得之則生，弗得則死。嘑爾而與之，行道之人弗受；蹴爾而與之，乞人不屑也；萬鍾則不辯禮義而受之。萬鍾於我何加焉？為宮室之美、妻妾之奉、所識窮乏者得我與？

<a id="k-d74ecb2a58884716"></a>
**語譯：** 一竹筐食物，一木碗湯羹，得到它們就能生存，得不到它們就會餓死。大聲地呼喝着給人吃，路人不會接受；用腳踐踏着給人吃，乞丐也不屑接受；萬鍾的俸祿卻不分辨是否合於禮義就接受了。萬鍾的俸祿對我有甚麼增益呢？為了得到華美的居室、妻妾的侍奉、讓我認識的窮困者感激我的接濟嗎？


### 第2段｜原文與語譯 2

<a id="k-c831ddd81f1d7295"></a>
**原文：** 鄉為身死而不受，今為宮室之美為之；鄉為身死而不受，今為妻妾之奉為之；鄉為身死而不受，今為所識窮乏者得我而為之，是亦不可以已乎？此之謂失其本心。」

<a id="k-41054b70107ab738"></a>
**語譯：** 從前寧願死都不接受的，現在卻為了華美的居室而接受了；從前寧願死都不接受的，現在卻為了妻妾的侍奉而接受了；從前寧願死都不接受的，現在卻為了讓我認識的窮困者感激我而接受了，這些做法不可以停止嗎？這就叫喪失了人的本性。」

## 字詞與句式

### 不屑

<a id="k-0320f7ad30131ae6"></a>
**詞義：** 認為不值得接受

> 語境：一簞食，一豆羹，得之則生，弗得則死。嘑爾而與之，行道之人弗受；蹴爾而與之，乞人不屑也；萬鍾則不辯禮義而受之。萬鍾於我何加焉？為宮室之美、妻妾之奉、所識窮乏者得我與？

<a id="k-5a0034b5d1084a66"></a>
**原句定位：** 乞人不屑也

**意思與必要辨析：** 認為不值得接受。路人面對呼喝、乞人面對踐踏，都拒絕受辱。


### 不辟

<a id="k-dfbe3c62e25f1b8a"></a>
**原句定位：** 故患有所不辟也

**意思與必要辨析：** 不躲避，辟通避；有所不辟不等於全不避。


### 之

<a id="k-fa83bb6de135186e"></a>

## 主旨與思想

### 一句話題旨

<a id="k-9be1b0f85dfc0fd4"></a>

### 孟子｜戰國｜論說文、語錄體選段

<a id="k-a2f03759b316b711"></a>
**內容：** 生命和道義不能兼得時取義；人人有本心，卻須警惕物欲使它喪失。


### 理解關鍵

<a id="k-1f17a68541cbc147"></a>
**內容：** 問題在不辨禮義便接受，不是所有俸祿和物質享受都有錯。

<a id="k-32eed48bca7882cb"></a>

<a id="k-4be0fe6ce9f6532a"></a>
**內容：** 魚與熊掌對應生與義；論點成立的條件是二者不可兼得。賢者能保存本心，不等於只有賢者才有本心。

<a id="k-dd711da61a884876"></a>
**內容：** 一簞食、一豆羹雖少卻能救命；萬鍾雖多卻不是救命所必需。為享受和感激而不辨禮義，才是所批評的取捨。

<a id="k-c24c6b7fbafc8e94"></a>

### 句段核心：第2段｜原文與語譯 2

<a id="k-5c388a3688f9c077"></a>
**重點：** 從拒食到受祿，以今昔反差揭露本心的喪失。


### 主旨、本心、義利與適用條件

<a id="k-efeea8fa8d799d87"></a>
**內容：** 中心是義比生命重要，當兩者不能兼得，應捨生取義；人皆有重義的本心，要保存它，警惕物欲使人不辨禮義。文章承認生命是「我所欲」，並非認為生命無價值，也不是凡有危險都須赴死。「所惡有甚於死者」指不義或失義比死亡更可厭惡；只有守義與保命不能兼得時，才形成文中的取捨。

<a id="k-d9caf3c1a26a3c07"></a>
**內容：** 人人都有重義的本心，但有本心不等於每次都能守住。賢者可貴之處是「能勿喪」：在生死或物欲壓力下，仍保有分辨禮義的能力。

<a id="k-c06a306c27224335"></a>
**內容：** 「所識窮乏者得我」寫希望受助者感激自己；問題在於為了這種回報而不辨禮義地受取萬鍾。批評的是取利時放棄原則，不是把幫助貧困者本身說成錯誤。


### 理解補充

<a id="k-af358472b9da1d98"></a>
**內容：** 「妻妾之奉」可理解為妻妾侍奉自己，也有供養妻妾之解。「鄉為身死而不受」按前文可連嗟來之食，也有連萬鍾的讀法。基本理解不變：過去重義，如今為利益放棄禮義，顯出本心失守。

> **異解／待核：** 明列妻妾之奉與鄉為身死而不受的兩解，不強判單一語譯；共同的今昔失義由所列題覆蓋。


### 被動句

<a id="k-1877d5d1dd0eab07"></a>
**內容：** 被動句中主語是動作的承受者。文言可用「見」「於」「為……所……」等標誌，也可不帶標誌而由語意判斷。不能看見「於」或「為」就直接判作被動，須查明動作由誰發出、誰承受。


<a id="structure"></a>
## 結構與脈絡

### 內容線索

<a id="k-e90d257e3f311843"></a>
**內容：** 魚熊掌類比→欲生惡死推論→人人有本心→拒食與受祿→鄉今對比


### 建立尺度

<a id="k-94186d779ebb5c19"></a>
**原句依據：** 二者不可得兼，舍魚而取熊掌者也。

**如何支持主旨：** 由熟悉的飲食取捨，類比生命與義不能兼得時取義。


### 兩面推論

<a id="k-a718fbabe16e6476"></a>
**原句依據：** 所欲有甚於生者；所惡有甚於死者。

**如何支持主旨：** 從欲生、惡死兩面說明，人仍有比求生避死更高的原則。


### 反設檢驗

<a id="k-fff87118ed146def"></a>
**原句依據：** 何不用也？……何不為也？

**如何支持主旨：** 若生命最高、死亡最可惡，理應不擇手段；實際卻有所不為，反證義更重要。


### 普通人亦能守義

<a id="k-1a0ae8d84d6f373f"></a>
**原句依據：** 行道之人弗受；乞人不屑也。

**如何支持主旨：** 連飢餓的路人、乞人都拒絕受辱，顯示本心並非賢者獨有。


### 物欲使本心失守

<a id="k-13580cf34750fd43"></a>
**原句依據：** 萬鍾則不辯禮義而受之；鄉……今……

**如何支持主旨：** 先列受祿的誘惑，再揭示今昔選擇矛盾，歸結為失其本心。


### 論證推進：由取捨到本心

<a id="k-dc4fe0a128e1d226"></a>
**內容：** 「人皆有之，賢者能勿喪耳」承上啟下：上承人人有重義本心，下啟能否保存的考驗。第二段不是另起無關故事，而是把抽象原則落實到拒食與受祿。


### 章末串連｜重建全文

<a id="k-bf96c6f830d8bcac"></a>
**內容：** 從取捨的原則，到生死考驗，再到日常物欲，全文追問同一件事：是否仍以義作判斷。


### 提出原則

<a id="k-a275f96472d9a790"></a>
**怎樣連起來：** 魚與熊掌難兼得，先示範取較可貴者；轉到生與義，提出捨生取義。


### 證明能做到

<a id="k-51b9437c73ca8254"></a>
**怎樣連起來：** 欲生惡死都有更高界限；行人、乞人寧可不受侮辱之食，顯示人人有本心。


### 揭示失守

<a id="k-43c08ff856356eac"></a>
**怎樣連起來：** 昔日寧死不受，如今為宮室、妻妾或感激而受萬鍾，前後反差證明本心會被物欲蒙蔽。


<a id="technique"></a>
## 手法與賞析

### 食物與俸祿

<a id="k-e529a68ec860c51a"></a>
**雙方表現與依據：** 「一簞食，一豆羹」雖少卻能救命；「萬鍾」雖多，所求卻是宮室、妻妾與他人感激。

**作用：** 對照生存所需與物質誘惑，凸顯受取是否合義才是關鍵。


### 不同人物

<a id="k-f5809b07fe6fd745"></a>
**雙方表現與依據：** 「行道之人弗受」「乞人不屑」；有人卻「不辯禮義而受之」。

**作用：** 地位卑微者也能守義，受厚祿者反失本心；不能以地位判定道德。


### 同一人的今昔

<a id="k-f63ce64ab00d6b14"></a>
**雙方表現與依據：** 三組「鄉為身死而不受，今為……為之」。

**作用：** 昔日寧死不受，今日因物欲接受，揭示價值選擇前後矛盾。


### 反問與設問

<a id="k-85fc1abbea976258"></a>
**內容：** 反問用疑問形式表達已確定的意思，通常不需回答，以加強語氣；設問先提出問題再作回答，引導讀者理解。判斷時看句子在上下文的作用，不能只憑問號。
