# 山居秋暝

[本篇核心](../chapters/essay-11.md) · [知識庫首頁](../README.md) · [跨篇比較](../topics/comparisons.md) · [異解與待核](../audit/REVIEW.md)

## 先回答這個問題

**清幽山景怎樣支持『自可留』的選擇？**

雨後秋晚的清新山景，配以浣女、漁舟的生活動態，形成清幽而有生氣的山居世界；尾聯反用典故，表達留居的意願與志趣。

## 全篇思路

1. 首聯交代雨後秋晚 → 頷聯月照泉流
2. 頸聯先聞竹喧、見蓮動，再知人舟 → 山居生活
3. 尾聯反用招隱士 → 王孫自可留

## 最容易混淆

- 『空山』不等於無人，後文正有人活動。
- 以動襯靜須指出局部聲動怎樣突出整體清幽。
- 春芳歇不是全詩悲秋的證據；末聯着重山中可留。

## 原文與語譯

### 原文第1組｜原文與語譯

<a id="k-93ea88f3cd2446f3"></a>
**原文：** 空山新雨後，天氣晚來秋。明月松間照，清泉石上流。

<a id="k-d91a1a5c3f844ddc"></a>
**語譯：** 清幽空曠的山中剛下過一場雨。傍晚的天氣清涼，使人感到秋意。皎潔的明月照耀松林之間。清澈的泉水在山石上流動。


### 原文第2組｜原文與語譯

<a id="k-afa88b8586a0502d"></a>
**原文：** 竹喧歸浣女，蓮動下漁舟。隨意春芳歇，王孫自可留。

<a id="k-2dbc3fcbcc8f7976"></a>
**語譯：** 竹林傳來喧鬧聲，原來是洗完衣裳的女子回來了。蓮葉搖動，原來是捕魚的船順流而下。任憑春天的花草凋謝。隱居山中的人，也就是詩人自己，仍自然可以留下來。

## 主旨與思想

### 一句話題旨

<a id="k-7cac38385495f4f9"></a>
**題旨：** 山居清景


### 王維｜唐代｜五言律詩

<a id="k-3af929be1bfa14c7"></a>
**內容：** 清幽秋景和淳樸人事，使詩人願意留居山中。


### 句段核心：原文第1組｜原文與語譯

<a id="k-de0aeb4640df8b1b"></a>
**重點：** 雨後秋晚清幽宜人，月照泉流動靜相映。


### 語譯

<a id="k-a50650ad83be41fd"></a>
**內容：** 「空」寫清幽，不否定下文有人居住。月照偏靜，泉流是動態；局部流水襯出整體寧靜。

<a id="k-5444d4f712c4e5c0"></a>
**內容：** 竹喧先聞聲、蓮動先見動，再帶出浣女和漁舟。尾聯反用「山中不可以久留」，不是因春花凋謝而感傷。

<a id="k-a22dd7d21e8bcd5c"></a>

### 古詩、律詩、絕句與排律

<a id="k-ff6087175fad708e"></a>
**內容：** 古詩在句數、平仄和對仗方面較自由；律詩通常八句，絕句四句，排律在律詩格律基礎上延長至十句或以上。不能單憑每句五字或七字判定體裁，還要核對句數與格律。


### 押韻與韻腳

<a id="k-b9e1a4bedd89a5cd"></a>
**內容：** 韻腳是詩句末尾用來押韻的字。律詩一般偶數句押韻，首句可入韻，也可不入韻；不能把每句最後一字都當作韻腳。判斷古詩用韻要留意古音及韻部，不能只按現代普通話讀音。

## 結構與脈絡

### 內容線索

<a id="k-2cee2c2b7df537e9"></a>
**內容：** 雨後秋晚→月泉景物→浣女漁舟→反用典故表留居


### 首聯

<a id="k-63a28eb78c962a88"></a>
**內容、線索和作用：** 總寫空山、新雨後的秋晚，交代時間傍晚、季節秋、地點山間、天氣雨後清涼，呼應山／秋／暝；空與新雨造成空靈、清新、宜人的基調。


### 頷聯

<a id="k-63e2a1a3a41906fc"></a>
**內容、線索和作用：** 寫眼前月、松、泉、石；皓月、青松偏靜，清泉流動，以局部動態襯整體靜謐。


### 頸聯

<a id="k-68d3eb588d128004"></a>
**內容、線索和作用：** 由自然景物轉山民人事；浣女歸來、漁人舟行、竹喧、蓮動都是生活活動，增添動感、聲音與情趣。


### 尾聯

<a id="k-df49e6fcba60971c"></a>
**內容、線索和作用：** 含蓄抒情；即使春芳凋謝，秋晚山景和淳樸生活仍值得欣賞享受，因而自可留，流露喜愛山居、嚮往隱居及厭倦官場。


### 四聯如何支持留居山中的選擇

<a id="k-2ce84e2eeada02e8"></a>
**內容：** 由景到人、再到自己的選擇，前三聯是尾聯情志的依據，不是與主旨無關的景物清單。觀察視線由上而下、由遠而近；頸聯又有先聲／動、後人／舟的發現次序。


### 延伸補充｜格律與對仗

<a id="k-e16defe69ebbc86d"></a>
**內容：** 本詩屬近體詩中的五言律詩：八句，每句五字，共四十字；一二句首聯、三四句頷聯、五六句頸聯、七八句尾聯。偶句韻腳為「秋、流、舟、留」，同押尤韻。中間兩聯對仗；首句「後」不列本詩偶句韻腳。

<a id="k-ee9424f6261a6df8"></a>
**內容：** 古體詩在句數、對仗和轉韻方面較自由；近體詩有較嚴整的格律。本詩是五言律詩，先掌握八句四聯、每句五字、頷頸兩聯對仗和偶句押韻，再看形式如何配合景物與情感。

<a id="k-1a4de9f5e8f63fc3"></a>
**內容：** 中間兩聯把相應的景物、位置和動作並排：「明月／清泉」「松間／石上」「照／流」。讀出這些對應，比只記「對仗工整」更能看清詩的組織。


### 首聯定基調

<a id="k-273a8b34b972fe73"></a>
**怎樣連起來：** 空山、新雨、晚、秋把地點與清新涼意連起來。


### 頷頸聯充實理由

<a id="k-66241530a9a5cbaa"></a>
**怎樣連起來：** 月泉寫自然，浣女漁舟寫人事；動與聲並未破壞幽靜，反令幽靜有生氣。


### 尾聯作選擇

<a id="k-8d14587bc65c56e2"></a>
**怎樣連起來：** 即使春芳已歇，仍願留山；反用典故把前面景物收為自己的生活理想。


### 律詩四聯

<a id="k-ad2de80606907343"></a>
**內容：** 律詩通常有八句，每兩句為一聯：第1–2句是首聯，第3–4句是頷聯，第5–6句是頸聯，第7–8句是尾聯。頷聯和頸聯通常要求對仗。判斷聯次須從全詩第一句數起，不能把題目節錄的次序當成全詩句次。


<a id="character"></a>
## 人物與情感

### 典故、主旨、人物與情感

<a id="k-6b508cd21ee66a43"></a>
**內容：** 「隨意春芳歇，王孫自可留」反用《楚辭・招隱士》「王孫兮歸來，山中兮不可以久留」：原意希望王孫歸來、不要久留山中；本詩反過來說山中美景與生活令人留戀，自可留下，不必回朝廷。即使春天花草已謝，秋景仍美，並非對春逝失落。常見典故活用成新意，深化歸隱主題、增強感染力。

<a id="k-dd53d840465a449b"></a>
**內容：** 「明月松間照」寄寓高潔，可分析月明淨皎潔→光明高尚，也可說松挺拔耐寒→剛直有節；或合看整句明淨清新的意境→不隨俗的高潔追求。不可只列「月、松象徵高潔」而漏掉特點與品格的連接。這與尾聯的反用典故是不同手法、不同證據。

## 手法與賞析

### 觸覺

<a id="k-5aaf4aed683463e6"></a>
**例句或內容：** 空山新雨後，天氣晚來秋

**運用、效果及不同角度：** 雨後秋涼，寫清爽宜人的感受。


### 視覺

<a id="k-08c2b488b034c37a"></a>
**例句或內容：** 明月松間照，清泉石上流

**運用、效果及不同角度：** 月照松、泉流石，上下景物清晰，構成秋晚圖畫。

<a id="k-c5be4711dd62ce70"></a>
**例句或內容：** 蓮動下漁舟

**運用、效果及不同角度：** 船過蓮葉搖動，呈現山民生活自然情趣。


### 聽覺兼視覺

<a id="k-d40219b57b34af02"></a>
**例句或內容：** 竹喧歸浣女

**運用、效果及不同角度：** 竹林先傳出笑語，再帶出歸來的浣女，形成先聞聲、後見人的次序，既引起注意，也增添山居生活的生氣。


### 動靜結合

<a id="k-0decdd7411aca4e9"></a>
**例句或內容：** 首聯、月照泉流、浣女與漁舟

**運用、效果及不同角度：** 首聯空山雨霽、頷聯青松如蓋皓月當空、山泉清洌／清冽，構成靜謐背景；泉水淙淙、浣女嬉笑、船行蓮動加入局部動景，使山村豐富多姿、活潑可喜而不冷清平淡。


### 以光襯暗／以明襯暗

<a id="k-deaf398ad899981c"></a>
**例句或內容：** 明月松間照

**運用、效果及不同角度：** 皎潔月光照入陰暗松林，明暗相映，明淨清幽。增寫光穿葉縫、斑駁影子；這是形象化聯想，不是詩句逐字內容。


### 以聲襯靜

<a id="k-af6dcf5679887f27"></a>
**例句或內容：** 竹喧歸浣女

**運用、效果及不同角度：** 洗衣歸來女子喧鬧嬉笑，以局部聲音反襯山村安靜、空靜閒適。


### 以動襯靜

<a id="k-8dc99fc74450f0c1"></a>
**例句或內容：** 清泉石上流

**運用、效果及不同角度：** 泉流動態映襯雨後空山靜謐；該聯以靜景為主不等於泉流屬靜物。

<a id="k-cad083f1d9c0d75c"></a>
**例句或內容：** 竹喧歸浣女，蓮動下漁舟

**運用、效果及不同角度：** 人舟活動、蓮葉搖動反襯環境平靜，恬淡自然且有生活情趣。另把竹喧聲音標「以動襯靜B」，屬分類角度。


### 對偶／對仗

<a id="k-b24ea7f56ecec339"></a>
**例句或內容：** 明月松間照，清泉石上流

**運用、效果及不同角度：** 明月／清泉、松間／石上、照／流相對，句式整齊，兩組自然景相映。

<a id="k-f3f34735e5c5e52a"></a>
**例句或內容：** 竹喧歸浣女，蓮動下漁舟

**運用、效果及不同角度：** 同構句式對寫女子歸和漁舟下，呈兩種純樸人事，符合律詩形式。


### 前後／題文呼應

<a id="k-80294b5aa79e9df7"></a>
**例句或內容：** 明月、歸浣女、下漁舟

**運用、效果及不同角度：** 呼應題中居、暝及第二句晚；月出和傍晚人事使山居場景時間一致，


### 觸景生情、借景抒情

<a id="k-a7cf037925743036"></a>
**例句或內容：** 雨後山景、山民生活→自可留

**運用、效果及不同角度：** 秋山如洗、松靜水清、人物生活有情趣，令人流連陶醉、忘懷世事，由景生出喜愛山居及厭倦官場之情。可用「世外桃源」形容其理想境界，不據此另立本詩用了桃花源典故。


### 詩中有畫

<a id="k-7b7e8c0f9f426f90"></a>
**例句或內容：** 空山秋夜圖

**運用、效果及不同角度：** 捕捉特點，從構圖、光暗、動靜繪景，意境優美。


### 白描與興寄／寓情於景

<a id="k-da71bab61787d1b7"></a>
**例句或內容：** 明月、清泉、浣女、漁舟

**運用、效果及不同角度：** 說表面以白描細刻美態，實際向景物投放情感，寄託曠達高潔及厭棄官場、脫離塵俗、隱居山林的理想。白描談描寫方式，興寄談情志寄託，可以兼容。


### 反用典故

<a id="k-17eb1247eef18174"></a>
**例句或內容：** 隨意春芳歇，王孫自可留

**運用、效果及不同角度：** 原典與本詩意思相反，詳見下節。


### 借代

<a id="k-8c0a2303eaa2e401"></a>
**例句或內容：** 王孫自可留

**運用、效果及不同角度：** 以王孫代隱士並指自己，含蓄表達留居選擇。


### 象徵

<a id="k-9f55f8fa7e0baf95"></a>
