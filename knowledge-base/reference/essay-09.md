# 岳陽樓記

[本篇核心](../chapters/essay-09.md) · [知識庫首頁](../README.md) · [跨篇比較](../topics/comparisons.md) · [異解與待核](../audit/REVIEW.md)

## 先回答這個問題

**遷客騷人與古仁人的憂樂有何根本不同？**

文章由修樓、湖景轉向覽物之情；陰雨與晴明引出隨境而變的悲喜，再以古仁人超越一己得失、憂國憂民的態度，提出先憂後樂的理想。

## 全篇思路

1. 修樓緣起 → 洞庭大觀 → 遷客騷人的覽物之情
2. 陰雨而悲／晴明而喜：景物與個人遭際相連
3. 不以物喜、不以己悲 → 進亦憂、退亦憂 → 先憂後樂

## 最容易混淆

- 古仁人不是沒有感情；其憂樂重心在天下。
- 『不以物喜』與『後天下之樂而樂』不矛盾，對象和依據不同。
- 景物分析須扣悲喜與議論轉折，不只羅列修辭名稱。

## 原文與語譯

### 第1段｜原文與語譯

<a id="k-87023f35cad4a1fe"></a>
**原文：** 慶曆四年春，滕子京謫守巴陵郡。越明年，政通人和，百廢具興。乃重修岳陽樓，增其舊制，刻唐賢、今人詩賦於其上；屬予作文以記之。

<a id="k-4ea42b14ba30bed7"></a>
**語譯：** 慶曆四年的春天，滕子京被貶官調守岳州。到了第二年，政事順利，百姓安居樂業，許多荒廢了的事情都興辦起來。於是他重新修建岳陽樓，擴大它原來的規模，把唐代著名文人和當代人寫的詩歌和辭賦刻在岳陽樓上；他委託我寫一篇文章記敍這件事。


### 第2段｜原文與語譯

<a id="k-56352c24ee4f711f"></a>
**原文：** 予觀夫巴陵勝狀，在洞庭一湖。銜遠山，吞長江，浩浩湯湯，橫無際涯；朝暉夕陰，氣象萬千。此則岳陽樓之大觀也，前人之述備矣。然則北通巫峽，南極瀟湘，遷客騷人，多會於此，覽物之情，得無異乎？

<a id="k-95288e58dc9e49e7"></a>
**語譯：** 我觀賞那岳州的美景，全在洞庭湖上。它包含着遠處的羣山，吸納着長江的巨流，水勢浩大，無邊無際；早晨和傍晚，景色或晴明或幽暗，千變萬化。這就是岳陽樓的雄偉景觀，前人的描述已經很詳盡了。那麼從洞庭湖向北可以通到巫峽，向南一直可以通到瀟水和湘江，被降職遠調的官吏和來往的詩人，大多在這裏聚會，他們觀賞自然景物所產生的感情，能沒有不同嗎？


### 第3段｜原文與語譯

<a id="k-a21571c4409289bb"></a>
**原文：** 若夫霪雨霏霏，連月不開；陰風怒號，濁浪排空；日星隱耀，山岳潛形；商旅不行，檣傾楫摧；薄暮冥冥，虎嘯猿啼。登斯樓也，則有去國懷鄉，憂讒畏譏，滿目蕭然，感極而悲者矣。

<a id="k-759d47ddaa947dee"></a>
**語譯：** 至於那連綿的陰雨下個不斷的日子，接連數月都不放晴；陰冷的風狂叫怒吼，渾濁的浪頭衝向天空；太陽和星星的光輝都被隱沒了，高山都隱藏不見；商人和旅客不能前行，船上的桅杆傾斜、船槳折斷；黃昏時天色昏暗，老虎怒吼，猿猴悲啼。在這時登上這座樓，就會產生因離開京師而懷念故鄉的心情，擔憂和害怕被別人誹謗或譏諷，只覺得滿眼蕭條空寂，感慨到極點而悲傷起來了。


### 第4段｜原文與語譯

<a id="k-061746dae85077be"></a>
**原文：** 至若春和景明，波瀾不驚，上下天光，一碧萬頃；沙鷗翔集，錦鱗游泳，岸芷汀蘭，郁郁青青。而或長煙一空，皓月千里，浮光躍金，靜影沉璧；漁歌互答，此樂何極！登斯樓也，則有心曠神怡，寵辱皆忘，把酒臨風，其喜洋洋者矣。

<a id="k-93b1d062c48c2bcc"></a>
**語譯：** 至於在春日天氣暖和，陽光明媚的日子，湖面風平浪靜，天色和湖光相映，一片碧綠廣闊無邊；成羣的沙鷗時而飛翔時而停歇聚集，美麗的魚兒游來游去，岸邊或小洲上的香草和蘭花，香氣濃郁，長得很茂盛。有時大片的煙霧完全消散了，潔白明亮的月光一瀉千里，月光映照在波動的湖面上，閃耀着金光，靜靜的月影像沉浸在水中的白玉，漁夫的歌聲互相唱和，這種快樂哪有窮盡！在這時登上這座樓台，就會心胸開闊，精神愉快，得失榮辱全都忘記，端起酒杯迎風暢飲，實在高興極了。


### 第5段｜原文與語譯

<a id="k-c101b12a80c08091"></a>
**原文：** 嗟夫！予嘗求古仁人之心，或異二者之為。何哉？不以物喜，不以己悲。居廟堂之高，則憂其民；處江湖之遠，則憂其君。是進亦憂，退亦憂，然則何時而樂耶？其必曰：「先天下之憂而憂，後天下之樂而樂」歟！噫！微斯人，吾誰與歸！

<a id="k-735576d5a75ebd3e"></a>
**語譯：** 唉！我曾經探求古時品德高尚的人的心思，也許和上述的兩種人有不同的表現。為甚麼呢？他們不會因為有美好的景物、環境而高興或悲傷，也不會因為自己不幸的遭遇而高興或悲傷。在朝廷上做大官，便會為他的百姓擔憂；處身在僻遠的地方，就會為他的君主擔憂。這就是說在朝廷做官也要憂慮，不在朝廷做官也要憂慮，那麼，甚麼時候才能快樂呢？他們一定會說：「在天下人擔憂之前先擔憂，在天下人享樂之後才享樂」吧！唉！如果沒有這些人，我將依從誰呢？

## 字詞與句式

### 「橫無際涯」「濁浪排空」「一碧萬頃」

<a id="k-7fe20903dbe2de0d"></a>
**怎樣運用：** 誇張空間範圍或浪勢。

**表達效果：** 分別突出廣闊、猛烈和晴明開展。


### 「浩浩湯湯」「霏霏」「冥冥」「郁郁青青」

<a id="k-2f574f0a2a992ab5"></a>
**怎樣運用：** 疊詞描摹水勢、雨態、昏暗與草木。

**表達效果：** 加強形象與節奏，使景色特點鮮明。


### 「銜遠山，吞長江」

<a id="k-6e174b80a61e41ac"></a>
**怎樣運用：** 用含、吞的動作寫湖與山水的關係，帶擬人意味。

**表達效果：** 把靜態景觀寫得有力量，顯出洞庭湖的恢宏氣勢。


### 「錦鱗」「檣楫」「廟堂」「江湖」

<a id="k-6110ca47bf10f07c"></a>
**怎樣運用：** 以魚鱗代魚、舟具代船、處所代朝廷或在野處境。

**表達效果：** 表達簡潔，所指仍須依語境理解。


### 「陰風怒號」

<a id="k-2fe84ba3a93d7b4f"></a>
**怎樣運用：** 「怒」把風寫得像人發怒。

**表達效果：** 使風聲猛烈可感，增添恐怖氣氛。

### 憂樂的對象：私己與君民

<a id="k-c249c32ce16dff37"></a>
**內容：** 遷客騷人因景及私己際遇而悲喜；古仁人超越個人利害，始終關心君民。不以物喜、不以己悲合讀是不因外物變化或自己遭遇而或喜或悲，不是完全沒有情緒；進憂民、退憂君，憂的對象是社會國家，與不憂個人並無矛盾。先憂是預見危機、為人籌謀，後樂是待天下安樂才以之為樂；不是要所有人先傷心自己才傷心。


### 暫忘榮辱與穩定原則

<a id="k-e720bac6e096486e"></a>
**內容：** 第四段寵辱皆忘是景美而暫忘榮辱，仍隨物而喜；古仁人是穩定處世原則，在何種處境都心繫天下，不能把境界等同。退居江湖也不等於放棄社會責任。二者指因景而悲與因景而喜的兩種表現，不是范、滕二人。末句表明嚮往與追隨，但不能據此推定當朝一個古仁人式官員也沒有。

**在全文的作用：** 略寫前人已詳述的景觀，引出同一地點會有不同感受。

<a id="k-8d7b26c9499a3770"></a>

### 煉字比較：為何「銜」比「接」鮮明

<a id="k-77858628f2cd4a5c"></a>
**內容：** 「接」只平直說湖與遠山相連；「銜」令人想像湖張口含着遠山，帶動勢，並與「吞」互相配合，讓山水氣象更磅礡。比較時先交代兩字意思，再說換字後形象和氣勢如何改變。


### 比喻

<a id="k-0566cf534a03ef48"></a>
**內容：** 比喻把兩種不同而具有相似點的事物聯繫起來。本體是要說明的對象，喻體是用來作比的事物。明喻常用「如、似、猶」等喻詞；暗喻以「是、為」等把兩者連起來；借喻只出現喻體。辨析時須指出相似點和具體作用。


### 反問與設問

<a id="k-7d53eb5b9baf23ef"></a>
**內容：** 反問用疑問形式表達已確定的意思，通常不需回答，以加強語氣；設問先提出問題再作回答，引導讀者理解。判斷時看句子在上下文的作用，不能只憑問號。


### 借代

<a id="k-454af3eaf68cec65"></a>
**內容：** 借代利用事物之間的關聯，以特徵、部分、材料或相關事物代替本體。比喻依靠相似，借代依靠關聯。答題要說明代指對象及兩者關係。
