# 師說

[本篇核心](../chapters/essay-07.md) · [知識庫首頁](../README.md) · [跨篇比較](../topics/comparisons.md) · [異解與待核](../audit/REVIEW.md)

## 先回答這個問題

**選老師的標準是甚麼？為何當時的人做不到？**

老師以傳道、受業、解惑為職責，擇師應看聞道和專長，不能受年齡、地位與羞恥心理限制。文章以多組對比批評恥學於師，再以孔子和李蟠作證。

## 全篇思路

1. 提出從師必要與擇師準則
2. 古今、自身與愛子、士大夫與百工：三組對比揭示矛盾
3. 孔子從師 → 弟子不必不如師 → 讚李蟠實踐古道

## 最容易混淆

- 『弟子不必不如師』是不一定，不是弟子必勝老師。
- 『道之所存，師之所存』說擇師準則，不是只拜一位老師。
- 答對比要列雙方、比較角度，以及所批評的態度。

## 原文與語譯

### 第1段｜原文與語譯

<a id="k-8e7462052b690e89"></a>
**原文：** 古之學者必有師。師者，所以傳道、受業、解惑也。人非生而知之者，孰能無惑？惑而不從師，其為惑也終不解矣。

<a id="k-ff8fe90ba2e567c0"></a>
**語譯：** 古代求學的人必定有老師。老師，是傳授儒家道統、講授課業、解答疑惑的人。人不是生下來就有知識的，誰能沒有疑惑？有疑惑卻不跟從老師學習，那些成為疑惑的東西最終都不能解決了。


### 第2段｜原文與語譯

<a id="k-f5b461b590df5e39"></a>
**原文：** 生乎吾前，其聞道也，固先乎吾，吾從而師之；生乎吾後，其聞道也，亦先乎吾，吾從而師之。吾師道也，夫庸知其年之先後生於吾乎？是故無貴無賤，無長無少，道之所存，師之所存也。

<a id="k-01b63b80294e2c95"></a>
**語譯：** 出生在我之前的人，他領會道理的時間本來就比我早，我應該跟從他學習；出生在我之後的人，如果他領會道理的時間亦比我早，我也應該跟從他學習。我拜師學習道理，何必去計較他的出生年份比我早還是比我晚呢？因此無論地位高低貴賤，無論年長年幼，道理存在的地方，就是老師所在的地方了。


### 第3段｜原文與語譯

<a id="k-857c70c77842b33e"></a>
**原文：** 嗟乎！師道之不傳也久矣！欲人之無惑也難矣！古之聖人，其出人也遠矣，猶且從師而問焉；今之眾人，其下聖人也亦遠矣，而恥學於師；是故聖益聖，愚益愚，聖人之所以為聖，愚人之所以為愚，其皆出於此乎！

<a id="k-4e7e1ae4ae0a5e47"></a>
**語譯：** 唉！從師學習的正確態度已經很久沒有流傳了！想人們沒有疑惑也很難了！古代的聖人，他們（的才智學問）超越一般人已經很遠了，尚且要跟從老師並向他們請教學問；現在的一般人，他們（的才智學問）不及聖人亦已經很遠了，卻恥於跟從老師學習；因此聖人更加聖明，愚人更加愚昧；聖人之所以成為聖人，愚人之所以成為愚人，大概都出於這個原因吧！


### 第4段｜原文與語譯

<a id="k-9a5eac99855262de"></a>
**原文：** 愛其子，擇師而教之，於其身也則恥師焉，惑矣！彼童子之師，授之書而習其句讀者，非吾所謂傳其道、解其惑者也。句讀之不知，惑之不解，或師焉，或不焉，小學而大遺，吾未見其明也。

<a id="k-c15fecbea2e01889"></a>
**語譯：** 愛惜自己的孩子，選擇老師來教他們；對於自己本身卻以跟從老師學習為恥辱，真是糊塗啊！那些孩子的老師，是向孩子講授經書從而讓孩子學習書中文句語法的人，不是我所說的傳授儒家道統、解答疑惑的人。（孩子）不知道句讀標點，（成人）不能解決疑惑，前者跟從老師學習，後者卻不學，小事從師學習而大事遺棄不學，我不認為這種人是明白事理的。


### 第5段｜原文與語譯

<a id="k-0dc0726a1810362d"></a>
**原文：** 巫、醫、樂師、百工之人，不恥相師；士大夫之族，曰師、曰弟子云者，則羣聚而笑之。問之，則曰︰「彼與彼年相若也，道相似也。」位卑則足羞，官盛則近諛。嗚呼！師道之不復，可知矣。巫、醫、樂師、百工之人，君子不齒，今其智乃反不能及，其可怪也歟！

<a id="k-9cb92979562828da"></a>
**語譯：** 神巫、醫生、樂師、各種工匠，他們不以互相拜師學習為可恥；做官讀書的名門望族，每聽到有人說「老師」、說「弟子」等等，就聚在一起譏笑別人。問他們笑甚麼，他們便回答說：「他跟他年紀差不多，道德學問也差不多啊。拜地位低的人為師就感到羞恥，拜官職高的人為師就近乎諂媚。」唉！從師學習的正確態度不能恢復，由此可以知道了。神巫、醫生、樂師、各種工匠，君子都不屑與他們等列，現在君子的智慧竟反而及不上他們，這可真是奇怪啊！


### 第6段｜原文與語譯

<a id="k-d78604b2a7f858e3"></a>
**原文：** 聖人無常師，孔子師郯子、萇弘、師襄、老聃。郯子之徒，其賢不及孔子。孔子曰︰「三人行，則必有我師。」是故弟子不必不如師，師不必賢於弟子；聞道有先後，術業有專攻，如是而已。

<a id="k-c12dd7cabd9e8caa"></a>
**語譯：** 聖人沒有固定的老師，孔子曾拜郯子、萇弘、師襄、老聃為師。郯子這些人，他們的賢能及不上孔子。孔子說：「三個人走在一起，其中必定有可以當我老師的人。」因此學生不一定比不上老師，老師不必事事都比學生賢能；領會道理的時間有先有後，本領學問各有各的專長，就是這樣罷了。


### 第7段｜原文與語譯

<a id="k-e7065671cced8306"></a>
**原文：** 李氏子蟠，年十七，好古文，六藝經傳，皆通習之；不拘於時，學於余。余嘉其能行古道，作《師說》以貽之。

<a id="k-2b6fbd44be3a8c09"></a>
**語譯：** 李家孩子名叫蟠的，十七歲，喜歡古文，六藝的經文和注疏，全都學習過了，他不拘泥時俗，向我學習。我讚許他能夠遵行古人從師的道理，寫了這篇《師說》送給他。

## 字詞與句式

### 三組對比與人物態度

<a id="k-24bf3b9fd4656b56"></a>
**內容：** 三組比較由古今人物，轉入士大夫自身的矛盾，再及他們所輕視的百工。比較範圍愈來愈貼近士大夫的生活，使恥於從師的荒謬逐層顯出，也增強批評的說服力。


### 下

<a id="k-9c4378c87525e1e9"></a>
**詞義：** 不及

> 語境：嗟乎！師道之不傳也久矣！欲人之無惑也難矣！古之聖人，其出人也遠矣，猶且從師而問焉；今之眾人，其下聖人也亦遠矣，而恥學於師；是故聖益聖，愚益愚，聖人之所以為聖，愚人之所以為愚，其皆出於此乎！

**原句定位：** 其下聖人也亦遠矣

**意思與必要辨析：** 才智學問不及聖人。


### 不必

<a id="k-e8da75c807ab6f31"></a>

### 句讀

<a id="k-79fb7d1f24df30a3"></a>

**意思與必要辨析：** 文句的斷句、停頓；語譯有書中文句語法、句讀標點的說明。 屬童子啟蒙、基本文句知識；借代分析另見修辭表。

<a id="k-ba181962ccf8389a"></a>

<a id="k-6c8032893ffd5543"></a>
**作用及理解：** 賓語前置，還原為「不知句讀、不解惑」。

## 主旨與思想

### 一句話題旨

<a id="k-34563a5247a56ef7"></a>
**題旨：** 從師與求道


### 韓愈｜唐代｜論辯體

<a id="k-c173e51f545b2038"></a>
**內容：** 有疑惑就需要從師；擇師看道理和專長，不看年齡、地位。


### 理解關鍵

<a id="k-00bb2f877da43b35"></a>
**內容：** 老師的傳道、受業、解惑彼此相連。「小學大遺」批評成人只重句讀、卻放棄求道解惑的取捨。


### 句段核心：第1段｜原文與語譯

<a id="k-cd72abbf2a85625c"></a>
**重點：** 人人有惑，從師才能解惑。


### 語譯

<a id="k-a6e768223382af9f"></a>
**內容：** 「學者」是求學的人。三項師職包括做人所據的道理、課業和疑難；只教識字斷句，未涵蓋本篇所說的全部職責。

<a id="k-7cc0f97633432e10"></a>
**內容：** 先出生不等於先聞道。只要對方領會道理在先，即使年紀較小也可以向他學習；「無」在此是無論。

<a id="k-55f9b41311f0240c"></a>
**內容：** 古聖本已勝人仍求師，今眾本不及人卻恥師。先對照態度，再見聖益聖、愚益愚的結果，批評才有依據。

<a id="k-41b405127f70bf06"></a>
**內容：** 小學指學句讀，大遺指放棄求道解惑。「惑矣」是在批評這種取捨不明智，不是單說心中有疑問。

<a id="k-2e30e389dd6a7a8c"></a>
**內容：** 位卑便嫌可羞，官高又嫌近諛，無論高低都找藉口。百工不恥相師的態度，反過來顯出士大夫的局限。

<a id="k-c2bdde9228d9754c"></a>
**內容：** 四人的整體賢能不及孔子，仍有專長可學。「不必」是不一定，不是必定不如；整體高下與局部專長不能混為一談。

<a id="k-d78204bfcf7681bd"></a>
**內容：** 「皆通習之」先說六藝經傳全都學過，不能直接換成所有學問完全精通。「貽之」的之指李蟠。


### 句段核心：第2段｜原文與語譯

<a id="k-77bdb6b58cf730b2"></a>
**重點：** 擇師以聞道為準，不受年齡與地位限制。


### 句段核心：第3段｜原文與語譯

<a id="k-951dcae8d9e60aa4"></a>
**重點：** 是否願意從師，使聖愚差距擴大。


### 句段核心：第4段｜原文與語譯

### 為何必須從師

<a id="k-434267d70a58bfd3"></a>
**內容：** 全文以「古之學者必有師」立論：人並非生而知之，必有疑惑；有惑卻不從師，疑惑終不能解決，所以從師有其必要。韓愈藉古今、父子學習取捨和社會階層的對照，批評恥於從師、固步自封的風氣，倡導謙虛求學。


### 教師三項職責如何相連

<a id="k-72ee6c0036ac0c35"></a>
**內容：** 「道」是本文要學習的儒家道理；「業」是經書課業及相關學問；「惑」是學習道、業時遇到的疑難。「受」通「授」，指傳授。三項相連，說明教師不只教人讀通字句，更要幫助學生理解道理。


### 擇師的標準

<a id="k-8f8de6724793673c"></a>
**內容：** 擇師以「道之所存，師之所存也」為準：不分地位貴賤、年齡長幼，只要對方聞道在先或有值得學習的專長，便可從學。出生早晚不是判斷學問先後的可靠標準；生於我後而聞道在先的人也可為師。官位高低亦不能成為拒絕從師的藉口。


### 為何可以互相學習

<a id="k-eea566b63a6782ce"></a>
**內容：** 「聖人無常師」指沒有固定不變的一位老師，並非不需要老師。「弟子不必不如師，師不必賢於弟子」的「不必」是不一定；老師不必事事勝過學生，因為「聞道有先後，術業有專攻」。整體賢能高下與局部專長有別，可以互相學習；先聞道與有專長也不必機械理解成兩項必須同時具備的門檻。


### 全文論點與局部論點

<a id="k-e1d1f7ca8ecaa50e"></a>
**內容：** <b>全文與局部論點</b>：全文從師必要；孔子段進一步說明「學習不應只限於以某一人為師」「為師不必限於優勝過自己的人」。孔子博學、不恥下問是事實或論據，不能代替該段所論的道理；「集思廣益」亦不是此段論證重點。

### 古之聖人／今之眾人；不同時代

<a id="k-0eb89fbd2d480ad7"></a>
**各方表現：** 聖人才智超越一般人仍虛心從師；今眾遠不及聖人卻恥於問學。

<a id="k-fc74799543acfa3c"></a>
**各方表現：** 愛子而擇師教句讀；對自身求道解惑卻不從師。

**結果、批評及推論：** 小的方面學，大的方面遺棄，本末倒置、言行不一、不明智。責備的是成人的兩種選擇，非孩子學習有錯。

<a id="k-c166254168ce5a61"></a>

**結果、批評及推論：** 士大夫不屑與百工並列，智慧卻反不及他們，顯出愚昧、膚淺和固步自封；反襯百工更明智，支持不以地位年齡擇師。

**分析、效果與限制：** 「惑」首尾相接，語勢緊湊，突出有惑須從師。

<a id="k-a96faabaf552ea0e"></a>
**例句／內容：** 「弟子不必不如師，師不必賢於弟子」

**分析、效果與限制：** 「師」承接，語句流暢而緊密，推進師生高下的論述。


### 明引／引用論證

<a id="k-15036940451ed676"></a>
**例句／內容：** 孔子曰：「三人行，則必有我師。」

**分析、效果與限制：** 引用名言支持人人有所長、可互相學習；權威性增強說服力。

**內容：** 反問用疑問形式表達已確定的意思，通常不需回答，以加強語氣；設問先提出問題再作回答，引導讀者理解。判斷時看句子在上下文的作用，不能只憑問號。


### 對比與襯托

<a id="k-252d104603369875"></a>
**內容：** 對比把兩方並置，突出差異，兩方都參與表意；襯托有主次，以陪襯的一方突出主要對象。分析須指出哪兩方、在哪一方面形成關係，以及這個關係如何支持文意。
