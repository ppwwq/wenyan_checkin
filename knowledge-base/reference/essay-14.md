# 念奴嬌・赤壁懷古

[本篇核心](../chapters/essay-14.md) · [知識庫首頁](../README.md) · [跨篇比較](../topics/comparisons.md) · [異解與待核](../audit/REVIEW.md)

## 先回答這個問題

**蘇軾如何由懷古走到自傷與自解？**

雄奇赤壁江山引出歷史英雄；周瑜的年少得意反照詞人的早生華髮與功業感慨，結尾以如夢之嘆和酹江月作複雜的自我排解。

## 全篇思路

1. 大江、故壘、亂石驚濤 → 江山引懷古
2. 小喬、雄姿、談笑破敵 → 集中塑造周瑜
3. 多情應笑我、早生華髮 → 如夢與酹月

## 最容易混淆

- 周瑜『談笑』和詞人『笑我』的主體、心情不同。
- 『小喬初嫁』是藝術上集中少年得意的形象，勿當赤壁之戰當年的精確婚期。
- 結尾兼有感慨與排解，不宜一刀切成全然消極或完全放下。

## 原文與語譯

### 上片｜原文與語譯

<a id="k-fe79f5c77fe634e7"></a>
**原文：** 大江東去，浪淘盡、千古風流人物。故壘西邊，人道是、三國周郎赤壁。亂石穿空，驚濤拍岸，捲起千堆雪。江山如畫，一時多少豪傑！

<a id="k-76309f4ccd8d8690"></a>
**語譯：** 浩蕩長江滾滾向東流去，滔滔巨浪把千百年來眾多傑出英雄及其事蹟淘洗淨盡。舊營壘西邊，人們說是三國時周瑜大敗曹操的赤壁。陡峭不平的石壁高插雲霄，洶湧巨浪拍擊江岸，捲起千萬堆如白雪的浪花。眼前江山美如圖畫，當時不知出現了多少英雄豪傑！


### 下片｜原文與語譯

<a id="k-a06e04117837992b"></a>
**原文：** 遙想公瑾當年，小喬初嫁了，雄姿英發。羽扇綸巾，談笑間、檣櫓灰飛煙滅。故國神遊，多情應笑我，早生華髮。人間如夢，一尊還酹江月。

<a id="k-12ae6fbba296e917"></a>
**語譯：** 遙想當年的周瑜，小喬剛嫁給他，他雄姿英偉、英氣煥發。他手持羽扇、頭戴青絲頭巾，談笑之間，曹軍戰船便已化為灰燼煙霧。神遊三國古戰場，應當笑我多情善感，過早生出花白頭髮。人生猶如一場夢，不如斟一杯酒，灑向江中明月的倒影，寄託情懷。

**題旨：** 懷古與自況


### 蘇軾｜北宋｜詞

<a id="k-080cf3302594aa08"></a>
**內容：** 由壯闊江山追想周瑜功業，對照自身早生華髮，再以酹江月寄託人生感慨。

<a id="k-b61287a78f0e0b70"></a>
**內容：** 「談笑」是周瑜的從容；「應笑我」轉向詞人自身，不能混成同一笑者。

<a id="k-c04b5a0b2edd7605"></a>
**重點：** 江流帶出千古興亡，壯闊赤壁引人追想豪傑。

<a id="k-6ef982006e3c7ebc"></a>
**內容：** 石的高峻、浪的強勁與浪花的白，合成雄奇景象。「人道是」保留相傳語氣，不是地點考證定論。

<a id="k-29d91db46df44783"></a>
**重點：** 周瑜的從容功業與自身蹉跎形成反差，最後酹月寄懷。

## 人物與情感

### 周瑜形象與兩個「笑」

<a id="k-250b2df73a3c5d38"></a>
**內容：** 詞人先用周瑜的年輕、英偉和功業建立理想形象，再用兩個「笑」把英雄與自己接起來。

<a id="k-bd8a2747dc89f348"></a>
**內容：** 兩個「笑」把年少功成與華髮未酬對照起來。第一個笑顯出英雄有把握，第二個笑顯出詞人對自身處境的感慨，讓懷古成為抒發抱負的途徑。

<a id="k-fa9e9a26b252b386"></a>
**內容：** 補充理解：「應笑我」也可讀成想像周瑜笑自己多情；這仍是詞人的想像，並非古人實際說話。兩種讀法都把情感焦點轉回蘇軾。


### 「小喬初嫁了」「雄姿英發」

<a id="k-18c569d8b98dc219"></a>
**寫了甚麼：** 以婚姻美滿和英偉姿態集中寫年少得意。

**形象與情感：** 小喬從側面烘托周瑜的風采。


### 「羽扇綸巾」「談笑間、檣櫓灰飛煙滅」

<a id="k-29296f4cbf19f6fa"></a>

**形象與情感：** 「談笑」寫周瑜指揮若定；詩人對他有讚賞與仰慕。


### 「多情應笑我，早生華髮」

<a id="k-1a7773397306614a"></a>
**寫了甚麼：** 由想像古人轉回自身，笑自己多情，卻已早生白髮。

**形象與情感：** 「笑我」可按自嘲理解：年華漸老而功業未成，仰慕轉成自傷。


### 「大江東去，浪淘盡、千古風流人物」

<a id="k-545367d29612b5a2"></a>
**景物怎樣引發聯想：** 東流不返的江水使人想到時間不停流逝；連英雄也會被歷史淘洗。

**心境如何推進：** 由雄闊江山感到個體生命短暫、功業難以長存。


### 「早生華髮」「人間如夢」

<a id="k-21a9c0721fc42827"></a>
**景物怎樣引發聯想：** 歷史人物的消逝連回自己年華漸老、抱負未酬的處境。

**心境如何推進：** 傷感不只在白髮，更在看見人生與功名如夢般短促。


### 「一尊還酹江月」

<a id="k-cd1e0b78f806968b"></a>
**景物怎樣引發聯想：** 把酒灑向江月，將目光由個人得失轉向可寄情的自然。

**心境如何推進：** 試着放下過分執着，在江月之美中自我開解，轉向曠達。


### 江水的感慨與江月的感悟

<a id="k-31e72f256a2d2513"></a>
**內容：** 全詞的連接是：江水引出流逝之感，周瑜使人想到功業，華髮把比較落回自己，如夢的省思再引向酹月寄懷。結尾的開解承接前面的傷感，並不是突然換成歡樂。


### 延伸理解：由江月想到甚麼

<a id="k-d6fb4aa1a146a3e8"></a>
**內容：** 月色長在，可使人想到自然比個人生命悠久；月有圓缺又不斷循環，可使人想到得失變化是常態。這些聯想的作用，是幫助人減輕對一時成敗的執着。分析時先說月的特點，再說如何紓解人生短促之感。

## 手法與賞析

### 結構、景情與主旨

<a id="k-02f076b4439469be"></a>
**內容：** 全詞融合寫景、懷古、詠史、抒情；由眼前江山到遙想三國，再回自身。懷古不是孤立介紹周瑜事蹟，而是以其風采功業反照自身抱負。上片歷久長存的山川，對照下片短促虛幻的人事；傷感與曠達有推進轉折，不能只剩一種情绪。


### 託物起興、借景抒情

<a id="k-dd737de2325feb33"></a>
**例句及表達效果：** 「大江東去」以眼前江流引時間流逝；「浪淘盡、千古風流人物」由景生人生短暫之感。


### 借事抒情、以古襯今

<a id="k-aebcfbf4520a5a08"></a>
**例句及表達效果：** 周瑜大破曹軍、愛情事業兩得意，對照蘇軾屢遭貶謫、年老未酬，抒懷才不遇。


### 直接抒情、自嘲

<a id="k-4bbb3c1c57067d1e"></a>
**例句及表達效果：** 「多情應笑我，早生華髮」「人間如夢」直接流露自傷與人生省思。


### 對比

<a id="k-194afe08102167af"></a>
**例句及表達效果：** 江水奔流不息而英雄消逝；江水明月長存而人生如夢；周瑜青春功成而蘇軾華髮未酬。比較對象及作用各不相同。


### 明喻

<a id="k-8fc17c11fe0cad1d"></a>
**例句及表達效果：** 「江山如畫」以圖畫比江山，美景形象化；「人間如夢」以夢比人生，寫短促虛幻。


### 借喻

<a id="k-d1d50905bb10a4e2"></a>
**例句及表達效果：** 「大江」「浪」可比歷史、時間及其力量；「雪」借喻白色浪花，寫浪花四濺如雪堆的形態。


### 借代

<a id="k-5c007046b250abe9"></a>
**例句及表達效果：** 「檣櫓」以船具代戰船，簡潔呈曹軍覆滅。

<a id="k-b446bea2e2492dde"></a>
**內容：** 借代利用事物之間的關聯，以特徵、部分、材料或相關事物代替本體。比喻依靠相似，借代依靠關聯。答題要說明代指對象及兩者關係。


### 誇張

<a id="k-2e4049b6b76849c9"></a>
**例句及表達效果：** 「亂石穿空」誇飾石壁高峻，突出高、尖、陡；「千堆」誇大浪花數量聲勢；「談笑間、檣櫓灰飛煙滅」誇飾敗軍覆滅之速及周瑜才能。


### 肖像、服飾、神態、側面烘托

<a id="k-31697de9c91f3e15"></a>
**例句及表達效果：** 雄姿、羽扇綸巾、談笑、小喬、曹軍敗況，分別見上節，不能用一個「人物描寫」刪掉具體例子。


### 過渡

<a id="k-ab12184c797a33d3"></a>
**例句及表達效果：** 「江山如畫，一時多少豪傑」承上寫景、啟下懷古；「故國神遊」由古返今，轉入自抒身世。


### 豪邁雄奇的語言

<a id="k-f2aac1f69f99ee50"></a>
**例句及表達效果：** 大江、亂石、驚濤等壯闊景象，配「淘盡、穿、拍、捲」等有力動詞，把江山與歷史相連，讚英雄、抒抱負並感生命短促。風格與具體景象、情感相配，不只背「豪放」。


### 理解補充

<a id="k-0341cfb23e6a4f97"></a>
**內容：** 原文沿用「人間」「檣櫓」，另本作「人生」「強虜」；詞義和修辭須跟所引版本一致。「多情應笑我」有詞人自笑、想像周瑜笑己等解讀；不可把後者說成周瑜真實說話。


### 對比與襯托

<a id="k-1f187ae2890b5ce8"></a>
**內容：** 對比把兩方並置，突出差異，兩方都參與表意；襯托有主次，以陪襯的一方突出主要對象。分析須指出哪兩方、在哪一方面形成關係，以及這個關係如何支持文意。


### 比喻

<a id="k-f74d34e4fdbca262"></a>
**內容：** 比喻把兩種不同而具有相似點的事物聯繫起來。本體是要說明的對象，喻體是用來作比的事物。明喻常用「如、似、猶」等喻詞；暗喻以「是、為」等把兩者連起來；借喻只出現喻體。辨析時須指出相似點和具體作用。
