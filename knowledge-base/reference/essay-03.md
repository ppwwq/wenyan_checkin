# 勸學

[本篇核心](../chapters/essay-03.md) · [知識庫首頁](../README.md) · [跨篇比較](../topics/comparisons.md) · [異解與待核](../audit/REVIEW.md)

## 先回答這個問題

**學習為甚麼有效，又要怎樣學？**

學習能提升人的認識與品行；成效既來自借助外物，也依賴積累、堅持和專一。每組喻例各有論證任務，不能全部只答『說明學習很重要』。

## 全篇思路

1. 青、冰、木、金：學習能改變和提升
2. 登高、順風、輿馬、舟楫：善用外物
3. 積土水善、跬步小流：積累 → 騏驥駑馬、鍥而不舍：堅持 → 蚓蟹：專一

## 最容易混淆

- 『君子生非異也』重點在善假於物，不是天資決定成敗。
- 比喻、對比與正反論證可在同一例子中同時成立。
- 『不積跬步』從反面說必要條件，須說出積累與成果的關係。

## 原文與語譯

### 第1段｜原文與語譯

<a id="k-81daff23d62e7b3d"></a>
**原文：** 君子曰：學不可以已。青，取之於藍，而青於藍；冰，水為之，而寒於水。木直中繩，輮以為輪，其曲中規；雖有槁暴、不復挺者，輮使之然也。故木受繩則直，金就礪則利，君子博學而日參省乎己，則知明而行無過矣。

<a id="k-9065ff86ccd663fb"></a>
**語譯：** 君子說：學習不可以停止。靛青色，是從蓼藍中提煉出來的，卻比蓼藍還要深；冰，由水凝結而成，卻比水還要冷。木材筆直符合墨線的標準，用火烘烤它使它彎曲成為車輪，它的彎度符合圓規的標準；即使再曬乾，也不會回復挺直，這是因為經過火烘烤使它變成這樣的。所以木材經過墨線校正就能取直，刀劍在磨刀石上磨過就變得鋒利，君子廣泛地學習並且每天檢驗反省自己，就能智慧聰明，行為不會有過失了。


### 第2段｜原文與語譯

<a id="k-994f0c8a85c3f559"></a>
**原文：** 吾嘗終日而思矣，不如須臾之所學也；吾嘗跂而望矣，不如登高之博見也。登高而招，臂非加長也，而見者遠。順風而呼，聲非加疾也，而聞者彰。假輿馬者，非利足也，而致千里；假舟楫者，非能水也，而絕江河。君子生非異也，善假於物也。

<a id="k-60015a2296e8cc05"></a>
**語譯：** 我曾經整天思索，卻比不上片刻學習到的知識；我曾經踮起腳遠望，卻比不上登上高處看得廣闊。登上高處招手，手臂並沒有加長，可是在遠處的人也能看見我。順着風呼喊，聲音並沒有加大，可是聽的人也能聽得很清楚。借助車馬的人，並不是行走快速，卻可以行到千里；借助船隻的人，並不是善於游泳，卻可以橫渡江河。君子的本性與一般人沒有差別，（只是君子）善於借助外物罷了。


### 第3段｜原文與語譯 1

<a id="k-7b9bd56add195fcf"></a>
**原文：** 積土成山，風雨興焉；積水成淵，蛟龍生焉；積善成德，而神明自得，聖心備焉。故不積跬步，無以至千里；不積小流，無以成江海。騏驥一躍，不能十步；駑馬十駕，功在不舍。鍥而舍之，朽木不折；鍥而不舍，金石可鏤。

<a id="k-5230bf2980c0f42a"></a>
**語譯：** 堆積土石成為高山，風雨就在那裏興起；匯聚水流成為深淵，蛟龍就在那裏生長；（一個人）積聚善行養成美德，就能神志從容，心智澄明，具備聖人的心志了。所以不一步步地累積，就沒有（方法）到達千里之遠；不匯聚細小水流，就沒有（方法）成為江海。駿馬一跳，也不超過十步的距離；劣馬能奔走十天的路程，牠的成功在於牠不放棄。只雕刻幾下就放棄，（即使是）腐爛的木材也不會折斷；不放棄地持續雕刻，（連）金石都可以雕鏤。


### 第3段｜原文與語譯 2

<a id="k-9ec09e3495f02802"></a>
**原文：** 螾無爪牙之利，筋骨之強，上食埃土，下飲黃泉，用心一也。蟹六跪而二螯，非蛇蟺之穴無可寄託者，用心躁也。

<a id="k-60908049dae207e4"></a>
**語譯：** 蚯蚓沒有鋒利的爪和牙，沒有強健的筋骨，卻能向上鑽食土壤，向下喝到泉水，這是因為牠用心專一。螃蟹有六隻蟹腳和兩隻蟹鉗，（但是）若不是蛇鱔的洞穴，就沒有可寄住的地方，這是因為牠心思浮躁、不專心。

### 內容線索

<a id="k-9efa8f6b81d5223f"></a>

### 中心、結構與內在連接

<a id="k-c9a28f2ed5236522"></a>
**內容：** 「學不可以已」開門見山，提出全文中心論點，緊扣篇題、引領下文，立場清楚。第一段論學習的意義與好處：改變本質、提升水平、造就人才，博學日省使知明行無過。第二段由學與思的收穫比較，轉到借助外物擴大效能，歸結君子與常人本性無異，成就在善假於物。第三段從方法與態度論積累、恆心、專一，呼應不停止學習的中心。

<a id="k-403aa1ce40d177fd"></a>
**內容：** 「終日而思」與「須臾之所學」比較投入時間和所得：長時間獨自思索，不及片刻學習的收穫。「跂而望」與「登高之博見」再用視野作比，說明借助外在條件可以擴大能力。這裏勸人把思考與學習結合，並非否定思考。

<a id="k-a758e09a55130179"></a>
**內容：** 文中所追求的「君子」「聖心」是修養、智慧與道德境界，人物並無情節化的喜怒轉折；文章的情感在勸勉、肯定後天努力和對讀者可成材的期望。善假於物須分字面借外在條件與所論借學習修身兩層，不把外物單限交通工具，也不說人的手臂、聲帶或本性天生優越。

<a id="technique"></a>
## 手法與賞析

### 青取之於藍而青於藍；冰水為之而寒於水

<a id="k-954080a302bba42c"></a>
**變化或對比：** 靛青由蓼藍提煉而顏色更深；冰由水凝成而更冷

**論述目的及限制：** 後天學習能改變、提高原有狀態，超越原來水平；藍是草，不是只指藍色。


### 木直中繩，輮以為輪；再曬不復挺

<a id="k-2dfc8c691163205b"></a>
**變化或對比：** 原直木火烤加工成合圓規的輪，改造效果持久

**論述目的及限制：** 學習造就人才、改善本性。加工效果持久，喻學習和修養可以形成穩定的改變。


### 木受繩則直；金就礪則利

<a id="k-20def63ce5e556dd"></a>
**變化或對比：** 墨線校正取直；刀劍磨礪鋒利

**論述目的及限制：** 廣泛學習、每日反省，可改過遷善、合道德禮教，使智慧通達、行為無過。這是與輮木成曲不同的加工喻例。


### 終日思／須臾學；跂望／登高

<a id="k-b2115b1c8949388d"></a>
**變化或對比：** 思索時間長而所得不及片刻學習；踮腳不如借高度看得廣

**論述目的及限制：** 學習助益，從獨力轉向善用條件；不等於思考一無是處。


### 登高而招

<a id="k-2c6d932fdcca0fa1"></a>
**變化或對比：** 臂沒有加長，遠處卻能看見

**論述目的及限制：** 外在高度擴大視覺傳達效果，借物能事半功倍。


### 順風而呼

<a id="k-96dd007ba9d26b80"></a>
**變化或對比：** 聲音沒有更大，聽者卻更清楚

**論述目的及限制：** 借風改善聽覺效果，聲量與聽聞清晰度分開。


### 假輿馬

<a id="k-2e595a36b54a7b09"></a>
**變化或對比：** 不以腳力快速見長而能到千里

**論述目的及限制：** 借外物彌補不足，資質一般者亦能有成就。


### 假舟楫

<a id="k-85486e9e2823a390"></a>
**變化或對比：** 不善游泳卻可橫渡江河

**論述目的及限制：** 借船比借學習，彌補不足、取得成就並修德成君子。


### 積土成山、風雨興；積水成淵、蛟龍生

<a id="k-f6532317917cb5f7"></a>
**變化或對比：** 點滴累積成大並產生新效果

**論述目的及限制：** 由自然累積推到積善成德、神明自得、聖心備。「積善」是由自然現象推到人的修養，是此組要說明的道理。


### 不積跬步／不積小流

<a id="k-5ed0856c5ccc0a15"></a>
**變化或對比：** 不累積則無法到千里／成江海

**論述目的及限制：** 反面證積累是必要條件，與積土、水、善的正面相配。


### 騏驥一躍／駑馬十駕

<a id="k-a30a8a337cf1250d"></a>
**變化或對比：** 良馬只躍一次不足十步，劣馬持續十日可走遠

**論述目的及限制：** 先天優劣不能取代後天努力，關鍵在不放棄；此組重恆心與持續積累，不答專一。


### 鍥而舍之／鍥而不舍

<a id="k-d0d5aff2e9eb4e5d"></a>
**變化或對比：** 易折的朽木因放棄而不折；堅硬金石因堅持而可刻

**論述目的及限制：** 難易不是決定因素，持之以恆方能克服困難；反對半途而廢。


### 螾／蟹

<a id="k-ad8ed488c4533dff"></a>
**變化或對比：** 螾無鋒利爪牙、強健筋骨，卻可上下覓食；蟹有足螯而須借蛇鱔穴

**論述目的及限制：** 形體強弱與結果相反，差在專一與浮躁；此組重專心，不可省寫成螾完全無爪牙筋骨。


### 全部喻例與道理逐組對應

<a id="k-c75f1055d494f643"></a>
**內容：** 第三段的三個重點彼此配合：積累使小量逐漸成大，恆心使積累不因中途放棄而中斷，專一使努力集中於目標。駑馬與鍥刻重在不捨，螾蟹重在用心一或躁；把例子連回各自的結果，便不易混淆。


### 論證與修辭：同一例子的不同層次

<a id="k-0a80199feafe4a89"></a>
**內容：** 「積土成山……積水成淵……積善成德……」構成三組排比，由自然現象推進到人的修養，語勢連貫。青與冰、騏驥與駑馬等則先看成兩相對照：分析時要說明各自怎樣支持學習的道理。

<a id="k-92c80c773048a379"></a>
**內容：** 喻例的重點在事物的變化：青與冰由原料而提升，木材經加工改變，刀劍經磨礪變利，土水由小積大。這些形象把看不見的學習成效具體化，讓讀者從熟悉事物理解修身的方法。

<a id="k-3b28f9182a61699b"></a>
**內容：** 駢散互用：開頭「君子曰：學不可以已」及第二段末「君子生非異也，善假於物也」以散句突出主張，夾於大量偶句、排比之間；整齊對偶厚重典雅，非等長相對句增加變化，排比使語勢奔放。觀物入微在以招手、呼聲呈現抽象視聽效能，以螾蟹形體與活動空間展示專心的結果；各喻都扣學習，結構環環相扣，不是散亂堆例。


### 對比與襯托

<a id="k-c2286ab41702b31e"></a>
**內容：** 對比把兩方並置，突出差異，兩方都參與表意；襯托有主次，以陪襯的一方突出主要對象。分析須指出哪兩方、在哪一方面形成關係，以及這個關係如何支持文意。


### 比喻

<a id="k-0c6f34fc31f65035"></a>
**內容：** 比喻把兩種不同而具有相似點的事物聯繫起來。本體是要說明的對象，喻體是用來作比的事物。明喻常用「如、似、猶」等喻詞；暗喻以「是、為」等把兩者連起來；借喻只出現喻體。辨析時須指出相似點和具體作用。

### 論證與修辭：同一例子的不同層次

<a id="k-fe5f82699a693cb7"></a>
**內容：** 比喻論證以生活、自然事物說抽象學習道理，形象、明白、有趣，所有組別見上表。類比論證另有兩組：由木受繩、金就礪推君子博學反省後知明行無過；由積土、積水推積善成德。分類着眼推論關係，與比喻的形象作用可並存。
