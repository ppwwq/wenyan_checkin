# 登樓

[本篇核心](../chapters/essay-13.md) · [知識庫首頁](../README.md) · [跨篇比較](../topics/comparisons.md) · [異解與待核](../audit/REVIEW.md)

## 先回答這個問題

**眼前繁花為何反而令人傷心？**

客居者登樓，因萬方多難而觸景傷情；壯闊江山引出古今與時局的思考，後主廟及梁甫吟把憂國、諷諫和懷才不遇連起來。

## 全篇思路

1. 繁花近樓 → 萬方多難，交代傷心根由
2. 錦江玉壘的遠景 → 古今與朝廷時局
3. 後主廟 → 梁甫吟 → 傷國事兼傷身世

## 最容易混淆

- 樂景可以襯哀情，不能見花便判斷喜悅。
- 後主與諸葛亮的典故各有作用，別把人物混淆。
- 象徵性解讀不能反推詩人精確年齡。

## 原文與語譯

### 原文第1組｜原文與語譯

<a id="k-01c49cde6e86a19c"></a>
**原文：** 花近高樓傷客心，萬方多難此登臨。錦江春色來天地，玉壘浮雲變古今。

<a id="k-3ab638efdf5bef30"></a>
**語譯：** 繁花在高樓近旁盛放，卻使我這客居異地的人傷心；天下到處災難重重，我在此時登樓遠望。錦江一帶的春色，從天地邊際鋪天蓋地湧來；玉壘山上的浮雲變幻不定，使人想到古往今來世事的變遷。


### 原文第2組｜原文與語譯

<a id="k-c61db8275f564c4c"></a>
**原文：** 北極朝廷終不改，西山寇盜莫相侵。可憐後主還祠廟，日暮聊為梁甫吟。

<a id="k-71c75622d0def3fc"></a>
**語譯：** 唐朝朝廷終究會像北極星那樣穩定不移，西山的吐蕃侵略者不要再來侵犯。可嘆昏庸亡國的蜀漢後主，竟仍有祠廟供奉；日暮時分，我姑且吟誦《梁甫吟》，寄託感慨。

## 主旨與思想

### 一句話題旨

<a id="k-a2121b9c009e0e8c"></a>
**題旨：** 登臨家國


### 杜甫｜唐代｜七言律詩

<a id="k-0cf1ba3b8b93efbc"></a>
**內容：** 登樓見春景，卻因國家多難而傷心；仍盼朝廷安定，感嘆報國無路。


### 理解關鍵

<a id="k-8e6aced1d6020182"></a>
**內容：** 繁花是美景，「傷」的原因在「萬方多難」，不是花凋謝。


### 句段核心：原文第1組｜原文與語譯

<a id="k-cf2147ff238a91ba"></a>
**重點：** 國難使美景反添悲情，視線由近花伸向遠方山河。


### 語譯

<a id="k-77745019c938f370"></a>
**內容：** 「萬方多難」說明傷心原因。頷聯一面拓開天地空間，一面由浮雲變化聯想到古今興亡。

<a id="k-d4bf0ed6052c4f4b"></a>
**內容：** 「終」表信念和祝願，「莫」含警告。尾聯諷昏君而思賢相，最後以「聊」寫只能吟詩自遣的無奈。


### 句段核心：原文第2組｜原文與語譯

<a id="k-c1d3736593ccd3ed"></a>
**重點：** 對唐室仍有信心，卻借後主與梁甫吟表達不遇。


### 本句的理解要點

<a id="k-26886c0f648f3ed1"></a>
**內容：** 「萬方多難」說明傷心原因。頷聯一面拓開天地空間，一面由浮雲變化聯想到古今興亡。
「終」表信念和祝願，「莫」含警告。尾聯諷昏君而思賢相，最後以「聊」寫只能吟詩自遣的無奈。


### 古詩、律詩、絕句與排律

<a id="k-495764ddd887e675"></a>
**內容：** 古詩在句數、平仄和對仗方面較自由；律詩通常八句，絕句四句，排律在律詩格律基礎上延長至十句或以上。不能單憑每句五字或七字判定體裁，還要核對句數與格律。


### 押韻與韻腳

<a id="k-7be0a962938b8d24"></a>
**內容：** 韻腳是詩句末尾用來押韻的字。律詩一般偶數句押韻，首句可入韻，也可不入韻；不能把每句最後一字都當作韻腳。判斷古詩用韻要留意古音及韻部，不能只按現代普通話讀音。

## 結構與脈絡

### 內容線索

<a id="k-4a3fadbb4c1759f8"></a>
**內容：** 近花傷心→遠望山河→信念與警告→借典自傷


### 首聯：登樓觸景，總提「傷」

<a id="k-7aefdf6969f063ab"></a>
**內容及作用：** 「花近高樓」交代環境與近景，「客心」點明客居身份，「萬方多難」揭示憂傷根由，「此登臨」扣題。繁花本可悅目，詩人卻因國難而傷心，奠定憂國傷時的基調。


### 頷聯：遠望山川，由景入思

<a id="k-465ac561b9db8f80"></a>
**內容及作用：** 錦江春色蓬勃，從天地邊際湧來，空間廣闊；玉壘浮雲變幻，牽動古今興亡的聯想，時間悠長。既讚歎山河壯麗，又感慨春色依舊、人事全非，憂慮國家前途。


### 頸聯：面對國難，申明立場

<a id="k-649f758feec94a87"></a>
**內容及作用：** 以北極比唐室，表示朝廷可望穩定、國祚長存的信心；斥責、警告吐蕃不要侵犯。既有對恢復秩序的欣慰，又有對侵擾、戰亂民苦的憂慮，表現忠心和抵禦外侮的決心。


### 尾聯：借古諷今，自傷不遇

<a id="k-f288d08f5bc7f711"></a>
**內容及作用：** 由附近後主廟想到昏庸君主仍受供奉，諷刺當朝信用宦官、治國無方，寄望任用賢才；再以諸葛亮未出仕時吟誦《梁甫吟》自況，慨歎年華老去、懷才不遇、報國無門，只能吟詩自遣。


### 章末串連｜重建全文

<a id="k-7d27b5e227073e34"></a>
**內容：** 國難使美景變成傷心的觸媒，也使個人不遇成為報國無門的感慨。


### 傷心有因

<a id="k-55639cf7719b754d"></a>
**怎樣連起來：** 「花近」是眼前近景，「萬方多難」才是傷的根由；遠景把思緒推至古今。


### 信念未失

<a id="k-629c7ef643fea5ab"></a>
**怎樣連起來：** 「終不改」「莫相侵」表守護唐室的願望，與對政治失當的不滿並存。


### 典故收束

<a id="k-a0be2a93fa433e01"></a>
**怎樣連起來：** 後主引諷今，梁甫吟引自況；「聊」把宏大的國家關切收回無從施展的個人。


### 兩個尺度

<a id="k-4a109a6d54d7a76d"></a>
**怎樣連起來：** 天地是空間，古今是時間；近花與遠山、眼前与歷史相接，使一人的傷心擴成對天下興亡的關切。


### 兩種態度相容

<a id="k-04b86fd317ab41c8"></a>
**怎樣連起來：** 信朝廷不改，是不願國家敗亡；諷昏君不任賢，是希望政治改善。忠於國家並不等於滿意一切現況。


### 律詩四聯

<a id="k-c5bfe20c3bb61319"></a>
**內容：** 律詩通常有八句，每兩句為一聯：第1–2句是首聯，第3–4句是頷聯，第5–6句是頸聯，第7–8句是尾聯。頷聯和頸聯通常要求對仗。判斷聯次須從全詩第一句數起，不能把題目節錄的次序當成全詩句次。


<a id="character"></a>
## 人物與情感

### 典故及人物關係

<a id="k-6ea011b7a7982fe2"></a>
**內容：** 「可憐後主還祠廟」寫昏庸亡國的劉禪竟仍受祭祀，「還」帶出不滿。這一典故可理解為借古諷今：批評君主不能善治、不能任賢，同時寄望賢才獲得重用。


### 梁甫吟：借未遇的諸葛亮自況

<a id="k-f76cac6fe36be77e"></a>
**內容：** 諸葛亮未出仕時曾吟《梁甫吟》。杜甫以「聊為梁甫吟」把自己與尚未被任用的賢才相連：有報國之志，卻無從施展，只能姑且吟詩寄懷。「後主」諷昏君，「梁甫吟」思賢相，兩個典故一反一正，共同指向任賢與濟世。


<a id="technique"></a>
## 手法與賞析

### 借景抒情

<a id="k-4f0fe09fdb74db73"></a>
**例句與具體作用：** 繁花春色牽動國難之愁；玉壘浮雲牽動時局興亡之感；眼前後主廟引出对昏君的憤慨；日暮烘托年老不遇。須寫出「何景→何情」。


### 樂景反襯哀情

<a id="k-17097bc4329806fe"></a>
**例句與具體作用：** 「花近高樓傷客心」及「錦江春色來天地」以美好的春景反襯憂國傷時，樂景愈美，哀情愈深；不可說景物本身衰敗淒涼。


### 頷聯對偶

<a id="k-fd15cffe20a743eb"></a>
**例句與具體作用：** 錦江／玉壘、春色／浮雲、天地／古今相對，景物相映，兼寫廣闊空間與悠長時間，造成雄渾氣象。


### 頸聯對偶

<a id="k-d03aa77eeef18b55"></a>
**例句與具體作用：** 北極／西山、朝廷／寇盜等相對，對舉朝廷與侵略者，立場鮮明，語勢整飭。


### 比喻

<a id="k-5169ed31cfdf66f4"></a>
**例句與具體作用：** 北極星的穩定比朝廷不改；星的穩定連到對唐室的信念。

<a id="k-b80ffaea621b9331"></a>
**內容：** 比喻把兩種不同而具有相似點的事物聯繫起來。本體是要說明的對象，喻體是用來作比的事物。明喻常用「如、似、猶」等喻詞；暗喻以「是、為」等把兩者連起來；借喻只出現喻體。辨析時須指出相似點和具體作用。


### 借代

<a id="k-def8d2cb6f553ce3"></a>
**例句與具體作用：** 「西山」代指吐蕃一方，須結合背景說明所指，不能只答山名。


### 象徵／景中寓比

<a id="k-3592ea6e27a5d1de"></a>
**例句與具體作用：** 浮雲變幻象徵世事不定；日暮象徵年華老去。也可以浮雲作景中寓比。


### 雙關

<a id="k-69df89bf09fb69ba"></a>
**例句與具體作用：** 「變」既寫浮雲形態改變，又引出古今世事變遷，將自然與人事相聯。


### 用典、借古諷今

<a id="k-af2f57ea667ec897"></a>
**例句與具體作用：** 後主亡國而受祀，諷刺當朝信用宦官、治理失當；梁甫吟借諸葛亮未遇時的行為自況，表達有志難伸。


### 呼應

<a id="k-7391c52f26f86a78"></a>
**例句與具體作用：** 「西山寇盜」回應「萬方多難」；「錦江春色」接「花近高樓」。也可把奇數句的花、春色、朝廷與偶數句的多難、浮雲古今、寇盜分線相承。


### 江山與人事對照

<a id="k-4915cf4f6d61873c"></a>
**例句與具體作用：** 常新、壯麗的山川，對照反覆多變的人事，使憂國傷時不局限於一時一地。


### 賦、比、興

<a id="k-b8fc0acf37014c2d"></a>
**例句與具體作用：** 見花而起情，可從「興」理解；浮雲景中寓比；西山寇盜陳述現實，屬賦寫。此為官方賞析角度，與具體修辭名目並列理解。


### 煉字

<a id="k-1110ec63d4866572"></a>
**例句與具體作用：** 「近」定近景、「暮」定時間並含老去之感；又以「近」引向錦江、玉壘遠景，以「暮」見詩人徜徉已久，兩字合見空間廣闊、時間綿長；「來」把春色寫得迎面湧來、鋪天蓋地；「變」連接時空與世事；「終」寫信念；「莫」帶警告與決心；「還」寫不應而竟然；「聊」寫不甘而只能如此。


### 語言與風格

<a id="k-e8a44d25ca6aa1fd"></a>
**例句與具體作用：** 實詞密集，對仗凝練，時空交織，景中含情，意蘊沉鬱；不能以「沉鬱」取代具体情感分析。


### 用典

<a id="k-a7122709bcdd3568"></a>
**內容：** 用典是引用或化用前人語句、故事，把既有含義帶入作品。分析時依次說明典故出處、原來意思、作者如何沿用或轉化，以及它表達的情感志趣。只寫「用了典故」未能交代作用。
