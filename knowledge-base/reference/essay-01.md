# 論仁、論孝、論君子

[本篇核心](../chapters/essay-01.md) · [知識庫首頁](../README.md) · [跨篇比較](../topics/comparisons.md) · [異解與待核](../audit/REVIEW.md)

## 先回答這個問題

**仁、孝、君子怎樣連成一套修養要求？**

仁是內在道德原則；孝把關愛、尊敬和禮落實於事親；君子則把正當原則實踐為穩定言行。讀十六則時，應辨清各則的對象、條件和重點，再串連三個主題。

## 全篇思路

1. 論仁：安仁與利仁 → 守仁 → 克己復禮 → 取捨時不害仁
2. 論孝：生死以禮 → 養而有敬 → 幾諫而敬 → 知年而喜懼
3. 論君子：修己、慎言力行，以義為質，以禮行之

## 最容易混淆

- 利仁者同樣行仁，不能把他等同不仁者。
- 孝不等於盲從；『幾諫』要求婉轉規勸。
- 第5則『無違』連着禮；第7則『不違』須保留語境及異解，不能混成同一詞解。

## 原文與語譯

### 第01則｜安仁與利仁

<a id="k-34d5e75c8793f6d1"></a>
**原文：** 子曰：「不仁者，不可以久處約，不可以長處樂。仁者安仁，知者利仁。」

<a id="k-645eaab7e80c0c9e"></a>
**語譯：** 孔子說：「沒有仁德的人，不能長久安於窮困，也不能長久安於安樂。仁者安於實踐仁德；知者認識到行仁的利益或價值，因此實踐仁德。」


### 第02則｜時刻守仁

<a id="k-480da5f7ff2ee80a"></a>
**原文：** 子曰：「富與貴，是人之所欲也；不以其道得之，不處也。貧與賤，是人之所惡也；不以其道得之，不去也。君子去仁，惡乎成名？君子無終食之間違仁，造次必於是，顛沛必於是。」

<a id="k-cc7187f906d720fd"></a>
**語譯：** 孔子說：「有錢、地位高，是人人都想要的；但若不是用正當方法得到，君子就不接受。貧窮、地位低，是人人都不想要的；但若不能用正當方法擺脫，君子就寧可保持原來的處境。君子若離開仁德，怎麼還能有君子的名聲？即使只是一頓飯的短時間，也不能違背仁德；匆忙時如此，生活困苦、流離失所時也如此。」


### 第03則｜克己復禮

<a id="k-d78177d4faff83f3"></a>
**原文：** 顏淵問仁。子曰：「克己復禮為仁。一日克己復禮，天下歸仁焉。為仁由己，而由人乎哉？」顏淵曰：「請問其目。」子曰：「非禮勿視，非禮勿聽，非禮勿言，非禮勿動。」顏淵曰：「回雖不敏，請事斯語矣。」

<a id="k-2ad7b460441b69cd"></a>
**語譯：** 顏淵請教甚麼是仁。孔子說：「約束自己，使言行回到禮的要求，就是仁。一旦做到克己復禮，天下人就會稱許你有仁德。實踐仁德在於自己，難道在於別人嗎？」顏淵說：「請問具體的條目。」孔子說：「不合禮的事不看，不合禮的話不聽、不說，不合禮的事不做。」顏淵說：「我雖然不夠聰敏，請讓我實踐這些教導。」


### 第04則｜殺身成仁

<a id="k-f5919e56a0c2bd47"></a>
**原文：** 子曰：「志士仁人，無求生以害仁，有殺身以成仁。」

<a id="k-40c26dc4fdc2b895"></a>
**語譯：** 孔子說：「有志向、有仁德的人，不會為了保住性命而損害仁德；必要時，會犧牲自己的生命來堅守仁德。」


### 第05則｜生死以禮

<a id="k-e2bde2f407c29990"></a>
**原文：** 孟懿子問孝。子曰：「無違。」樊遲御，子告之曰：「孟孫問孝於我，我對曰，無違。」樊遲曰：「何謂也？」子曰：「生，事之以禮；死，葬之以禮，祭之以禮。」

<a id="k-b1c06bfd0b07d846"></a>
**語譯：** 孟懿子問怎樣才算孝。孔子說：「不要違背禮。」樊遲替孔子駕車時，孔子告訴他：「孟孫向我問孝，我回答他：不要違背禮。」樊遲問：「這是甚麼意思？」孔子說：「父母在世時，依禮侍奉他們；父母去世後，依禮安葬和祭祀他們。」


### 第06則｜養而有敬

<a id="k-111c2f692507a12a"></a>
**原文：** 子游問孝。子曰：「今之孝者，是謂能養。至於犬馬，皆能有養；不敬，何以別乎！」

<a id="k-50c450afe8e05c18"></a>
**語譯：** 子游問怎樣才算孝。孔子說：「現在所謂的孝，只是能供養父母。可是，狗和馬也能得到飼養。如果不尊敬父母，那麼供養父母和飼養犬馬有甚麼分別呢？」


### 第07則｜幾諫與尊敬

<a id="k-91717aef6b836f68"></a>
**原文：** 子曰：「事父母幾諫，見志不從，又敬不違，勞而不怨。」

<a id="k-71bb886fe48b5add"></a>
**語譯：** 孔子說：「侍奉父母，若他們有過錯，要婉轉勸止。看到自己的勸告沒有被接納，仍然尊敬父母，不冒犯他們；雖然擔憂，也不抱怨。」


### 第08則｜知年與喜懼

<a id="k-34c6d7beefac27f6"></a>
**原文：** 子曰：「父母之年，不可不知也。一則以喜，一則以懼。」

<a id="k-44776b813d0e2ced"></a>
**語譯：** 孔子說：「父母的年紀，子女一定要知道。一方面因他們長壽而高興，另一方面又因他們年老而擔憂。」


### 第09則｜修身與擇友

<a id="k-43ccd79365d4320a"></a>
**原文：** 子曰：「君子不重則不威；學則不固。主忠信。無友不如己者。過則勿憚改。」

<a id="k-563086542ecf9327"></a>
**語譯：** 孔子說：「君子若不莊重，就沒有威儀；即使學習，所學也不能鞏固。做人以忠誠、誠信為根本。不與不同道的人交朋友。有過錯，就不要害怕改正。」


### 第10則｜坦蕩與戚戚

<a id="k-67f8c55d60cd749f"></a>
**原文：** 子曰：「君子坦蕩蕩，小人長戚戚。」

<a id="k-3c37301feb70c1b6"></a>
**語譯：** 孔子說：「君子心裏坦然，胸襟開闊；小人卻經常憂愁不安。」


### 第11則｜內省不疚

<a id="k-2ab0f00fa49aa6ea"></a>
**原文：** 司馬牛問君子。子曰：「君子不憂不懼。」曰：「不憂不懼，斯謂之君子已乎？」子曰：「內省不疚，夫何憂何懼？」

<a id="k-04a9d702aaa2b2b0"></a>
**語譯：** 司馬牛問怎樣才算君子。孔子說：「君子不憂愁、不害怕。」司馬牛追問：「只要不憂愁、不害怕，就算君子了嗎？」孔子說：「反省自己的言行，沒有做過虧心事，那還有甚麼要憂愁、害怕的呢？」


### 第12則｜成人之美

<a id="k-5e6686d9fa067088"></a>
**原文：** 子曰：「君子成人之美，不成人之惡。小人反是。」

<a id="k-b6b005a1091186f4"></a>
**語譯：** 孔子說：「君子會幫助別人做好事，不會幫助別人做壞事。小人的做法剛好相反。」


### 第13則｜慎言力行

<a id="k-c3793624eee40b86"></a>
**原文：** 子曰：「君子恥其言而過其行。」

<a id="k-2898b801ae91565a"></a>
**語譯：** 孔子說：「君子會因自己說的話超過實際做的事，即說得多、做得少，而感到羞恥。」


### 第14則｜義禮孫信

<a id="k-1b1cd39c75fb0cc4"></a>
**原文：** 子曰：「君子義以為質，禮以行之，孫以出之，信以成之。君子哉！」

<a id="k-ec82a09ede8029f7"></a>
**語譯：** 孔子說：「君子以道義為根本，按禮實行，用謙遜的言語表達，以誠實的態度完成。這才是君子啊！」


### 第15則｜病無能

<a id="k-f54e9f50f3d50568"></a>
**原文：** 子曰：「君子病無能焉，不病人之不己知也。」

<a id="k-fd009083bc791144"></a>
**語譯：** 孔子說：「君子擔心的是自己能力不足，不擔心別人不了解自己。」


### 第16則｜求諸己

<a id="k-d204133ad0385497"></a>
**原文：** 子曰：「君子求諸己，小人求諸人。」

<a id="k-4098a260654e052a"></a>
**語譯：** 孔子說：「君子先要求自己做到應該做的事，小人卻只要求別人做到。」

## 字詞與句式

### 「之」的三種用法

<a id="k-2a4cbf1c5cdbe322"></a>
**內容：** 「其言」「其行」是君子自己說的話和做的事。說了卻做不到，君子會感到羞恥。


### 一日

<a id="k-ea0f6919e0f1d0ca"></a>
**詞義：** 一旦

> 語境：顏淵問仁。子曰：「克己復禮為仁。一日克己復禮，天下歸仁焉。為仁由己，而由人乎哉？」顏淵曰：「請問其目。」子曰：「非禮勿視，非禮勿聽，非禮勿言，非禮勿動。」顏淵曰：「回雖不敏，請事斯語矣。」

<a id="k-ddbb05a11a0385b1"></a>
**本文古義：** 一旦

**常見今義：** 一天


### 不仁者

<a id="k-c502bf641e827d27"></a>
**詞義：** 沒有仁德的人

> 語境：子曰：「不仁者，不可以久處約，不可以長處樂。仁者安仁，知者利仁。」


### 不以其道得之

<a id="k-b297146459a1dc40"></a>
**具體指代：** 其道：正當的方法。
之：第一句指富貴，第二句指貧賤。


### 不可不知

<a id="k-67f9d69dfc730ba7"></a>
**詞義：** 不能不知道，必須知道

> 語境：子曰：「父母之年，不可不知也。一則以喜，一則以懼。」


### 不己知

<a id="k-2db253115298353a"></a>
**詞義：** 不了解自己，即不知己

> 語境：子曰：「君子病無能焉，不病人之不己知也。」


### 不敬，何以別乎

<a id="k-69a22e343d730566"></a>
**句式與還原：** 何以即以何：用甚麼；敬後省略父母。


### 不病人之不己知也

<a id="k-cd34fbeee6c5bfe7"></a>
**句式與還原：** 「不己知」為否定句代詞賓語前置，還原「不知己」。


### 不違

<a id="k-4238b4a140cd9d55"></a>
**詞義：** 不觸忤、不冒犯父母

> 語境：子曰：「事父母幾諫，見志不從，又敬不違，勞而不怨。」

> **異解／待核：** 來源另列異解：「不違」本書採不觸忤父母，考查語境另作不違父母意願；不與第5則無違禮混同。


### 主

<a id="k-33a43f454d93c5fb"></a>
**詞義：** 把……作為最基本的原則

> 語境：子曰：「君子不重則不威；學則不固。主忠信。無友不如己者。過則勿憚改。」


### 主謂之間

<a id="k-8021119e6c47ffc0"></a>
**例句：** 不病人之不己知也：人與不己知之間。


### 之

<a id="k-285f101d78cfc8f1"></a>
**詞義：** 指按道義所做的事

> 語境：子曰：「君子義以為質，禮以行之，孫以出之，信以成之。君子哉！」

<a id="k-9084afb1587b1467"></a>
**原句：** 父母之年

**意思：** 的

<a id="k-8560e58829efff1e"></a>
**原句：** 子告之曰

**意思：** 他，指樊遲

<a id="k-d721eff3d6c16874"></a>
**原句：** 生，事之以禮

**意思：** 他們，指父母

<a id="k-cfe5097660fc29cd"></a>
**原句：** 人之不己知

**意思：** 放在主語與謂語之間，不必譯出。

<a id="k-96e4277c8f901201"></a>

### 事

<a id="k-acc7aed414bf637e"></a>
**詞義：** 侍奉

> 語境：孟懿子問孝。子曰：「無違。」樊遲御，子告之曰：「孟孫問孝於我，我對曰，無違。」樊遲曰：「何謂也？」子曰：「生，事之以禮；死，葬之以禮，祭之以禮。」

### 內省

<a id="k-bccfcaecff890a37"></a>
**內容：** 「為仁由己，而由人乎哉？」以反問肯定實踐靠自己。「無求生以害仁，有殺身以成仁」以否定與肯定相對，鮮明表達抉擇。

<a id="k-677eb667bffefb2a"></a>
**內容：** 句式名稱之外，還原語序有助確定誰做甚麼、對誰做。

## 主旨與思想

### 一句話題旨

<a id="k-e7b9d0f54211d16f"></a>
**題旨：** 仁孝與君子修養


### 全篇總覽｜仁、孝、君子與禮

<a id="k-5e329da796ce95a7"></a>
**內容：** 仁是道德核心；孝把關愛落實於親子關係；君子呈現理想人格；禮規範如何合宜地實踐。四者互相連繫，各有着眼點。


### 仁

<a id="k-9222a412bf715706"></a>
**原句：** 克己復禮為仁

**讀懂關係：** 約束自己，使言行合禮；不能只憑感覺判斷對錯。


### 孝

<a id="k-9c253bcf3007eb27"></a>
**原句：** 不敬，何以別乎

**讀懂關係：** 對父母不只供養，還要尊敬；有過則婉勸。


### 君子

<a id="k-51453c44eac7a518"></a>
**原句：** 君子義以為質

**讀懂關係：** 以義為根本，從修身、待人、言行等方面實踐。


### 禮

<a id="k-628834b3b9ab196b"></a>
**原句：** 生，事之以禮

**讀懂關係：** 使關愛與行事符合規範；禮不只是表面禮貌。

<a id="k-a38b91e1c10ff56d"></a>
**意思與關係：** 實踐時符合禮的規範。

<a id="k-d95a1713d8995e32"></a>
**完整要求：** 父母在世時，依禮照顧他們；去世後，安葬和祭祀也要依禮。


### 三部分怎樣連起來

<a id="k-6619f577ab735eb4"></a>
**內容：** 論仁（第1–4則）：為甚麼行仁、如何行仁、困難時如何取捨。
論孝（第5–8則）：把禮、敬、關心和規勸落實於事親。
論君子（第9–16則）：修己、向善、慎言力行，成為有道德修養的人。


### 閱讀次序

<a id="k-efc9fe400592ced7"></a>
**內容：** 原文小編號與右側黑色詞解編號相對應。逐則先看意思，再看原句怎樣說明仁、孝和君子的修養。


### 句段核心：第01則｜安仁與利仁

<a id="k-2d13a013924d9f0d"></a>
**重點：** 安仁出於自覺；利仁由認識行仁的利益或價值而來。


### 語譯

<a id="k-f51b11f6b6e60417"></a>
**內容：** 安仁：把仁德當作自己應守的道理，自然願意實踐，不以利益作前提。利仁：認識到行仁有長遠利益或價值，因而實踐。比較的是行仁動機和道德自覺，不是誰會思考。知者也行仁，不等於不仁。

<a id="k-28fe5064b9153f32"></a>
**內容：** 人都希望富有、地位高，不想貧窮、地位低。孔子認為這很正常，但不能為此做不仁的事。

<a id="k-54ad2c6b2b7ef720"></a>
**內容：** 「克己」是約束自己，結合語境指克制私欲；「為仁由己」說行仁要由自己實踐。兩處「己」都指自己，但不能把後一句理解成依靠私欲。四勿把克己復禮落實到視、聽、言、動。

<a id="k-3a70ea465e7fdfec"></a>
**內容：** 如果保住生命就會損害仁德，君子寧可犧牲自己，也不做違背仁德的事。「殺身」指犧牲自己的生命。

<a id="k-afe55aad47f710cc"></a>
**內容：** 孟懿子先問孝；孔子後向樊遲轉述，樊遲再追問。
下文說生前、死後都要依禮，所以「無違」指不要違背禮。

<a id="k-38ae2d0f3cf0d506"></a>
**內容：** 父母有過，子女應委婉規勸；未被接納，仍保持尊敬。「不違」此處採不冒犯的解釋，與第5則不違禮的「無違」分開。尊敬的態度不等於執行不當要求。

<a id="k-a45477a012b6a0b5"></a>
**內容：** 擇友重在向善，可以與志同道合的人互相砥礪、學習長處。這是修養上的意思，不是按財富、成績或身分把人分高低，也不是拒絕與其他人友善相處。

<a id="k-39a23ba726885976"></a>
**內容：** 君子反省言行而無愧，因而坦然；這份心安有道德標準。「不憂」不表示沒有任何煩惱或責任，也不取消對自身不足的警覺。不能憑一時焦慮便給人貼上「小人」標籤。

<a id="k-3103cc83b4fcba27"></a>

**內容：** 有志向、有仁德的人也珍惜生命，但不會為了活命而做不仁的事。兩者只能選一個時，他們把仁德看得比生命更重要。「無……有……」分別說明不會做甚麼、會做甚麼，使態度更明確。

<a id="k-f238b9a995928bba"></a>
**含義：** 不會為保存性命而損害仁德。


### 有殺身以成仁

<a id="k-647bfa68cb9fe1b4"></a>
**含義：** 當生命與仁德不能兩全時，寧可犧牲生命以成全仁德。


### 句段核心：第05則｜生死以禮

<a id="k-8a04fb851971fca2"></a>
**重點：** 父母生前、死後都須依禮相待。


### 句段核心：第06則｜養而有敬

<a id="k-6236416d06df1b1f"></a>
**重點：** 供養父母，還須真心尊敬。


### 養：外在行為

<a id="k-29fe93b7369138e2"></a>
**意義：** 提供衣食、照顧生活，是盡孝的實際行動。


### 敬：內在態度

<a id="k-b1fa77a4294850a6"></a>
**意義：** 照顧父母時，要讓他們感受到真心的尊重。

<a id="k-6acc2413b14eb2db"></a>
**意義：** 只給父母衣食，卻不尊重他們，仍未做到孝。


### 句段核心：第07則｜幾諫與尊敬

<a id="k-359e0576c15dcf58"></a>
**重點：** 父母有過婉轉勸諫，未納仍敬而不怨。


### 句段核心：第08則｜知年與喜懼

<a id="k-e323debe9cfa15cf"></a>
**重點：** 知父母年歲，既喜其長壽，又懼其衰老。

<a id="k-e0ea59d23db984fe"></a>
**內容：** 可以這樣表達：我既因父母健康長壽而高興，又想到他們漸漸衰老而感到擔憂，因此更想珍惜相處的時間。

<a id="k-c855e8da4f9faaf2"></a>
**內容：** 知年不是只背出歲數，而是把父母放在心上：喜其長壽，憂其衰老，珍惜相處。


### 句段核心：第09則｜修身與擇友

<a id="k-8b684ce6fd09390b"></a>
**重點：** 莊重、認真學習、忠信、擇友向善、勇於改過。

### 句段核心：第10則｜坦蕩與戚戚

<a id="k-b085f9e8af81bc15"></a>

<a id="k-b3002c9f89219b28"></a>
**內容：** 可以這樣表達：我雖然對成績失望，但知道自己已盡力，也沒有作弊，所以能坦然面對，再找出不足。一次焦慮不等於一個人就是小人。

<a id="k-d66956fc9b876598"></a>
**內容：** 不能因一時焦慮便斷定一個人是小人。本文對比修養及心境，不是替所有情緒貼人格標籤。


### 句段核心：第11則｜內省不疚

<a id="k-b3bff743584053b3"></a>
**重點：** 內省無愧，是不憂不懼的根據。


### 句段核心：第12則｜成人之美

<a id="k-a31b6757b7d477f1"></a>
**重點：** 成全別人的善事，不助長惡事。

<a id="k-6b09ac9185c20f45"></a>
**重點：** 以言語超過行動為恥，重視慎言力行。


### 句段核心：第14則｜義禮孫信

<a id="k-d175c19d4013f10e"></a>

### 孫

<a id="k-3ea8b01bf1f535da"></a>

### 信

<a id="k-70041abf2b110c7e"></a>
**意思與關係：** 以誠實、誠信的態度完成；負責是補充。


### 句段核心：第15則｜病無能

<a id="k-f8afe439e0979699"></a>

<a id="k-3559f6f5a0f36752"></a>
**重點：** 先要求自己，盡自己的責任。

<a id="k-0ab0c863966f5aee"></a>

<a id="k-4d3c345996fb9fc2"></a>
**行仁動機與境界：** 缺乏仁德作依歸，不能長久安處貧困或安樂。


### 仁者安仁

<a id="k-671e288e10eccad8"></a>
**行仁動機與境界：** 出於內在道德自覺，安於實踐仁德，不以利益作前提。心安源於合乎仁德。


### 知者利仁

<a id="k-f7ecf84c1323cba8"></a>
**行仁動機與境界：** 認識到行仁的長遠利益或價值，因而行仁；知者同樣肯定、實踐仁德。


### 克己復禮的完整關係

<a id="k-f4c414383d0cd0ba"></a>
**內容：** 克己是約束自己、克制私欲；復禮是使言行合乎禮；四勿指出具體要求。「為仁由己」再說明實踐的主體：靠自己，而不是靠私欲或等待別人代做。

<a id="k-c021e86ece208aef"></a>
**內容：** 比較示範：以行仁動機的道德自覺為準則，仁者行仁出於內在認同，不以得利作條件，因此貧困或安樂都不改所守。知者也行仁，但由認識行仁的利益或價值而實踐。仁者把仁德作為自身應守的準則，道德自覺更充分，因而更可貴。

<a id="k-f465c0cde1570435"></a>
**內容：** 比較重點是動機和道德自覺。不能說仁者不思考，也不能斷言知者遇到不利必定停止行仁。「利仁」的基本理解是知道仁的價值而實行仁。


### 養與敬

<a id="k-ab4f7844aefa69b6"></a>
**完整要求：** 不只給父母衣食和照顧，還要真心尊重他們。


### 幾諫

<a id="k-0cf4c8f97bbb7a3c"></a>
**完整要求：** 父母做錯事，要委婉勸說；即使不被聽取，也要尊重他們，不埋怨。


### 知年

<a id="k-50203d4a2b88ee84"></a>
**完整要求：** 關心父母年歲；因父母長壽而高興，因父母日漸衰老而擔憂，珍惜盡孝機會。


### 「無違」「不違」：分清三個層次

<a id="k-849293f7ce071854"></a>
**內容：** 第5則「無違」指不違禮；第7則「不違」依本篇主解，指不觸忤、冒犯父母。2019年第3題的選項另把「不違」表述為不違父母意願，這是該題的解讀語境，不能把三者混成同一詞義。

### 持續改進

<a id="k-1240569ef835bf03"></a>
**原句與道理：** 「無友不如己者」「過則勿憚改」：擇友向善，互相砥礪，知錯能改。

<a id="k-85f822d39bd5e8a1"></a>
**原句與道理：** 「內省不疚」而「不憂不懼」：行事無愧，才能坦然。


### 待人的方向

<a id="k-bf5e4367b18aa28c"></a>
**原句與道理：** 「成人之美，不成人之惡」：助人成善，不助長過錯。


### 言行的關係

<a id="k-807969063c7034fc"></a>
**原句與道理：** 「恥其言而過其行」：言語超過行動而羞愧，提醒自己慎言力行。


### 行事的根本

<a id="k-bab1968ab80f6f31"></a>
**原句與道理：** 「義以為質」：義貫穿始終，禮、謙遜、誠信共同落實道義。

<a id="k-4059c0e607938060"></a>
**原句與道理：** 「病無能」「求諸己」：在意自身不足，先盡自己應盡的責任。

### 賓語前置

<a id="k-b17e1b6dc6c1f177"></a>
**內容：** 文言常見賓語前置包括否定句中代詞作賓語，以及疑問句中疑問代詞作賓語。例如「不己知」即「不知己」；「吾誰與歸」可按「吾與誰歸」理解。辨認後仍須連同全句翻譯。


### 被動句

<a id="k-4193c85c333637a2"></a>
**內容：** 被動句中主語是動作的承受者。文言可用「見」「於」「為……所……」等標誌，也可不帶標誌而由語意判斷。不能看見「於」或「為」就直接判作被動，須查明動作由誰發出、誰承受。

<a id="technique"></a>
## 手法與賞析

### 簡短而有針對性的語錄

<a id="k-54e3c07b7398114f"></a>
**內容：** 直接記錄孔子的話，以及他和學生的對話。文字雖短，卻包含重要道理。顏淵追問仁應該怎樣實行；司馬牛追問甚麼才算君子，讓孔子進一步說明必須先做到問心無愧。

<a id="k-bcc964bd59372341"></a>
**內容：** 先提出一句重點，再解釋具體怎樣做。例如先說「克己復禮」，再列出四勿；先說「無違」，再說父母生前、死後都要依禮。這種寫法叫領語式，方便讀者掌握重點。


### 仁者／知者

<a id="k-b1403350aecfbeb4"></a>
**所突出之處：** 同樣行仁；安仁出於道德自覺，利仁出於對行仁利益或價值的認識，突出動機與境界的差別。


### 富貴／貧賤

<a id="k-30544de621f3b5db"></a>
**所突出之處：** 人都想得到富貴、擺脫貧困，但所用的方法必須正當。


### 求生害仁／殺身成仁

<a id="k-bbb1aca73589fad3"></a>
**所突出之處：** 不能為了保住性命而違背仁德。


### 養父母／養犬馬

<a id="k-88b9d0e6ae58dbb0"></a>

### 喜／懼

<a id="k-a778c90522886e2d"></a>
**所突出之處：** 父母長壽令人高興；想到他們逐漸衰老，又令人擔憂。


### 君子／小人

<a id="k-0e944f1bbcfda52f"></a>
**所突出之處：** 君子按道義做事、幫助別人做好事，也先要求自己；小人只顧利益、幫人做壞事，卻常怪責別人。


### 君子去仁，惡乎成名？

<a id="k-e460f5e5823d6598"></a>
**所肯定的意思：** 君子若不講仁德，就不配得到君子的名聲。


### 為仁由己，而由人乎哉？

<a id="k-6fcc24ae64e51994"></a>
**所肯定的意思：** 實踐仁德全靠自己。


### 不敬，何以別乎！

<a id="k-715fc9ff804f9f69"></a>
**所肯定的意思：** 照顧父母時必須真心尊敬他們。


### 內省不疚，夫何憂何懼？

<a id="k-51f4de82f1b9e3d5"></a>
**所肯定的意思：** 問心無愧便能不憂不懼。


### 對偶、排比與疊字

<a id="k-dc4bd7afda46fef3"></a>
**內容：** 對偶：「無求生以害仁，有殺身以成仁」突出生命與仁德衝突時的抉擇；「君子坦蕩蕩，小人長戚戚」使兩種心境的分別鮮明。「仁者安仁，知者利仁」「一則以喜，一則以懼」也以兩兩相對的結構，突出行仁動機、事親感受的不同。

<a id="k-248dcd0e1071255d"></a>
**內容：** 排比：「非禮勿視，非禮勿聽，非禮勿言，非禮勿動」從視、聽、言、動列出要求，說明守禮須落實於各方面，重複「非禮勿」加強語勢。「禮以行之，孫以出之，信以成之」也用相近結構並列三項實踐要求，語勢連貫。

<a id="k-a97654eac2bb6694"></a>
**內容：** 疊字：「坦蕩蕩」「戚戚」音節重複，具體呈現坦然寬廣、憂愁不安的心境，兼有音韻節奏。

<a id="k-2842f42fb013ecc2"></a>
**內容：** 「終食之間」是一頓飯的短時間。用很短的時間來說明君子也不能離開仁德，突出片刻不離、時刻堅守。

<a id="k-7124d40fe62da3f9"></a>
**內容：** 內容上的對比與形式上的對偶可以同時成立。

要說清楚這個手法突出甚麼道理，不能只寫「生動形象」。


### 反問與設問

<a id="k-ddc9b9745c7ea378"></a>
**內容：** 反問用疑問形式表達已確定的意思，通常不需回答，以加強語氣；設問先提出問題再作回答，引導讀者理解。判斷時看句子在上下文的作用，不能只憑問號。


### 對比與襯托

<a id="k-c675702b30a5bafa"></a>
**內容：** 對比把兩方並置，突出差異，兩方都參與表意；襯托有主次，以陪襯的一方突出主要對象。分析須指出哪兩方、在哪一方面形成關係，以及這個關係如何支持文意。

<a id="k-47a13fae0a6715eb"></a>
**內容：** 生活例子：考試已認真準備、誠實作答，成績未如理想，仍能坦然檢討；若只怕排名落後、被人看低，便容易反覆焦慮。


### 生活中的言行相符

<a id="k-e4719e2d77b1ce92"></a>
**內容：** 生活例子：小組報告時答應完成一半工作，最後卻沒有交出成果，讓同學替自己補做。

<a id="k-901e5e55616a197f"></a>
**內容：** 可以這樣表達：我想到自己承諾很多，實際卻做得很少，還拖累了同學，便感到羞愧；我應向他們道歉，並補回應做的工作。


### 反省：把注意力放回自己

<a id="k-fc28283fb21df818"></a>
**內容：** 生活例子：小組簡報未被選中，先檢查自己的內容是否清楚、準備是否充分，而不是一味怪同學或評判。


### 時刻、境遇、生命：三重要求

<a id="k-10a70052e13dfa7a"></a>
**內容：** 即使只是一頓飯的短時間，也不能違背仁德；遇到突然變故、生活困苦時也一樣。到了生命與仁德只能選一個的時候，仍要堅守仁德。


### 勸諫未被接納時的表達

<a id="k-ed972ce3763a4249"></a>
**內容：** 生活表達：父母請你轉發未核實的消息，你可說：「我怕錯誤消息影響你和別人，所以暫時不代轉發。我願意和你一起查清楚，也會耐心聽你的想法。」這同時表達尊重、擔憂和不助長過失的立場。

### 《魚我所欲也》：生與仁義

<a id="k-73126ec0e5f22c40"></a>
**內容：** 《論語》說「有殺身以成仁」，《魚我所欲也》說「二者不可得兼，舍生而取義者也」。共同點是生命與道德要求衝突而不能兩全時，仍選擇道德。前者着重成全仁德；後者着重取義，並以接受不合禮義的萬鍾作反面對照，警惕因利益失去本心。仁與義相關，但不是同一個詞。


### 《廉頗藺相如列傳》：以義為本與改過

<a id="k-4ddf12042d2afe77"></a>
**內容：** 藺相如說「先國家之急而後私讎也」，並以避讓廉頗的行動顧全趙國。這可與「義以為質」相比：以正當的公義為根本，約束私人意氣。完璧歸趙雖有履諾的一面，單憑履約不能證明相如曾因言過其行而羞恥，故不直接套作「恥其言而過其行」的例證。

<a id="k-3de2ab1424ce35da"></a>
**內容：** 廉頗得知相如的用心後，「肉袒負荊」，登門請罪，承認自己不懂相如的寬厚。這與「過則勿憚改」相通：認清過失後，願意放下身分和面子，以行動改正。


### 《岳陽樓記》：憂的對象

<a id="k-690dae2a6a22ac9a"></a>
**內容：** 君子以「內省不疚」說明不憂不懼的根據；古仁人「居廟堂之高則憂其民；處江湖之遠則憂其君」，憂的是百姓與君主。前者重在道德自省後的坦然，後者重在公共責任；共同點是不以個人得失為中心。君子的「不憂」並不排斥憂國憂民。


### 仁者與君子

<a id="k-57a2ceac15075b73"></a>
**內容：** 「仁者安仁」着重與仁德的關係；「君子義以為質」等章句呈現君子多方面的修養要求。「君子去仁，惡乎成名？」說明君子不能離仁，所以兩者相通；但稱謂的着眼點不同，不能當成毫無分別的同義詞。
