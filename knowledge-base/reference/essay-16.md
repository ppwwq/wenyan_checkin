# 青玉案・元夕

[本篇核心](../chapters/essay-16.md) · [知識庫首頁](../README.md) · [跨篇比較](../topics/comparisons.md) · [異解與待核](../audit/REVIEW.md)

## 先回答這個問題

**滿城繁華為何最後收在燈火闌珊的一人？**

燈火、車馬、音樂、盛裝遊人構成繁華背景，反覆尋覓後突然發現闌珊處的那人。熱鬧與冷落、群體與個體的反差突出其形象；寓意解讀應與字面情節分層。

## 全篇思路

1. 上片多感官描繪盛景 → 下片盛裝女子經過
2. 千百度反覆尋覓 → 驀然回首
3. 燈火闌珊處那人 → 反襯獨特形象

## 最容易混淆

- 『玉壺』『星如雨』有不同解釋，不能寫成已排除異說。
- 尋人是字面情節；孤高自持是寓意解讀，需另交代依據。
- 結尾重心在那人，前面的繁華須連回反襯作用。

## 原文與語譯

### 上片｜原文與語譯

<a id="k-0119073eb53999e8"></a>
**原文：** 東風夜放花千樹，更吹落、星如雨。寶馬雕車香滿路。鳳簫聲動，玉壺光轉，一夜魚龍舞。

<a id="k-d979c50dd5aed959"></a>
**語譯：** 春風吹拂的夜晚，滿城花燈像千樹繁花一下盛放，又像吹落了如雨點般的煙花。名貴駿馬拉着華麗雕車經過，路上瀰漫車中人的衣鬢香氣。簫樂四處繚繞，月光照射的位置隨時間轉移，魚形、龍形的彩燈整夜舞動。


### 下片｜原文與語譯

<a id="k-c75768bbb0f7e6b1"></a>
**原文：** 蛾兒雪柳黃金縷，笑語盈盈暗香去。眾裏尋他千百度；驀然迴首，那人卻在、燈火闌珊處。

<a id="k-0e66b50369dfb863"></a>
**語譯：** 婦女戴着蛾兒、雪柳、金縷等華美頭飾，儀態美好，帶着笑語、幽香從眼前經過。我在人群中反覆尋她千百次；忽然回頭，才發現那個人獨自站在燈火稀疏暗淡的地方。

## 主旨與思想

### 一句話題旨

<a id="k-d26d33c9f48116ed"></a>
**題旨：** 燈火與尋覓


### 理解關鍵

<a id="k-30901b8f54196bb3"></a>
**內容：** 那人的孤高可作寄託解讀；不能直接把尋人敘事改成已證實的生平事件。


### 句段核心：上片｜原文與語譯

<a id="k-2854e644e15e3b6b"></a>
**重點：** 燈火、車馬、音樂與魚龍舞，合寫元夕的繁華。


### 句段核心：下片｜原文與語譯

<a id="k-cc8dfff7e3b9736d"></a>
**重點：** 盛裝人群襯出那人的不同，尋找由反覆轉為驀然得見。


### 語譯

<a id="k-958a586b2bd20277"></a>
**內容：** 千百度極言尋找之多，驀然寫發現的突然。那人不在熱鬧中心，位置上的反差支持其孤高形象。


### 主旨、那人形象與不同解釋

<a id="k-36009fff7df0a552"></a>
**內容：** 詞面為元夕尋人。常見寄託是以那人不慕繁華、自甘寂寞、孤高耿介，表作者不隨波逐流、不與世俗同流的品格；也可說盼望高潔知己、不滿國家動盪而人們沉醉逸樂苟安。那人與眾女不同：眾女盛裝嫵媚、穿梭擁擠喧鬧人群；她獨站燈火疏落處，不為繁華所動。這是孤高脫俗，不能改成高傲冷漠或若即若離。

<a id="k-8e51d760b6d9bc5d"></a>
**內容：** 補充理解：尋人也可讀成追求知己或理想。詞人沒有直接宣布寓意，而是讓繁華人群與闌珊處的那人形成反差；因此，解釋孤高自持時，要從這個反差說起。得見的驚喜與末景的幽靜可以並存。


### 理解補充

<a id="k-b3dd67a1aa3eee8f"></a>
**內容：** 本篇主線以「星」為煙花、「玉壺」為明月；另有花燈、漏壺等解釋。那人可從愛情尋覓理解，也可寄託不隨俗的高潔理想；後者是寓意解讀，不抹去詞面尋人的故事。

> **異解／待核：** 原資料明示另一解讀；須連同語境閱讀。此為文字提示，未判定所有解釋同等成立。


### 本句的理解要點

<a id="k-ce6014e60b1fc733"></a>
**內容：** 視覺、聽覺和嗅覺共同營造熱鬧；熱鬧寫得充分，才更能反襯最後燈火闌珊處的人。
