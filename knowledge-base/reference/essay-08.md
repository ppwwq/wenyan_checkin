# 始得西山宴遊記

[本篇核心](../chapters/essay-08.md) · [知識庫首頁](../README.md) · [跨篇比較](../topics/comparisons.md) · [異解與待核](../audit/REVIEW.md)

## 先回答這個問題

**『始得』究竟得到了甚麼？**

舊遊雖廣，仍未排解被貶後的惴慄；登西山後由看見高峻特立，進至心凝形釋、與萬化冥合。『始得』重在首次得到真正的遊賞體驗。

## 全篇思路

1. 恒惴慄 → 漫遊醉夢醒歸：未得真趣
2. 始指異之 → 登高遠望 → 知西山特立
3. 心凝形釋 → 萬化冥合 → 遊於是乎始

## 最容易混淆

- 『施施』『漫漫』寫外在遊態，不證明內心已快樂。
- 不能把『始得』只譯作第一次出門遊玩。
- 舊遊與西山之遊要比較心境和所得，不能只比路線。

## 原文與語譯

### 第1段｜原文與語譯

<a id="k-3d4904855ee705c7"></a>
**原文：** 自余為僇人，居是州，恒惴慄。其隙也，則施施而行，漫漫而遊。日與其徒上高山，入深林，窮迴溪，幽泉怪石，無遠不到。到則披草而坐，傾壺而醉。醉則更相枕以臥，臥而夢。意有所極，夢亦同趣。覺而起，起而歸。以為凡是州之山有異態者，皆我有也，而未始知西山之怪特。

<a id="k-d2a87a98353bdb0b"></a>
**語譯：** 自從我受罰被貶，居住在永州，便常常恐懼不安。有空時，就緩緩行走、隨意遊覽。每天與同伴登高山、入深林，走到曲折溪流的盡頭；幽僻的泉水、奇形怪狀的山石，無論多遠，沒有不到的。到了便撥草而坐，倒盡壺中的酒喝醉。醉後輪流互相枕靠着躺下，睡着做夢；心意想到哪裏，夢也往那裏。睡醒起身，起身回去。自以為這州所有形態奇異的山都遊過了，卻未曾知道西山的奇異卓絕。


### 第2段｜原文與語譯

<a id="k-d489c833ba0552dd"></a>
**原文：** 今年九月二十八日，因坐法華西亭，望西山，始指異之。遂命僕人，過湘江，緣染溪，斫榛莽。焚茅茷，窮山之高而止。

<a id="k-0d50eb480d4bce6c"></a>
**語譯：** 今年九月二十八日，因為坐在法華寺西亭，遠望西山，才指着它覺得奇異。於是命令僕人，渡過湘江，沿着染溪，砍掉叢雜的草木，燒去茂密的茅草，一直開路到山的最高處才停止。


### 第3段｜原文與語譯 1

<a id="k-83f8cea621969855"></a>
**原文：** 攀援而登，箕踞而遨，則凡數州之土壤，皆在衽席之下。其高下之勢，岈然洼然，若垤若穴，尺寸千里，攢蹙累積，莫得遯隱。

<a id="k-b0e516a9379f6518"></a>
**語譯：** 攀援登頂，伸開兩腿席地而坐，隨意遠望，附近數州的土地都在坐席之下。高低起伏的地勢，深邃低窪，像蟻穴外的小土堆、像洞穴；千里景物縮在眼前尺寸間，密集重疊，無處隱藏。


### 第3段｜原文與語譯 2

<a id="k-801941ffe6dbd651"></a>
**原文：** 縈青繚白，外與天際，四望如一。然後知是山之特立，不與培塿為類。悠悠乎與顥氣俱，而莫得其涯；洋洋乎與造物者遊，而不知其所窮。

<a id="k-56aae9a217c8929b"></a>
**語譯：** 青山白水縈繞，遠與天接，四望渾然一體。這才知道西山卓絕獨立，與小丘不同類。心神悠遠，彷彿與天地元氣同在，不知其邊際；廣大無盡，彷彿與大自然同遊，不知其盡頭。


### 第4段｜原文與語譯

<a id="k-dd3c9d808e82a24c"></a>
**原文：** 引觴滿酌，頹然就醉，不知日之入。蒼然暮色，自遠而至，至無所見，而猶不欲歸。心凝形釋，與萬化冥合。然後知吾嚮之未始遊，遊於是乎始，故為之文以志。是歲元和四年也。

<a id="k-fe2b48e14c9c58b0"></a>
**語譯：** 舉起酒杯斟滿酒，東歪西倒，將要醉了，竟不知道太陽已落山。蒼茫暮色從遠處而來，直至甚麼也看不見，我仍不想回去。心神凝聚安定，形體的束縛彷彿解開，與自然萬物暗合為一體。這才知道我從前不算真正遊覽過，真正的遊覽從這次才開始，所以寫下這篇文章記述此事。這一年是元和四年。

## 字詞與句式

### 「故為之文以志」的解釋層次

<a id="k-0163dfd0324e21b2"></a>
**內容：** 「故為之文以志」說明寫作的緣由和目的。「之」可作「這」理解，即為這次宴遊作文章記錄；整句也可理解為因此作文以記述。

<a id="k-9d14bd578ea39d26"></a>
**內容：** 語譯可補語境中省略的「我」或「此事」，不能添出新情節：末段沒有「睡醒才發現天黑」；「未始遊」也不是從未出遊。

## 手法與賞析

### 語譯

<a id="k-591f3ccdfcb3512c"></a>
**內容：** 「若垤若穴」既有比喻，又以周景之小反襯西山之高。「特立」可寄託不與世俗同流的志向。


### 旁批

<a id="k-0b3109e64baebc4c"></a>
**內容：** 山下景物渺小 → 反襯西山高峻。「特立、不與培塿為類」又寄寓高潔自持、不與世俗同流的志向。

<a id="k-c9d6bb1f9260ace6"></a>
**內容：** 「悠悠」「洋洋」是疊詞，也各有詞義；不是單純為押韻而重複。長對偶與疊詞的節奏共同承載景與情。


### 對偶

<a id="k-1d4a686b0d8a499a"></a>
**原文例子：** 施施而行，漫漫而遊。

**表達作用：** 句式整齊、節奏和諧，寫隨意緩行的遊態；聯繫「恒惴慄」，可見藉遊排遣而憂懼未解。


### 排比

<a id="k-7330a979b996e4b4"></a>
**原文例子：** 上高山，入深林，窮迴溪。

**表達作用：** 連列遊覽活動，突出足跡遍及各處。


### 頂真

<a id="k-8bf1ba4e95b7bd93"></a>
**原文例子：** 「傾壺而醉。醉則更相枕以臥，臥而夢」；「覺而起，起而歸」。

**表達作用：** 前句末字接後句開首，把醉、臥、夢、覺、起、歸連成循環，文氣緊接；舊遊的心境見前後對比。


### 明喻

<a id="k-4f3d020191b08ec2"></a>
**原文例子：** 若垤若穴。

**表達作用：** 將俯視地形比作小土堆和洞穴，突出山下景物渺小。


### 誇飾

<a id="k-c4249b9af4b1257d"></a>
**原文例子：** 尺寸千里。

**表達作用：** 極言千里景物盡收眼底，突出山高、視野遼闊。


### 借代

<a id="k-c193eabca58103db"></a>
**原文例子：** 縈青繚白。

**表達作用：** 青代青山、白代白水；以色代物，凝練地呈現山水交纏。

<a id="k-697e8463f295f48f"></a>
**內容：** 借代利用事物之間的關聯，以特徵、部分、材料或相關事物代替本體。比喻依靠相似，借代依靠關聯。答題要說明代指對象及兩者關係。


### 側面描寫／反襯

<a id="k-1cd0c694241a71cc"></a>
**原文例子：** 凡數州之土壤，皆在衽席之下。

**表達作用：** 以山下群山、窪地的低小，側面突出西山高峻。


### 借景抒情

<a id="k-540dd353d79a3418"></a>
**原文例子：** 蒼然暮色……而猶不欲歸。

**表達作用：** 暮色漸深仍不願歸，表現對宴遊所得的留戀。


### 托物言志／自況

<a id="k-92fec25e3842f8be"></a>
**原文例子：** 是山之特立，不與培塿為類。

**表達作用：** 以西山卓立比況自己，寄託高潔、不隨俗的志向。


### 駢散交錯：整齊與靈活並存

<a id="k-eb3419bd5032a5ae"></a>
**內容：** 「施施而行，漫漫而遊」是整齊的駢句；「自余為僇人，居是州，恒惴慄」長短不齊，自然敘述。局部可辨對偶，全段則看駢句與散句交錯的節奏。


### 修辭與作用的分別

<a id="k-bd2088b34c685e34"></a>
**內容：** 「若垤若穴」以相似性構成明喻；以山下之小突出西山之高，則是反襯作用。同一句可以從修辭形式與表達關係兩個角度分析。


### 歷年考查提示

<a id="k-81b39cef9eddcc01"></a>
**內容：** 2019：整段語言特色為駢散交錯，不能只以某一句的對偶代替全段判斷。


### 正襯

<a id="k-f70c971fc4d9b2ee"></a>
**文中關係：** 舊遊已見各山異態，仍驚異西山之怪特。

**具體作用：** 以其他山水之奇，突出西山更奇；寫「始得」的驚喜與可貴。


### 反襯

<a id="k-9dee80cd39f3138e"></a>
**文中關係：** 四周群山、窪地如垤如穴；西山高峻。

**具體作用：** 以山下低小反襯西山高大，從周圍景物側寫山勢。


### 正襯、反襯與對比

<a id="k-429dc77a58c7dbc1"></a>
**內容：** 側面描寫是從周景或登程間接寫西山；反襯是以相反特點突出主體。兩者可同時成立，卻不是同義詞。


### 短句、連續動詞

<a id="k-e2caf34474ce3ba9"></a>
**原文例證：** 過湘江，緣染溪，斫榛莽。焚茅茷。

**節奏與心境：** 動作接連展開，節奏明快，表現開路登山、熱切探勝。


### 長對偶、疊詞

<a id="k-2d5cb7f832d1a1b1"></a>
**原文例證：** 悠悠乎與顥氣俱，而莫得其涯；洋洋乎與造物者遊，而不知其所窮。

**節奏與心境：** 句式相稱，語勢舒展；悠悠、洋洋延展聲情，寫天地悠遠廣大及心境泰然。


### 俯視：「若垤若穴，尺寸千里。」

<a id="k-a57ed9964803ac68"></a>
**景物特點：** 群山窪地低小，千里景物盡收眼底，反襯西山高峻。

**如何連到心境：** 在廣大天地中重新看待個人得失，從被貶的執著中釋放。這是景情關係的理解。


### 環視：「縈青繚白，外與天際，四望如一。」

<a id="k-0086008238ebb8d4"></a>
**景物特點：** 山水交纏、天地相接，四周渾然一體。

**如何連到心境：** 感到自身與自然相融，放下彼此與榮辱的分別。


### 體悟：「與顥氣俱」「與造物者遊」「與萬化冥合」。

<a id="k-b2c08aa88be4adba"></a>
**景物特點：** 由天地廣大，寫到心神同遊和萬物融通。

**如何連到心境：** 從登高觀照深入「心凝形釋」的忘我境界，精神感受逐步深化。


### 景情關係：由俯視到物我相融

<a id="k-4dbff0056ed004da"></a>
**內容：** 環視說觀看四周，平視說視線高低，兩者可以並存。「高峻」不等於已證明是永州最高山；「釋懷」不等於貶謫處境已改或此後永無憂苦。

<a id="k-01e53a652f7c6cc7"></a>
**內容：** 前兩句本為對偶；這裏說感受「逐步深化」，不把三句一律標成層遞修辭。


### 比喻

<a id="k-df8490ace41d9331"></a>
**內容：** 比喻把兩種不同而具有相似點的事物聯繫起來。本體是要說明的對象，喻體是用來作比的事物。明喻常用「如、似、猶」等喻詞；暗喻以「是、為」等把兩者連起來；借喻只出現喻體。辨析時須指出相似點和具體作用。


### 對比與襯托

<a id="k-e4756705eaa03631"></a>
**內容：** 對比把兩方並置，突出差異，兩方都參與表意；襯托有主次，以陪襯的一方突出主要對象。分析須指出哪兩方、在哪一方面形成關係，以及這個關係如何支持文意。

## 比較與應用

### 延伸補充｜人格自況與跨篇比較

<a id="k-10d3e76eeec4762e"></a>
**內容：** 「是山之特立，不與培塿為類」可自況高潔、不隨俗；西山幽僻、直到這次才被發現，又可聯想到才華未被賞識。前者重人格，後者重處境；後者屬寓意解讀，不是原文明言所有人均不識西山。

<a id="k-bcb317f232eb6f82"></a>
**內容：** 《念奴嬌》引文沿用本書「人間」底本；比較重點是各自的困境、轉變與精神寄託，不能只說兩人都看山水。


### 岳陽樓記

<a id="k-522734885677cc37"></a>
**雙方原文依據：** 西山：「與萬化冥合」。
岳陽：「不以物喜，不以己悲」「先天下之憂而憂」。

**共同點與不同方向：** 共同超越個人榮辱；柳宗元由山水取得物我相融的精神解放，范仲淹把憂樂放到君民天下。


### 逍遙遊

<a id="k-860ca83d591fcd1c"></a>
**雙方原文依據：** 西山：「心凝形釋，與萬化冥合」。
逍遙：「無何有之鄉，廣莫之野」「逍遙乎寢臥其下」。

**共同點與不同方向：** 共同突破世俗功利尺度；柳宗元由宴遊改變觀照，莊子用寓言重新理解「無用」的價值。


### 念奴嬌

<a id="k-a76fee7bb9d751c2"></a>
**雙方原文依據：** 西山：「悠悠乎與顥氣俱，而莫得其涯」。
念奴嬌：「人間如夢，一尊還酹江月」。

**共同點與不同方向：** 共同在失意中尋求安頓；柳宗元走向物我冥合，蘇軾經懷古、自傷，再以酹月寄懷。
