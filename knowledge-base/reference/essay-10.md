# 六國論

[本篇核心](../chapters/essay-10.md) · [知識庫首頁](../README.md) · [跨篇比較](../topics/comparisons.md) · [異解與待核](../audit/REVIEW.md)

## 先回答這個問題

**論六國，是為了向誰提出甚麼警告？**

蘇洵以賂秦為敗亡的核心原因，分賂秦者力虧、不賂者失援兩線論證，最後借古諷今，警告治國者勿為積威所劫。這是文章的論證立場，不能當成歷史敗因的完整清單。

## 全篇思路

1. 先破兵戰解釋，再立弊在賂秦
2. 賂秦：土地有限、欲望無厭 → 不賂：失援、附秦或策略失誤
3. 提出抗秦設想 → 勿為積威所劫 → 以六國警告當世

## 最容易混淆

- 作者不是說六國全部直接賂秦。
- 『百倍』等語帶強調作用，不宜當成核實過的統計。
- 『非兵不利』的兵器義與借代軍力須分層處理，不互判為錯。

## 原文與語譯

### 第1段｜原文與語譯

<a id="k-15eddba948ad04d8"></a>
**原文：** 六國破滅，非兵不利，戰不善，弊在賂秦。賂秦而力虧，破滅之道也。或曰：「六國互喪，率賂秦耶？」曰：「不賂者以賂者喪。」蓋失強援，不能獨完，故曰「弊在賂秦」也。

<a id="k-80c2ac586808921f"></a>
**語譯：** 六國破敗滅亡，不是兵器不鋒利，作戰不得法，弊病在於割地賄賂秦國。賄賂秦國而令自己的國力損耗，這是破敗滅亡的原因啊。有人問：「六國相繼滅亡，全都是因為賄賂秦國嗎？」回答說：「不賄賂秦的國家因為賄賂秦的國家而亡，因失去了強大的援助，自然不能獨個兒保全，所以說弊病就在賄賂秦國。」


### 第2段｜原文與語譯 1

<a id="k-3a07bf9a04884fc5"></a>
**原文：** 秦以攻取之外，小則獲邑，大則得城，較秦之所得與戰勝而得者，其實百倍；諸侯之所亡與戰敗而亡者，其實亦百倍。則秦之所大欲，諸侯之所大患，固不在戰矣。思厥先祖父，暴霜露，斬荊棘，以有尺寸之地。子孫視之不甚惜，舉以予人，如棄草芥。

<a id="k-d46b9fdbd0d7733d"></a>
**語譯：** 秦國用武力奪取土地之外，小則得到城邑，大則得到城池。秦國受賄賂得到的土地，跟戰勝而得到的土地相比，實際要多百倍；六國賄賂秦國所喪失的土地，跟戰敗而喪失的土地相比，實際也多百倍；那麼秦國最大的慾望，六國最大的禍患，根本就不在於戰爭了。六國的祖輩，冒着風霜雨露，披荊斬棘，才佔有很少的一點土地。子孫卻不怎麼愛惜這些土地，把土地全部送給別人，好像拋棄小草一樣。


### 第2段｜原文與語譯 2

<a id="k-92bc28888a9a9ccc"></a>
**原文：** 今日割五城，明日割十城，然後得一夕安寢；起視四境，而秦兵又至矣。然則諸侯之地有限，暴秦之欲無厭，奉之彌繁，侵之愈急，故不戰而強弱勝負已判矣。至於顛覆，理固宜然。古人云：「以地事秦，猶抱薪救火，薪不盡，火不滅。」此言得之。

<a id="k-b828f6d88d19f5f7"></a>
**語譯：** 今天割讓五座城池，明天割讓十座城池，然後才換得一夜的安睡。可是起來看看四周邊境，秦國的軍隊又來了。但是六國的土地有限，強暴的秦國的貪慾無窮，你送給他愈多，他侵略你就愈厲害，所以不用戰爭，誰強誰弱，誰勝誰負已能清楚分辨了。終於弄到滅亡的結局，是順理成章的。古人說：「拿土地侍奉秦國，就好比抱着木柴去救火，柴沒燒完，火不熄滅。」這話真有道理。


### 第3段｜原文與語譯 1

<a id="k-24831f7cb30adceb"></a>
**原文：** 齊人未嘗賂秦，終繼五國遷滅，何哉？與嬴而不助五國也。五國既喪，齊亦不免矣。燕趙之君，始有遠略，能守其土，義不賂秦。是故燕雖小國而後亡，斯用兵之效也。至丹以荊卿為計，始速禍焉。

<a id="k-f3bc4c4989aefd05"></a>
**語譯：** 齊國從來不曾賄賂秦國，最後也隨着五國滅亡，為甚麼呢？這是親附秦國而不幫助五國的緣故。五國已經滅亡，齊國也就不能倖免了。燕國、趙國的國君，起初還有遠大的謀略，能守住自己的國土，堅持原則不賄賂秦國。所以燕國雖然是小國而能較後才滅亡，這就是用兵的效果。到了太子丹以荊軻刺秦王作為對付秦的策略，才招致滅亡的禍患。


### 第3段｜原文與語譯 2

<a id="k-ee0078d8857a7b36"></a>
**原文：** 趙嘗五戰于秦，二敗而三勝；後秦擊趙者再，李牧連卻之；洎牧以讒誅，邯鄲為郡，惜其用武而不終也。且燕趙處秦革滅殆盡之際，可謂智力孤危，戰敗而亡，誠不得已。向使三國各愛其地，齊人勿附於秦，刺客不行，良將猶在，則勝負之數，存亡之理，當與秦相較，或未易量。

<a id="k-8b49bd0134cf1a55"></a>
**語譯：** 趙國曾五次跟秦國作戰，兩次失敗而三次勝利。後來秦國兩次攻打趙國，李牧接連擊退了秦軍。及至李牧因遭受讒言誣陷而被殺，邯鄲就變成秦國的一個郡了，真可惜趙國用武力抗秦卻不能堅持到底。況且燕、趙兩國處於秦國快要把其他國家消滅淨盡的時候，可說智謀和軍力都很單薄，被打敗而亡國，確實是不得已的事。假使三國都愛惜自己的國土，齊國人不要去親附秦國，荊軻不去刺秦王，李牧這樣的良將還在，那麼勝敗的運數，存亡的因素，假使跟秦國相比，或許還不容易估量。


### 第4段｜原文與語譯

<a id="k-9b4508a3f7110179"></a>
**原文：** 嗚呼！以賂秦之地，封天下之謀臣；以事秦之心，禮天下之奇才；幷力西嚮，則吾恐秦人食之不得下嚥也。悲夫！有如此之勢，而為秦人積威之所劫，日削月割，以趨於亡！為國者無使為積威之所劫哉！

<a id="k-32423aaf2780cab4"></a>
**語譯：** 唉！如果用賄賂秦國的土地，封賞給天下有謀略的大臣；用侍奉秦國的心意，禮遇天下才智出眾的人才；合力向西抵禦秦國，那麼我恐怕秦國的人連飯也吃不下去了。這多麼可悲啊！六國有這樣的形勢，卻被秦國久積的威勢所脅迫，土地一天天、一月月地割削，以致走向滅亡。治理國家的人不要被別人積累的威勢所脅迫啊！


### 第5段｜原文與語譯

<a id="k-1cb9de32db99f912"></a>
**原文：** 夫六國與秦皆諸侯，其勢弱於秦，而猶有可以不賂而勝之之勢；茍以天下之大，而從六國破亡之故事，是又在六國下矣！

<a id="k-ae6a062e5eddcf95"></a>
**語譯：** 六國跟秦國一樣是諸侯國，他們的勢力比秦國弱，尚且還有可以不用賄賂而戰勝秦國的形勢。如果以一統天下的大國，卻跟隨六國滅亡的舊事，這就連六國也不如了。

## 結構與脈絡

### 內容線索

<a id="k-f9024074a6d944cc"></a>
**內容：** 總論賂秦→賂者力虧→不賂者失援→用才合力→借古諷今


### 一

<a id="k-18c15727e3c485b0"></a>
**內容與層次：** 先否定兵不利、戰不善，再立「弊在賂秦」；分賂秦力虧、不賂失援兩線

**作用及不同分法：** 總論；開門見山、下筆立論、先破後立。設問預先回應「六國是否全賂秦」的質疑，論點直接明確、給人先入印象，後文可從容反覆論證


### 二

<a id="k-75dcde905d77970e"></a>
**內容與層次：** 韓魏楚賂秦：秦受賄所得多於戰勝所得，諸侯賂秦所失多於戰敗所失；祖先艱辛、子孫轻棄；割地多而安寧短；有限國土不能滿足無限秦欲

**作用及不同分法：** 本論的正面申論；「抱薪救火」引用鎖住全段，回應賂秦力虧


### 三

<a id="k-b235bd24c5724a53"></a>
**內容與層次：** 齊附秦不援；燕先守土後派刺客；趙先抗秦後殺良將；失援造成孤危。末反設韓魏楚惜地、齊不附秦、燕不用刺客、趙良將仍在

**作用及不同分法：** 本論另一線，反面申論不賂者仍亡；既遙應首段失援，又由賂秦轉至抗秦。燕趙曾抗秦有效，亦呼應非兵不利、戰不善


### 四

<a id="k-2400251c2bef4f5f"></a>
**內容與層次：** 封謀臣、禮奇才、並力西向；感歎本有形勢卻為秦威所劫，告誡為國者

**作用及不同分法：** 總結前面的分析：吸取歷史教訓、總結論點、回應總論。「為國者」既指六國，也泛指治國者，預開下段諷今


### 五

<a id="k-726efebdc05efc42"></a>
**內容與層次：** 比較六國分裂諸侯與北宋統一大國；勢較有利仍循破亡舊事，更不如六國

**作用及不同分法：** 從六國轉到當世，明示借古諷今、警誡北宋的目的。


### 逐段結構、主旨與論證關係

<a id="k-4da89652c0f802c4"></a>
**內容：** 總論點的完整摘句是「六國破滅，非兵不利，戰不善，弊在賂秦。」兩分論點是「賂秦而力虧，破滅之道也」和「不賂者以賂者喪」，後者須接「失強援，不能獨完」。不能把六國一概寫成直接割地賂秦。

<a id="k-3e61fb7c50e205d1"></a>
**內容：** 齊、燕、趙的個別敗因與共同敗因須分開：齊親秦而不援其他五國，五國亡後不能倖免；燕太子丹派荊軻刺秦引禍，破壞早先守土方略；趙聽讒殺李牧，不能堅持用武。共同處境是賂秦諸侯先亡、失去鄰國後援、勢寡力弱。因此「不賂秦」並不足夠，尚須惜地、用才、團結及堅持抗敵。

<a id="k-37010c738f2a53b7"></a>
**內容：** 第三段末「向使」反設已述錯誤；第四段再把事秦的土地與心力轉作封臣禮才、合力抗秦。兩個都是未實行的方案，不能寫成真實史例；「或未易量」只說尚難估量勝負，不保證必勝。結構表把兩假設併列第四段，是分析欄合併，並非原文段落位置。

<a id="k-28d928545046e9e4"></a>
**內容：** 主旨：以六國因賂秦而亡的歷史教訓，說屈辱求和會自招敗亡，委婉諷諫北宋以史為鑑，改變對遼、西夏輸歲幣苟安的政策，善用人才、備戰禦侮、保國長治久安。六國亡因本來複雜，本文為政論的選材和立意服務，不是完整歷史定論。

## 手法與賞析

### 語譯

<a id="k-d80eac84f55c7916"></a>
**內容：** 割地者國力耗損；不割地者失去援國而難獨存。設問預先處理「是否全都賂秦」的疑問，使論述更周密。

<a id="k-b29719cc2d2f1934"></a>
**內容：** 六國只是分立諸侯，尚可不賂而勝；北宋以天下之大仍循舊事，反襯警告的迫切。「故事」是舊事。


### 下筆立論、先破後立

<a id="k-ab42fc1a36ca4ffc"></a>
**原句／運用：** 「非兵不利，戰不善，弊在賂秦」

**知識與表達效果：** 先破一般兵器戰術解釋，再立賂秦敗因；使論點鮮明、設想較全面，開門見山統領全文。不是先抑後揚


### 兩重設問

<a id="k-bd56d807d334ada8"></a>
**原句／運用：** 「六國互喪，率賂秦耶？」自答不賂因賂者而亡；「何哉？」自答與嬴不援

**知識與表達效果：** 第一重預答反對意見補足總論，第二重引個別因果，論證周密


### 頂真

<a id="k-8381f96479d3a30b"></a>
**原句／運用：** 「弊在賂秦。賂秦而力虧」

**知識與表達效果：** 賂秦接續前後句，連起中心論點與結果，文氣緊密


### 土地得失對比

<a id="k-a6d82153b41bba31"></a>
**原句／運用：** 秦受賄所得／戰勝所得；諸侯賂秦所失／戰敗所失

**知識與表達效果：** 兩組均寫前者百倍，說壯敵自弱、此消彼長，禍患不在戰爭。


### 祖先子孫對比、動之以情

<a id="k-0f9493b645651f25"></a>
**原句／運用：** 「暴霜露，斬荊棘」對「舉以予人，如棄草芥」

**知識與表達效果：** 創業艱辛對輕率棄地，責子孫不孝、不肖，激起痛惜，引君主勿重蹈覆轍


### 代價收益對比

<a id="k-5047b959b661f9cd"></a>
**原句／運用：** 「今日割五城，明日割十城」對「一夕安寢」

**知識與表達效果：** 割地多、快、頻繁卻只短安，顯畏秦情態與策略不智


### 有限無限對比

<a id="k-cd7a7a770575c3c3"></a>
**原句／運用：** 「諸侯之地有限，暴秦之欲無厭」

**知識與表達效果：** 有限土地不能滿足無窮欲望，指出妥協不能長保國家


### 獻地侵略對比

<a id="k-97e565951279fd1d"></a>
**原句／運用：** 「奉之彌繁，侵之愈急」

**知識與表達效果：** 獻地越多，侵略越急，與求安目的相反，反助敵欲


### 引用、比喻論證

<a id="k-d9ec655f1141db9d"></a>
**原句／運用：** 「以地事秦，猶抱薪救火，薪不盡，火不滅」

**知識與表達效果：** 薪＝土地，火＝秦的侵略野心，救火＝阻止侵略求安；割地如添柴，反增秦欲與秦力，地盡而亡。古人之言使論據有依，形象化抽象道理


### 明喻

<a id="k-9b00ab406fe83942"></a>
**原句／運用：** 「舉以予人，如棄草芥」

**知識與表達效果：** 割地如扔不值錢小草，活現子孫不惜祖業


### 舉史例

### 反面設例／假設

<a id="k-4a2dc3cbd163cd5d"></a>
**原句／運用：** 「小則獲邑，大則得城」

**知識與表達效果：** 小大、邑城對舉，具體寫非戰所得規模

**原句／運用：** 「暴霜露，斬荊棘」

**知識與表達效果：** 兩動賓短句寫創業動作，凝練鮮明

<a id="k-27af414033d1247a"></a>

**知識與表達效果：** 兩長句相稱，強調損己益敵兩端


### 借代

<a id="k-629c0eb4d803f466"></a>
**原句／運用：** 「嬴」代秦國；「兵」由兵器借代軍隊兵力

**知識與表達效果：** 前者以君王姓氏代國，後者保存字面兵器義與延伸軍事義

<a id="k-84a3752bb007d959"></a>
**內容：** 借代利用事物之間的關聯，以特徵、部分、材料或相關事物代替本體。比喻依靠相似，借代依靠關聯。答題要說明代指對象及兩者關係。

<a id="k-84a99b6d28ffa516"></a>
**內容：** 語言兼說服力與感染力：開首斷言、末段總括帶出觀點；中間鋪張描寫見艱辛與不肖；比喻、排偶、設問使內容鮮明生動；褒貶、感歎使史論情理兼備。所有手法須連原句和具體作用，不能只列名稱。


### 反問與設問

<a id="k-c0b05852813d8677"></a>
**內容：** 反問用疑問形式表達已確定的意思，通常不需回答，以加強語氣；設問先提出問題再作回答，引導讀者理解。判斷時看句子在上下文的作用，不能只憑問號。


### 對比與襯托

<a id="k-1f36d13737e65b52"></a>
**內容：** 對比把兩方並置，突出差異，兩方都參與表意；襯托有主次，以陪襯的一方突出主要對象。分析須指出哪兩方、在哪一方面形成關係，以及這個關係如何支持文意。


### 比喻

<a id="k-a143e19239fe51c9"></a>
**內容：** 比喻把兩種不同而具有相似點的事物聯繫起來。本體是要說明的對象，喻體是用來作比的事物。明喻常用「如、似、猶」等喻詞；暗喻以「是、為」等把兩者連起來；借喻只出現喻體。辨析時須指出相似點和具體作用。
