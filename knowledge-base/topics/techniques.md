# 修辭、寫作與答題方法

[知識庫首頁](../README.md)

讀手法時依次回答：**怎樣構成 → 原文何處 → 表達甚麼 → 怎樣支持主旨**。同一句可有多種手法，須按題目層次作答。

## 修辭

<a id="k-313c104d4707c505"></a>
**比喻**

- **定義與辨識：** 利用本體與喻體的相似點，以具體、常見的事物說明抽象、生疏的事物或道理。
  明喻：本體＋喻詞（像、似、如、彷彿）＋喻體。
  暗喻：本體＋「是／為／變成／成為／當作」等＋喻體。
  借喻：只出現喻體，省略本體、喻詞；表達較含蓄隱晦。
  作用：使抽象事理具體、形象、易明；答案須指出本體、喻體及相似點。
- **例子與作用：** 明喻：「沉澱着彩虹似的夢。」
  暗喻：「那河畔的金柳，是夕陽中的新娘。」（徐志摩《再別康橋》）
  借喻：「你不妨搖曳着一頭的蓬草。」以蓬草比喻頭髮。（徐志摩《翡冷翠山居閒話》）

<a id="k-e55446bdc8ad0582"></a>
**比擬**

- **定義與辨識：** 借助想像，把物當人、把人當物，或把甲物當乙物。
  擬人：賦予物人的行動、言語、思想感情。
  擬物：把人當物，賦予物的特性或行為；也可把甲物當乙物。
  作用：突出形象或性格，令描寫生動，寄託感情；要說明被賦予甚麼特徵。
- **例子與作用：** 擬人：「成羣的白鷺鷥在凝神養氣，誰也不叫一聲。」（梁容若《我看大明湖》）
  擬物：「十指在翻飛疾走，把驟雨潑落窗格和浮萍。」把十指當鳥和獸來寫。（黃國彬《聽陳蕾士的琴箏》）
  「月徘徊、影零亂」也把月、影人格化。

<a id="k-1cb1981071e67133"></a>
**借代**

- **定義與辨識：** 不用本名，借用與本體密切相關的事物代稱，例如部分代全體、具體代抽象、外表特徵代人物，亦可用工具、產物等代稱。關鍵是關聯替代。
  作用：語言簡潔而具體，突出特徵並引起聯想。
- **例子與作用：** 「我為了明天的麵包及昨日的債務辛勞地工作。」（紀弦《存在主義》）以「麵包」替代糧食；在句中亦令人聯想到生計。

<a id="k-d8aae1dc32b1f3a9"></a>
**象徵**

- **定義與辨識：** 用容易引起聯想的具體符號、事物或形象，間接表現抽象情意、觀念、思想和感情。
  作用：表達含蓄，深化主題，增強感染力；須交代形象與象徵義的關係。
- **例子與作用：** 「爸爸的花兒落了，我也不再是小孩子。」（林海音《爸爸的花兒落了》）花兒落了象徵爸爸去世；後句同時帶出人物成長。

<a id="k-a88780197aa371e4"></a>
**通感（移覺）**

- **定義與辨識：** 把一種感官的詞語移來描寫另一種感官，可與比喻同時出現。
  作用：使難以描摹的感受具體新鮮，擴闊聯想並增強感染力。
- **例子與作用：** 以『渺茫的歌聲』寫清香：聽覺寫嗅覺。

<a id="k-48a52696307b4300"></a>
**對比（對照）**

- **定義與辨識：** 把對立的事物、觀念，或同一事物相反／相對的兩面並列比較，突出差異；分析時須說清雙方及比較角度。
  作用：使差異、優劣或正誤鮮明，突出觀點或情感。
- **例子與作用：** 「朱門酒肉臭，路有凍死骨。」（杜甫《自京赴奉先縣詠懷五百字》）對比貴族奢華與百姓窮苦，揭露當時悲慘的社會狀況。

<a id="k-6720b5c7fac1bae4"></a>
**襯托（映襯）**

- **定義與辨識：** 又稱烘托。有主體和陪襯物之分。
  正襯：用性質相近或相關的事物突出主體，如好的襯更好、大的襯更大。
  反襯：用性質相反或對立的事物突出主體，如壞的襯好、小的襯大。
  作用：令主體特徵更鮮明；答題要明說誰是主體、誰是陪襯。
- **例子與作用：** 「窰裏靜悄悄的，只聽見鍋台後面那隻老黃貓的呼嚕聲。」（路遙《人生》）以聲音反襯窰裏寧靜。

<a id="k-81bd64ba66985749"></a>
**誇張／誇飾**

- **定義與辨識：** 故意言過其實地描寫形象、特徵、作用或程度。
  擴大誇張：往多、快、高、長、強等方面誇大。
  縮小誇張：往少、慢、矮、短、弱等方面縮小。
  超前誇張：把後發生說成先發生或同時發生。
  作用：強化特徵與主觀感受，形成鮮明印象；不可把修辭數量當統計。
- **例子與作用：** 「白髮三千丈，緣愁似个長。」（李白《秋浦歌》）誇大白髮長度，強化愁苦的主觀感受。

<a id="k-d608d4ce21cf9804"></a>
**反語**

- **定義與辨識：** 字面意思與內心真意相反。
  反意正說：褒詞貶用，表面讚賞，實際責罵。
  正意反說：貶詞褒用，表面責罵，實際讚賞。
  作用：產生諷刺或幽默效果，曲折表達憤慨、不滿、自責等感情，引人深思，有時比正說更有力量。
- **例子與作用：** 「我現在想想，那時真是太聰明了！」（朱自清《背影》）用「太聰明」反省自己當時自以為是。

<a id="k-0a998c3ce873c687"></a>
**雙關**

- **定義與辨識：** 在特定語境中，使語句同時具有表面和內裏兩層意思。
  語義雙關：利用一詞多義。
  諧音雙關：利用同音或近音。
  作用：含蓄、風趣，增添言外之意；必須寫出兩層意思。
- **例子與作用：** 「東邊日出西邊雨，道是無晴卻有晴。」（劉禹錫《竹枝詞》）「晴」雙關「情」：一層是天氣晴雨，一層是情感有無。

<a id="k-182d577a3a759275"></a>
**設問**

- **定義與辨識：** 故意設置問題，引起注意、帶動思考；可自問自答、留待下文回答，也可提出問題而不予確定答案。
  作用：引起注意、啟發思考、帶出下文或轉換層次。
- **例子與作用：** 「怎樣才能把一種勞作做到圓滿呢？惟一的祕訣就是忠實……」（梁啟超《敬業與樂業》）屬自問自答。

<a id="k-f65d6cf04ce22631"></a>
**反問（反詰）**

- **定義與辨識：** 只問不答，以問句表達已確定的意思。否定形式的反問可表肯定，肯定形式的反問可表否定；須按語境還原實意。
  作用：加強語氣，使立場鮮明、有不容置辯之感。
- **例子與作用：** 「做工苦，難道不做工就不苦嗎？」（梁啟超《敬業與樂業》）實意是不做工也苦。

<a id="k-86968871b7f8702e"></a>
**引用**

- **定義與辨識：** 援引現成語句或資料，如名言、成語、諺語、格言、詩句、警句、典籍或他人話語。可以原文照錄，也可融入文字；可以註明或不註明出處。
  作用：闡明論點，表達思想感情，或說明內容；視引用材料增加說服力、可信度、權威感或文化意味。
- **例子與作用：** 「陸放翁有一聯詩句：『傳呼快馬迎新月，卻上輕輿趁晚涼。』」（徐志摩《我所知道的康橋》）援引陸游詩句。

<a id="k-f5f9844b50eb9c7f"></a>
**用典**

- **定義與辨識：** 把古書故事、人物事跡或有來歷的詞語融入文句，通常不直接交代完整故事。
  作用：以少總多，含蓄寄託感情、處境或志向，增添歷史文化聯想。
- **例子與作用：** 『梁甫吟』借諸葛亮典故寄託報國志向。

<a id="k-b1e2d6b0c592f0c4"></a>
**呼告**

- **定義與辨識：** 行文中直接呼喚人或物，再向其說話；可分呼人、呼物。可先叫對方引起注意，也可突然撇開一般敘述，向不在面前的人、物傾訴。
  作用：集中感情，增強抒情感染力與現場感。
- **例子與作用：** 「諸君啊！醒醒罷！」（梁啟超《為學》）直接呼喚對方，加強感情與感染力。

<a id="k-dca68d95ab67623d"></a>
**對偶**

- **定義與辨識：** 把字數相等、結構相同或基本相同、意思密切相關的兩個短語或句子對稱排列。可分單句對偶、複句對偶；意思可相對或相反。
  作用：句式整齊勻稱，音律和諧，增強節奏，也可形成對照。
- **例子與作用：** 「浮雲遊子意，落日故人情。」（李白《送友人》）兩句各五字，結構相應。

<a id="k-5e9aa8445b48af4f"></a>
**排比**

- **定義與辨識：** 三個或以上結構相同／相似、語氣一致、意思密切相關的詞組、句子或段落連續排列。後面的句子常重複前句某些詞語。
  作用：強調內容，增強氣勢和節奏，表達強烈感情。
- **例子與作用：** 「燕子去了，有再來的時候；楊柳枯了，有再青的時候；桃花謝了，有再開的時候。」（朱自清《匆匆》）三組句式連續排列。

<a id="k-a1ca809f913956f7"></a>
**層遞**

- **定義與辨識：** 三項或以上按深淺、高低、大小、輕重、多少、遠近、本末、先後等次序遞升或遞降，逐層推進。
  作用：層次分明、環環緊扣、步步深入，形成漸進美；增強說理的說服力或抒情的感染力。
- **例子與作用：** 「籬外有四野的山，繞山的水，抱住水的岸，以及抱住岸的草。」（張曉風《情懷》）由山、水、岸、草逐層推移。

<a id="k-1629e5189c88c2b6"></a>
**反復**

- **定義與辨識：** 為表達需要，使同一詞語或句子一再出現。
  連續反復：接連出現。
  間隔反復：中間隔有其他語句，再次出現。
  作用：加強語勢，強調內容，集中或推進感情。
- **例子與作用：** 「沉默啊，沉默啊！不在沉默中爆發，就在沉默中滅亡。」（魯迅《紀念劉和珍君》）以「沉默」反復強化感情。

<a id="k-e0c1e9b7ac8bb2a4"></a>
**頂真（頂針／聯珠）**

- **定義與辨識：** 以上句末字／詞語作下句開頭，或以前段末句作後段首句，上遞下接，使前後首尾相連。
  作用：語氣連貫，意思環環相扣，音律流暢。
- **例子與作用：** 「將軍百戰死，壯士十年歸。歸來見天子，天子坐明堂。」（《木蘭辭》）「歸／歸來」「天子／天子」接續。

<a id="k-27dfb29be1e4fac5"></a>
**互文**

- **定義與辨識：** 相關意思分寫在上下兩句，理解時須把兩句成分互相補足。
  作用：文字精煉，句式整齊，語意含蓄完整；不能逐句割裂直譯。
- **例子與作用：** 「不以物喜，不以己悲。」（《岳陽樓記》）上下句互相補足：不因外物或個人遭遇而或喜或悲。

<a id="k-3b5a7d9448937ed2"></a>
**疊字／疊詞**

- **定義與辨識：** 相同的字或詞直接重疊使用。
  作用：增強音韻節奏，突出程度、狀態或動作反覆。
- **例子與作用：** 「舟遙遙以輕颺，風飄飄而吹衣。」（陶淵明《歸去來辭並序》）「遙遙」「飄飄」增強音韻，描寫狀態。

<a id="k-648f6fd492752563"></a>
**雙聲**

- **定義與辨識：** 兩個字的聲母相同，組成雙音詞。
  作用：使語音和諧，增強音樂感；辨認時須按讀音而非字形。
- **例子與作用：** 「既自以心為形役，奚惆悵而獨悲。」（陶淵明《歸去來辭並序》）「惆悵」為雙聲例。

<a id="k-c05e1e8da2e5bdb8"></a>
**疊韻**

- **定義與辨識：** 兩個字的韻母相同，組成雙音詞。
  作用：使語音迴環和諧，增強音樂感。
- **例子與作用：** 「景翳翳以將入，撫孤松而盤桓。」（陶淵明《歸去來辭並序》）「盤桓」為疊韻例。

## 修辭與結構

<a id="k-a5412238b6a8e566"></a>
**比喻 vs 借代**

- **定義與辨識：** 相似關係 vs 關聯替代
- **例子與作用：** 『北極』若把朝廷比作北極星，是借喻；『紅領巾』代學生，是借代。

<a id="k-b1f7e932d4213aa5"></a>
**對比 vs 襯托**

- **定義與辨識：** 並列比較差異 vs 用陪襯突出主體
- **例子與作用：** 對比須交代雙方；襯托須進一步分清主體與陪襯物。

<a id="k-f328f85ed83a8f90"></a>
**設問 vs 反問**

- **定義與辨識：** 提出問題帶動思考 vs 問句包含確定意思
- **例子與作用：** 設問可自答，也可不予確定答案；反問須還原已有的肯定或否定意思。

<a id="k-250a9bedf2b6dc7d"></a>
**排比 vs 層遞**

- **定義與辨識：** 三項以上重結構與氣勢 vs 三項以上有程度次序
- **例子與作用：** 同一句可同時成立，但答案要分別指出結構與遞進尺度。

<a id="k-1299b9d4db5485ae"></a>
**引用 vs 用典**

- **定義與辨識：** 援引現成語句／資料 vs 融入有出處的故事或詞語
- **例子與作用：** 關鍵是作者有沒有把典故壓縮進文句，讓背景意義參與表達。

<a id="k-f496ab138ab1fa4f"></a>
**疊字 vs 反復**

- **定義與辨識：** 字詞重疊形成語音形態 vs 為強調而讓語句再現
- **例子與作用：** 『尋尋覓覓』偏疊詞；整句隔段再出現偏反復。

<a id="k-04a96e7cd9b6ae20"></a>
**伏筆 vs 鋪墊**

- **定義與辨識：** 留下後文線索 vs 為重點蓄勢
- **例子與作用：** 伏筆重『日後會應驗』；鋪墊重『先準備氣氛／條件』。

<a id="k-d2b6141dac27c5ff"></a>
**插敘 vs 補敘**

- **定義與辨識：** 主線中插入相關片段後回主線 vs 後文補足前文漏項
- **例子與作用：** 看是否暫時離開主線，以及補充發生在敘述的哪一點。

## 記敘

<a id="k-ced9e7627422ccda"></a>
**順敘**

- **定義與辨識：** 按時間先後或事件發生、發展的順序敘述，是常見、基本的敘事方式。
- **例子與作用：** 清楚交代來龍去脈。

<a id="k-d4496808723430b7"></a>
**倒敘**

- **定義與辨識：** 先寫結局、現況或最突出情節，再回頭按發展順序記述。
- **例子與作用：** 突出中心，製造懸念，吸引閱讀，避免平鋪直敘。

<a id="k-f185b0502261d060"></a>
**插敘**

- **定義與辨識：** 主線暫停，插入相關的過去片段、補充或解釋，之後回到原敘述。
- **例子與作用：** 豐富內容，增加層次，深化主題，使敘述有波瀾。

<a id="k-8f6069c0d2374c5f"></a>
**補敘**

- **定義與辨識：** 前文已提及事件，後文再補充資料或解釋。
- **例子與作用：** 補足因果，揭開先前懸念，使情節完整合理。

<a id="k-966be539a36ebd01"></a>
**散敘**

- **定義與辨識：** 把時間不連貫但意義有聯繫的多件事組織起來。
- **例子與作用：** 從不同側面展現、深化主題，增加深度和廣度。

<a id="k-b06aab462a454a91"></a>
**詳寫與略寫**

- **定義與辨識：** 詳寫是具體細緻地記事；略寫是粗略交代。與主題、高潮或人物轉變密切的情節詳寫；關係較小的略寫。
- **例子與作用：** 略寫仍可作過渡或總結。詳略有致能突出中心，避免內容瑣碎煩冗。

<a id="k-1dc57515584a8477"></a>
**第一人稱**

- **定義與辨識：** 以當事人「我」的身分和角度記述親身經歷。
- **例子與作用：** 真實、親切，便於直接抒情；視野受「我」所知限制。

<a id="k-537258324f92932f"></a>
**第三人稱**

- **定義與辨識：** 以旁觀者的身分和角度敘述人物、事件或別人的經歷。
- **例子與作用：** 便於交代全貌，敘述範圍較廣。

<a id="k-7ad521134feabe8a"></a>
**選用敘事人稱**

- **定義與辨識：** 因應題材和內容選擇；一般維持同一敘事人稱，轉換時要交代清楚。
- **例子與作用：** 避免敘事視角混亂。

<a id="k-794dfa85000fca04"></a>
**時間線索**

- **定義與辨識：** 以時間推移串連人物經歷與事件。
- **例子與作用：** 《一件小事》按「我」乘人力車遇意外、與車夫處理不同、最後結果的順序敘述。

<a id="k-aff5f2c0bec46e4f"></a>
**空間線索**

- **定義與辨識：** 按空間位置的變換敘述。
- **例子與作用：** 《大明湖》以不同景物帶讀者一步步遊覽。

<a id="k-9b93949a3d0b521d"></a>
**事物線索**

- **定義與辨識：** 圍繞具體事件或物件，組織相關人和事。
- **例子與作用：** 《珍珠鳥》以人鳥相處帶出「信賴，往往能創造出美好的境界」。

<a id="k-729f03bb542ead2d"></a>
**人物線索**

- **定義與辨識：** 圍繞人物的性格或事跡組織材料。
- **例子與作用：** 《楊修之死》以楊修的行事為人，揭示他被處死的原因。

<a id="k-85beaa674c545888"></a>
**思想感情線索**

- **定義與辨識：** 以一種感情，或感情的變化貫串全文。
- **例子與作用：** 《鄉居閑情》以熱愛鄉居之情串連鄉間環境與生活。

## 描寫

<a id="k-5bd021bd02a8748d"></a>
**直接／正面描寫**

- **定義與辨識：** 直接描繪人物、事物或景物本身的形態和特徵。
- **例子與作用：** 具體呈現對象；人物可分外貌、行動、語言、心理四項。

<a id="k-cb0f1798b9ade725"></a>
**外貌／肖像描寫**

- **定義與辨識：** 寫容貌、神情、服飾、身材等外部特徵；也留意不同情況下的神態、表情變化。
- **例子與作用：** 突出人物形象，表現性格；不能只列外表資料。

<a id="k-59316c69f487c797"></a>
**行動描寫**

- **定義與辨識：** 描摹動作、行為舉止。
- **例子與作用：** 從行動看背後的思想、動機及性格。

<a id="k-88391726f2b8a6a3"></a>
**語言描寫**

- **定義與辨識：** 寫獨白或對話，包括說話的內容和語氣。
- **例子與作用：** 呈現人物的思想感情、個性、身分和經歷；言為心聲。

<a id="k-6eee9677d4477989"></a>
**心理描寫**

- **定義與辨識：** 寫特定環境中的感覺、心態、聯想等，可用人物內心獨白或敘述者描述。
- **例子與作用：** 展示內心世界，了解性格及思想感情。

<a id="k-86d553f405bf30f0"></a>
**間接／側面描寫**

- **定義與辨識：** 通過別人或其他事物，間接烘托主要對象。
- **例子與作用：** 強化特徵，讓讀者聯想對象形象，增加閱讀趣味。

<a id="k-989aafa6674d2422"></a>
**旁人反應作襯托**

- **定義與辨識：** 寫對象身邊人物對他的印象、感受，或周圍事物的反應。
- **例子與作用：** 從側面突出主體形象；答題要交代誰烘托誰。

<a id="k-5c27db807a668ec8"></a>
**環境烘托**

- **定義與辨識：** 在特定時間、地點，圍繞人物活動的場所和環境描寫。
- **例子與作用：** 展現故事情節、人物動態，烘托人物形象或心情。

<a id="k-4590e60fb630ea71"></a>
**白描法**

- **定義與辨識：** 抓住特徵，用簡潔質樸的文字勾勒本來面目，不依靠濃烈色彩字眼或比喻、比擬、誇張等修飾。
- **例子與作用：** 簡潔、傳神。

<a id="k-a21a5bf78aab847e"></a>
**細描法**

- **定義與辨識：** 細緻刻畫，講究鋪陳、渲染，常用對比、比喻、擬人、誇張等手法。
- **例子與作用：** 纖毫畢現、繪聲繪色，語言精細而富色彩。

<a id="k-54756ca25da2ac59"></a>
**動態描寫**

- **定義與辨識：** 寫活動或變化中的景物，也可賦予靜態事物動感。
- **例子與作用：** 生動傳神，感染力較強。

<a id="k-1f8497378d7650a4"></a>
**靜態描寫**

- **定義與辨識：** 寫靜止狀態或環境氛圍。
- **例子與作用：** 精細刻畫特徵，使讀者注意力集中於景物。

<a id="k-e3d9b35b9ce95ad7"></a>
**動靜結合**

- **定義與辨識：** 把動態與靜態描寫配合使用。
- **例子與作用：** 畫面有層次；如用動襯靜，須交代動與靜的關係。

<a id="k-8e3a39d2f8ba0428"></a>
**多感官描寫**

- **定義與辨識：** 運用視、聽、嗅、味、觸覺寫所見、所聞、所感。通常選其中兩三種，不必湊齊五種。
- **例子與作用：** 例如沙灘的景色、海浪聲、腳踏沙粒的感覺、海水味道，使景物逼真，引起共鳴。

<a id="k-b1d699cd0da21020"></a>
**多角度描寫**

- **定義與辨識：** 從仰望、俯瞰、平視、遠眺、近看，以及全景、局部等角度觀察。
- **例子與作用：** 不同角度呈現不同面貌，增強空間層次與立體感。

<a id="k-24a3f103fef09a36"></a>
**場面描寫**

- **定義與辨識：** 在特定時間、地點，鋪排周圍環境、景物及人物的行為、心理活動。
- **例子與作用：** 營造氣氛，再現情境；須按內容判斷是否推動情節。

<a id="k-8893dcd99f72e1ed"></a>
**步移法**

- **定義與辨識：** 觀察點隨人物移動，逐一描寫沿途所見。
- **例子與作用：** 條理清楚，使讀者有隨作者同遊之感，引起共鳴與聯想。

<a id="k-c13f9f947348710f"></a>
**定點描寫**

- **定義與辨識：** 立足點固定，按視線轉移，依次寫所見景物。
- **例子與作用：** 固定的是觀察位置；視線仍可改變方向、遠近及高低。

<a id="k-dda06d0dec8260b7"></a>
**隨時推移法**

- **定義與辨識：** 按早晚、不同日子、晴陰雨、春至冬、潮漲退、花開謝、日出落等時間或變化過程描寫。
- **例子與作用：** 抓住同一景物在不同時間的特點，突出面貌變化。

## 說明

<a id="k-07fef67bb0356a1c"></a>
**定義說明**

- **定義與辨識：** 用簡明、準確的語言指出對象的本質特徵。
- **例子與作用：** 界定概念與範圍。

<a id="k-0e51ef3d151119a8"></a>
**數字／數據說明**

- **定義與辨識：** 列出數量、比例、年份等，如城市人口年齡分布、市民平均收入。
- **例子與作用：** 使資料準確、具體、可信；數據須可核實。

<a id="k-61bf52b2160b8921"></a>
**舉例說明**

- **定義與辨識：** 用典型生活事例、歷史事例或明示的假設情況，說明抽象、生疏、複雜的事物。
- **例子與作用：** 使形狀、性質、特徵、功效或用途具體清楚。

<a id="k-7e42c7e2ad9b46e7"></a>
**分類說明**

- **定義與辨識：** 按形狀、性質、成因、功能等標準分門別類，再逐類說明。
- **例子與作用：** 條理分明，容易掌握。

<a id="k-1f2211fed7c45c2f"></a>
**引用說明**

- **定義與辨識：** 引用名言、詩詞、典故、典籍、諺語、文獻或資料記錄等。
- **例子與作用：** 增加權威感、說服力及閱讀趣味。

<a id="k-d0bd8cd5525bec9d"></a>
**比喻說明**

- **定義與辨識：** 以熟悉、具體、淺顯的事物，比喻抽象、陌生、複雜的事物或道理。
- **例子與作用：** 化抽象為具體，使內容生動易明，增加趣味。

<a id="k-47bd4be6da2a1fc6"></a>
**類比說明**

- **定義與辨識：** 以性質相近的另一事物說明事理。
- **例子與作用：** 由已知通向未知，幫助掌握。

<a id="k-5d9a0d5f54cd02ad"></a>
**比較說明**

- **定義與辨識：** 比較兩種或以上有關、相同或不同的事物。
- **例子與作用：** 突出異同、特徵、差別、優劣或正誤。

<a id="k-25328a760ca2b294"></a>
**描述說明**

- **定義與辨識：** 細緻描述對象某方面的形態、特徵、狀態或演變。
- **例子與作用：** 使讀者具體了解對象。

<a id="k-9cf4ca4393259bdb"></a>
**時間順序**

- **定義與辨識：** 按發生、演變的先後，從先到後、早到晚、古到今、開始到結束說明。
- **例子與作用：** 例如說明印刷術發展史。

<a id="k-1d9ba3ddd3c7a57a"></a>
**空間順序**

- **定義與辨識：** 依空間位置或構成組織，按上下、高低、前後、左右等方位說明。
- **例子與作用：** 例如介紹公園設施。

<a id="k-a4e50b627e287ede"></a>
**總分層次**

- **定義與辨識：** 「總」是綜合概述，「分」是分項說明。總分式先在開首綜合說明，再在各段分項展開。
- **例子與作用：** 層次清楚，分項受總述統攝。

<a id="k-7d6f8672f0678a8e"></a>
**其他組織方式**

- **定義與辨識：** 按需要使用分—總、總—分—總，或依事理邏輯安排。
- **例子與作用：** 這是可選的組織方式，先看說明對象及全文實際安排。

## 議論

<a id="k-f0f56ceef95d66d0"></a>
**舉例論證／例證法**

- **定義與辨識：** 舉出真實、典型事例作證據；也可明示設想的情境作推論。
- **例子與作用：** 具體有力；必須說明例子怎樣支持論點。

<a id="k-a8c14373c43ca0ef"></a>
**引用論證**

- **定義與辨識：** 以古語、俗語、典籍、名言、偉人言論或公認道理為論據。
- **例子與作用：** 以權威或常用言論增加說服力。

<a id="k-c946e32675c868de"></a>
**對比論證**

- **定義與辨識：** 把互相對立的事物、道理對舉，比較它們的對立點。
- **例子與作用：** 突出某些屬性及優劣、對錯，深入剖析觀點。

<a id="k-9164a367adeeac92"></a>
**正反論證**

- **定義與辨識：** 從正反兩方面論證同一觀點。
- **例子與作用：** 以一正一反的鮮明對比，清楚呈現立場；與對比論證部分重疊。

<a id="k-578ed29708b5b76f"></a>
**比喻論證**

- **定義與辨識：** 以一種或幾種具體事物，比喻並論證抽象道理；本體與喻體須有相同或相似性質。
- **例子與作用：** 要加上議論，說明比喻與道理的共同點，才能使論證淺白易懂。

<a id="k-fe1fafecd8330797"></a>
**類比論證**

- **定義與辨識：** 比較兩種性質相同或相似的事物，抓住共通點，由已知一事推知或證明另一事。
- **例子與作用：** 建立合理聯繫，幫助理解與接受觀點。

<a id="k-4477c189f9e6b435"></a>
**因果論證**

- **定義與辨識：** 分析原因、結果及兩者關係以證明論點。
- **例子與作用：** 揭示事理發展邏輯。

<a id="k-482d71e429069e6e"></a>
**演繹論證**

- **定義與辨識：** 根據道理作符合邏輯的推論；常由一般原則推到個別結論。
- **例子與作用：** 使推理清楚，增加說服力。

<a id="k-deba4065bf901d50"></a>
**歸納論證**

- **定義與辨識：** 從多個事例的共通點得出一般結論。
- **例子與作用：** 累積多項證據，增強說服力。

<a id="k-c2ea4fcf31a9131b"></a>
**借事說理**

- **定義與辨識：** 敘述具體事情以說明抽象道理，事與理須有緊密聯繫。
- **例子與作用：** 以說理為主，記事不必鉅細無遺；使深奧道理易懂、易共鳴。

<a id="k-20c3169a0b447bbf"></a>
**託物說理**

- **定義與辨識：** 藉某物的特徵寄託道理、思想感情、品格或志向；可使事物帶有人格化色彩。
- **例子與作用：** 含蓄、形象地表達。辨認時須交代物的特性與所寄託內容。

<a id="k-4359d923fb65fc9b"></a>
**論點**

- **定義與辨識：** 作者提出的看法和主張：認同、要求、贊成或反對甚麼。
- **例子與作用：** 回答「作者主張甚麼」。

<a id="k-bb138d4fc9bc5e62"></a>
**中心論點**

- **定義與辨識：** 全文全力論證的總主張。
- **例子與作用：** 統攝各部分論述。

<a id="k-2fbcea7d41b38aa5"></a>
**分論點**

- **定義與辨識：** 從不同角度補充或支持中心論點的主張。
- **例子與作用：** 各分論點須回到中心論點。

<a id="k-11778c11d52a1bbd"></a>
**論據**

- **定義與辨識：** 用來印證論點的事實和理由。
- **例子與作用：** 須真實可靠；假設情境要明示，不能冒充已發生的事實。

<a id="k-086e2092fe100419"></a>
**事實論據**

- **定義與辨識：** 實際發生的事情，如歷史事件、統計數據、新聞時事。
- **例子與作用：** 用具體材料支持主張。

<a id="k-bb07211a7e5edd10"></a>
**道理論據**

- **定義與辨識：** 公認道理、名人言論、寓言故事、科學定理等。
- **例子與作用：** 用道理或具有說理意義的材料支持主張。

<a id="k-7f01b7c450a979c8"></a>
**事例**

- **定義與辨識：** 以當前、有代表性的事件作例證。
- **例子與作用：** 區分例子的時代與代表性。

<a id="k-68a3d9f3c8cdd68a"></a>
**史例**

- **定義與辨識：** 以歷史事件作例證。
- **例子與作用：** 說明歷史事件與論點的聯繫。

<a id="k-d6829cef1e1dcab8"></a>
**設例**

- **定義與辨識：** 以明示的假設情況作例證。
- **例子與作用：** 用設想推演說理，不能當作史實。

<a id="k-42b933272d656192"></a>
**語例**

- **定義與辨識：** 以專家、學者、名人的話語，或精警格言、成語作例證。
- **例子與作用：** 也可從援引言論的角度判作引用論證。

## 抒情

<a id="k-15bf9b2d78d5bdf1"></a>
**直接抒情**

- **定義與辨識：** 不借其他載體，直截了當地說出自己的感情。
- **例子與作用：** 感情明確、直率，也可強烈集中；適用於不同文體。

<a id="k-6f3836831f28a4fe"></a>
**間接抒情**

- **定義與辨識：** 把感情滲透於敘事和描寫中，藉事件、景物、物件，也可藉旁人反應或環境表達。
- **例子與作用：** 感情有依託，較含蓄而具體。

<a id="k-d90c18d5f100cdf7"></a>
**借事抒情**

- **定義與辨識：** 通過記述一件事或多件零碎事件，抒發感情和抱負。
- **例子與作用：** 感情具體、真實，與選材及情節相連。

<a id="k-972d1a2d4cbc5363"></a>
**借景抒情**

- **定義與辨識：** 描寫客觀景物以抒發感情，可再按景與情的關係細分。
- **例子與作用：** 《販夫風景》寫小販擺賣的熱鬧情景，反映對小攤子的喜愛。

<a id="k-04cd7e90fbbe2ef6"></a>
**借物抒情**

- **定義與辨識：** 描述物的外形、內在特徵，聯想到象徵意義或人物品格，寄託感情、抱負。
- **例子與作用：** 感情含蓄而有具體依託，也可生動傳神。

<a id="k-b81a76016dccd5f5"></a>
**觸景生情／因景生情**

- **定義與辨識：** 看到外在景物，觸發心中情思；通常以先寫景、後抒情的結構表現。
- **例子與作用：** 交代感受生起的經過，使情感脈絡清晰。

<a id="k-cbb6281cab8c8f56"></a>
**緣情寫景／融情入景**

- **定義與辨識：** 把主觀情感融入或投射於景物，寫景文字本身也是抒情文字。
- **例子與作用：** 寓情於景、情景交融，使感情突出具體而含蓄。

## 結構

<a id="k-e361d854c1acbd0e"></a>
**開門見山／下筆立論**

- **定義與辨識：** 開首先點題、解說題意、闡明主旨或提出觀點。
- **例子與作用：** 明朗有力，讓讀者迅速了解意圖。

<a id="k-67ef9713df548fb5"></a>
**設置懸念**

- **定義與辨識：** 先交代部分情節或設置疑團，後文再解釋。
- **例子與作用：** 引起好奇，吸引追讀，使敘述有起伏。

<a id="k-06100053f8b1c50e"></a>
**鋪墊**

- **定義與辨識：** 先鋪陳次要人物、事物、事件或背景，烘托後面要出現的重點。
- **例子與作用：** 為主要內容蓄勢，使發展自然。

<a id="k-89d0449a9d015433"></a>
**伏筆**

- **定義與辨識：** 前文為後文的人、事、情節留下含蓄的提示或線索。
- **例子與作用：** 後文出現時不突兀，結構嚴密緊湊。

<a id="k-58587095e40961e1"></a>
**首尾呼應**

- **定義與辨識：** 開頭交代、提示或埋下的伏筆，在結尾重申、補充或揭示。
- **例子與作用：** 結構完整、統一連貫。

<a id="k-e1dfd87a5683c7b8"></a>
**前後呼應**

- **定義與辨識：** 文章不同位置重提相近內容、回答前文問題或揭示伏筆；一篇可有多處呼應。
- **例子與作用：** 使人物事件的出現自然合理，強調重要內容或主題。

<a id="k-4e6d36d4ce0e1425"></a>
**承上啟下／過渡**

- **定義與辨識：** 以字詞、句子、段落或層次之間的銜接承轉，承接上文、開啟下文。
- **例子與作用：** 像橋樑串連內容，使脈絡清晰、發展順暢。

<a id="k-df6d61d47e937d59"></a>
**先抑後揚**

- **定義與辨識：** 先否定或貶低，再深入寫特徵、內在意義，予以肯定褒揚。
- **例子與作用：** 突出值得肯定之處，形成轉折，印象深刻。

<a id="k-ccfbc2863592e669"></a>
**先揚後抑**

- **定義與辨識：** 先肯定，再經描述加以否定或貶低。
- **例子與作用：** 突出被否定之處，使文章有波瀾。

<a id="k-1c74f21a1087853f"></a>
**先破後立**

- **定義與辨識：** 先提出並駁斥錯誤觀點，再確立自己的主張。
- **例子與作用：** 論證有針對性，立場突出。

<a id="k-aa3134c1e963d6a7"></a>
**層層遞進**

- **定義與辨識：** 按大小、高低、遠近、內外、整體到局部或相反方向，逐層描述或論說。
- **例子與作用：** 條理分明，突出重點，使讀者逐步深入理解。

<a id="k-2a21bb77fc51a963"></a>
**借古諷今**

- **定義與辨識：** 評論古代相類似的人事，含蓄影射現實狀況。
- **例子與作用：** 以史為鑑，具體表達看法，增加說服力，達到意在言外的效果。

<a id="k-7b8f2ae11c779fd4"></a>
**善用譬喻**

- **定義與辨識：** 適當用比喻表達內容。
- **例子與作用：** 使內容具體、生動，增加趣味；可同時從修辭和篇章表達角度分析。

<a id="k-363eb907f3991193"></a>
**善用想像**

- **定義與辨識：** 在已有材料和觀念上，聯想或創造新觀念、新情境。
- **例子與作用：** 增加新鮮感、畫面感與趣味。

## 寫作實用

<a id="k-1e8981182fe64137"></a>
**順敘起首**

- **定義與辨識：** 簡單交代時間、地點、人物等，直接帶出事件或場景。
- **例子與作用：** 記敘抒情：迅速建立情境。

<a id="k-0dd6d4c4640081f8"></a>
**倒敘起首**

- **定義與辨識：** 先寫結果或現在情況，再回憶過去，引入主題。
- **例子與作用：** 記敘抒情：突出重點或製造懸念。

<a id="k-ecba9753502f45ca"></a>
**景物描寫起首**

- **定義與辨識：** 描寫眼前景物以渲染氣氛，或由景觸發感情。
- **例子與作用：** 記敘抒情：以環境、心境帶入主題。

<a id="k-e5031f6355c259da"></a>
**名言起首**

- **定義與辨識：** 引用與主題相關的名言、諺語或詩詞。
- **例子與作用：** 記敘抒情：引入主題，不能只放一句無關引文。

<a id="k-20c2447f7f72108b"></a>
**開首設置懸念**

- **定義與辨識：** 先交代部分情節，讓讀者想了解事件全貌。
- **例子與作用：** 記敘抒情：吸引閱讀下文。

<a id="k-3e99722512bb1982"></a>
**概括描寫起首**

- **定義與辨識：** 概括寫人物或場景，讓讀者對描寫對象有初步印象。
- **例子與作用：** 記敘抒情：先建立整體輪廓。

<a id="k-b798b537e773c80d"></a>
**引用材料起首**

- **定義與辨識：** 用生活事例、名言、社會時事、故事等引入。
- **例子與作用：** 論說：由材料帶出討論主題。

<a id="k-72f989528a4fa272"></a>
**定義起首**

- **定義與辨識：** 解釋關鍵詞句，設定論說範圍。
- **例子與作用：** 論說：先界定要討論甚麼。

<a id="k-08b845dcb64e770e"></a>
**相反意見起首**

- **定義與辨識：** 先提出相反意見，明確表示反對，再表達個人立場。
- **例子與作用：** 論說：建立論述針對性。

<a id="k-4d3e30cd924bc859"></a>
**交代六要素**

- **定義與辨識：** 時間、地點、人物、起因、經過、結果。
- **例子與作用：** 記敘抒情：以「經過」為敘事重心，分配較多篇幅。

<a id="k-7634ab804e0ce05f"></a>
**情節起伏**

- **定義與辨識：** 安排變化、轉折及高潮，使重點帶來驚喜、意外或情感轉變。
- **例子與作用：** 記敘抒情：使事件有發展，避免平鋪直敘。

<a id="k-8899002d660c3188"></a>
**刻畫人物**

- **定義與辨識：** 按需要用肖像、行動、語言、心理描寫。
- **例子與作用：** 記敘抒情：用細節反映性格。

<a id="k-5d9703375487b535"></a>
**直接與間接抒情**

- **定義與辨識：** 可直接傾吐，也可寫別人反應、事件或環境來表達。
- **例子與作用：** 記敘抒情：感情要與具體內容相連。

<a id="k-1d554d8410eb87e1"></a>
**融情入景**

- **定義與辨識：** 把喜怒哀樂融於客觀景物。
- **例子與作用：** 記敘抒情：用景物含蓄表達感情。

<a id="k-a30a86e9b3849d65"></a>
**配合論證方法**

- **定義與辨識：** 按材料選用舉例、引用、對比等方法。
- **例子與作用：** 論說：每種方法都要支持論點。

<a id="k-4e8fe4b202970c62"></a>
**不同角度論證**

- **定義與辨識：** 可從個人、學校、家庭、社會等角度展開。
- **例子與作用：** 論說：讓內容全面；各角度仍要回到中心。

<a id="k-ac2e0180151b5aba"></a>
**正反論述**

- **定義與辨識：** 既分析反面，也分析正面。例：談戒煙，既論吸煙壞處，也論戒煙好處。
- **例子與作用：** 論說：透過正反兩面把道理說完整。

<a id="k-a82b50e7df96e721"></a>
**善用駁論**

- **定義與辨識：** 舉出相反意見，再分析其不足、加以反駁。
- **例子與作用：** 論說：使觀點更明確。

<a id="k-3f59b120934158d2"></a>
**善用標示語**

- **定義與辨識：** 例如「首先」「其次」「另外」「最後」「總括而言」。
- **例子與作用：** 論說：提示次序和層次；詞語須符合實際關係。

<a id="k-a7f24eb3b99ee5af"></a>
**善用主題句**

- **定義與辨識：** 在分論點起首或結尾，寫一句簡潔表達觀點的句子。
- **例子與作用：** 論說：讓讀者清楚看見本段主張。

<a id="k-47180cb3cf09b209"></a>
**首尾呼應作結**

- **定義與辨識：** 回應首段交代的人、事、景、疑問或伏筆。
- **例子與作用：** 使文章完整嚴謹，重點更突出。

<a id="k-db7e8c105c018e1d"></a>
**展望作結** 【待核，不作唯一判斷】

- **定義與辨識：** 帶出正面展望，表達積極的人生觀。
- **例子與作用：** 由當前經驗推向未來，延伸主題。

> 核對提醒：來源只給正面展望的寫作建議，未釐清它是一般定義還是正面寫法示例；不能把一般概念限為正面積極。暫停新抽題，保留歷史，待補證再重構。

<a id="k-9852174d19d30bda"></a>
**名言作結**

- **定義與辨識：** 以相關名言、詩句畫龍點睛，回應主題。
- **例子與作用：** 收束內容，留下餘韻。

<a id="k-276795877dcf161c"></a>
**反問作結**

- **定義與辨識：** 用包含確定意思的問句作結。
- **例子與作用：** 加強語氣，引人深思；要與已有論述一致。

<a id="k-411e5de514c81b9f"></a>
**卒章顯志**

- **定義與辨識：** 經過前文描述或論述，在結尾點明全文主題、志向。
- **例子與作用：** 自然點題，收畫龍點睛之效，留下深刻印象。

<a id="k-25278b5073f6a4c5"></a>
**總結全文**

- **定義與辨識：** 以簡明語句概括全篇的主張或主要內容。
- **例子與作用：** 收束全文，強調重點。

## 閱讀應用

<a id="k-35f46d31141e7837"></a>
**1 指出手法**

- **定義與辨識：** 寫完整名稱；需要時寫分型，如反襯、暗喻。
- **例子與作用：** 避免只抄題目或羅列多個手法。

<a id="k-b90808eedef7381e"></a>
**2 引文本證據**

- **定義與辨識：** 摘錄關鍵短語，或準確概括其安排。
- **例子與作用：** 避免大段抄文而不分析。

<a id="k-6c7616c77d66befb"></a>
**3 解釋如何成立**

- **定義與辨識：** 指出本體與喻體、比較雙方、遞進尺度、感官轉移等。
- **例子與作用：** 避免只背定義或只寫「生動形象」。

<a id="k-06930dcb4053b1b4"></a>
**4 寫具體作用**

- **定義與辨識：** 說明突出哪個特徵、感情、人物形象或觀點。
- **例子與作用：** 避免把全部可能效果套上。

<a id="k-afaaad71570a27b1"></a>
**5 扣連上下文**

- **定義與辨識：** 回到段旨、主旨、語氣、結構或作者態度。
- **例子與作用：** 避免離開語境作空泛評價。
