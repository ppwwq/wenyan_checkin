# 我的 DSE 文言知識庫

**從知識出發：先讀懂篇章，再查字詞、手法和跨篇關係。**

第一層是16篇概要、48張重新整合的核心知識卡及六組主題比較；第二層才是完整字詞、解釋與例證。來源只保留在核對層，不作主要目錄。

## 怎樣使用

1. **學一篇：** 點篇名，先讀核心問題、全篇思路和常見混淆，再查完整細項。
2. **查一個知識：** 用字詞總索引或手法總表；同詞不同意思會並列語境。
3. **練比較：** 讀六組主題比較，再用原句支持異同。
4. **有不同說法：** 看異解與待核清單，不硬背成唯一答案。
