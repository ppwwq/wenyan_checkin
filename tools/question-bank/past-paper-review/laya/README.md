## 模型能否用來篩選

40題預留集，與Codex依來源建立的作者參考標記比較：

| 維度 | 模型一致數 | 全部猜調整集最多的類別 |
|---|---:|---:|
| 逐個錯項吸引力 | 51／120（42.5%） | 60／120 |
| 整組錯項效力 | 25／40（62.5%） | 25／40 |
| 主要考查操作 | 14／40（35%） | 9／40 |

這是對作者參考標記的一致率，不是教師金標準確率。沒有真人學生資料，不稱誘答率、鑑別度或學習效果。逐項吸引力低於簡單基線，整組效力與基線持平；操作分類也不足以承擔可靠分流。正誤、多解、用途適配等輸出尚未建立充分的獨立評測，不能拿它們補救上述不足。

因此`adoption.json`將`fullBankEnabled`保持為false，批次工具拒絕全庫語義篩選。Laya目前只用於固定樣本實驗，不作題目准入／淘汰、答案或評分裁決。要更换規準或模型须另建run並重新評測，不能解除开关當作改善效果。
