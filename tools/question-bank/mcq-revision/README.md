# 指定篇章四選一修訂

用戶要求以選擇題形式改善 App 現有題目。2026-09-20 進一步確認：出題扣住十六篇指定文本及篇章間比較；不以另造陌生短文替代甲部訓練。

- `baseline-bank.json`：本輪修改前的完整題庫快照，保留舊題及穩定識別碼。
- 核准分包：`part-a.json`、`part-b.json`、`part-c-final.json`、`part-c-lunyu.json`、`part-c-vocab-1.json`、`part-c-vocab-tail.json`。合計1,980題處置，1,921修訂、59保留；其餘分包為中間稿，不直接發布。
- `release-manifest.json`：只列獲核查的篇章改稿及精確 SHA-256；生成流程不讀取其他草稿。
- `apply_revision.py`：在原生成流程完成後套用修訂，檢查來源未漂移、題號／記憶單元不變、版本遞增及全量處置。

`part-d.json`、`part-d-specs.txt` 和 `author-d.py` 是早段誤作的151道自擬情境附錄改稿，**已撤出本輪發布範圍，不應合併進 App**。原151道附錄知識題暫保留原狀，仍須使用者另開附錄專項，不算本輪甲部指定文本改題成果。這些撤回草稿及中間稿僅留在原本地工作區，不包含於本次GitHub發布；保留記錄不代表內容通過驗收。

題庫已合入版本2026.09.20.1，2,131題／2,081記憶單元；37項自動測試及Chromium驗證通過。2026-09-20已部署正式網站，26個公開檔案與發布包逐位元一致，見 [部署狀態](../../../web-study/cloudflare/DEPLOYMENT.md)。

重建仍用 `full-expansion/build_full_bank.py`，然後執行 `validate_bank.py` 和應用檢查。不得用舊作者工具的產物直接覆蓋最終題庫。

所有修訂仍是四選一辨識練習，不能等同完成甲部的自行摘錄、完整書面解說或評分訓練。代理審稿與結構核查不代表教師獨立終審、學生試做或線上部署完成。
