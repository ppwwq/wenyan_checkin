# 跨篇易混詞

把現有「易混詞義對照」的跨篇用法編成獨立的四選一辨義題。只加入跨篇內容；同篇對照、原有11組閱讀卡及原有題目保持原樣。

目前跨篇對照為「歸」：《論語》「天下歸仁焉」、《岳陽樓記》「吾誰與歸」、《山居秋暝》「竹喧歸浣女」。三種兩篇配對各一題，合計3題。每題有獨立題號及記憶單元、雙方原文和PDF定位。沿用原書對「天下歸仁」的「稱讚、認同」之解。

`items.json` 保存作者題稿及逐項解析；`build_questions.py` 對照原書結構資料和已提取的PDF頁文字驗證詞義、原句及篇章，再加入題庫。`full-expansion/build_full_bank.py` 已接入此步驟；重建時不會遺失新增题。已有同名題內容不符時會停止，須明確處理版本。

現有抽題規則要求 `essayIds` 全部選中，所以只選其中一篇不會出題。題目仍受字詞能力、題數、錯題及指定題目範圍限制；三篇全選時，三種配對都可進入題池。

版本2026.09.22.1：總數2,134題／2,084個記憶單元。內容核對方式為作者自檢，逐題G1–G5記錄及干擾項誤讀假設隨題保存；教師覆核、學生試做均未執行。建立與測試本機題庫不代表已部署正式站點。

驗證：`py -m unittest discover -s tools/question-bank/confusable -p test_build_questions.py`；應用測試見 `web-study/tests/comparison-scope.test.mjs`。
