## 行為

在現有「學習設定 → 選擇作答方式」加入「加入字詞打字練習」，預設關閉。開啟後，可打字字詞題在日常訓練及當日錯題回練中直接用打字作答，並受原篇章、題類、題量與去重規則限制；沒有新入口或複製題目。選取不含可打字字詞的範圍時，題組仍全為選擇題。

提交後對照原參考答案自查，不作字串相等自動判分；「暫時不會」直接記為待鞏固。已提交題目按原作答模式顯示。未答題切換方式時，選擇與打字草稿分別保留；跳過草稿、補題、補答、同步與同帳號備份沿用原流程。普通自選練習仍用選擇題。
