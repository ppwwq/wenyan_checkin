# 錯題入口修復（2026-09-24）

本地介面 `2026.09.24.7` 已完成；正式站保持 `2026.09.24.6`，本輪未部署或推送。

## 已確認的問題

- 正式站點擊首頁「錯題」後進入一般選篇頁，顯示「可用252題」，實際只組到1題。入口沿用自選練習的篇章／能力等篩選，可能隱藏其他錯題。
- 合成回歸案例確認，舊程式按 `memoryId` 的薄弱狀態篩選，可能抽到同一知識點的未答題，並排除真正答錯的變體。[修復前證據](before/reproduction.json)記錄實際抽到 `a-unseen-sibling`，預期為 `z-actually-wrong`。

## 修復

- 首頁錯題入口改為獨立清單，包含各篇及手法附錄的實際錯題，支援整組及逐題重練，不更改每日設定或自選篩選。
- 錯題篩選與題目標記共用既有 `questionMistakes` 規則，按題目ID及有效作答判斷；保留當天訂正後標記、另一天答對移出及教師評分更正的規則。
- 自選練習「只練錯題」的可用數量、篇章數量、標題及開始按鈕使用錯題口徑；下架題不加入新練習。
- 沒有錯題時顯示空狀態，不能用未答新題湊數。新模組加入建置語法檢查與離線快取清單。
