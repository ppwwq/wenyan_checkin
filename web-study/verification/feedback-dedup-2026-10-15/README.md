# 反饋入口、每日去重及獨立修辭題 · 2026-10-15

介面與題庫版本均為 `2026.10.15.1`。改動在雲端工作區完成，尚未推送或部署。

## 實際行為

1. 每題上方固定顯示「反饋／舉報」。未作答、答錯、答對後均可回報；答對時解析收起也不會藏起按鈕。增加「同日重複出題」「DSE真題與原卷不符」分類。回報保存題號、版本、來源及可用的本次答案；離線可保存，連線後同步至維護者。
2. 每日訓練、自選加練、錯題練習共用同日去重：題號、知識點、同組辨析題均去重。實際顯示即記錄，跳過後當天不再抽到；只預先排進題組但尚未顯示的題目不算。暫停後允許續做當前未答題。香港時間零點更新可出題範圍，錯題最早翌日再練。
3. 出題記錄使用既有 `browse` 事件的 `purpose: practice` 子類型，支援原有同步與備份。普通閱讀卡不佔每日出題名額，也不新增作答、正確率或每日完成數。歷史答案、已提交題目快照及有效評分保留。
4. 題庫總數和累計已練數獨立於每日可抽題數；當天已出現的題目退出抽題池，不會使累計數下降。舊題組在續做及換題時按現有範圍、可用題和版本重新檢查。
5. 按使用者澄清，只改 30 道獨立修辭題（24 道單項辨識、6 道易混修辭比較），先展示例句再選手法。文言文、古詩篇章題不改；DSE 原題 27 題完整資料不改，固定保留原選項順序，並清楚標示原題年份、題號、分值。

每日去重依據本機及已同步的紀錄；互相未同步的離線裝置無法預先得知對方顯示了甚麼。瀏覽器驗證覆蓋離線後同步以及第二個裝置收到紀錄後的去重。
